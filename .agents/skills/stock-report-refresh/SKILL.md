# 股票标签与报表刷新

消费基础数据清单，计算标签并保存可复算的评估快照，再更新报表。默认每个交易日完整收盘数据到达后计算价格标签；新闻/综合状态可每日检查。长历史窗口不要求低频刷新。

## 读取与接入

读取根目录 `AGENTS.md`、[数据交接契约](../stock-data-backfill/references/data-contract.md) 和 [当前五标签公式](references/five-traits-v2.md)。任务指定的报表、证券范围、截止时点及算法版本优先；数据粒度/补齐间隔/刷新间隔/计算窗口分别记录。

现有目标通常是 `analysis/ai_trend_quadrant_v2/`。若存在，先读 README、VIEW_NOTES、model/build/render 和验证入口，保留当前交互与公式。原 `PROTOCOL.md` 登记的是冻结模型及旧排版，当前视图以 README/VIEW_NOTES 为准。

已知接入缺口：旧 `build.py` 从 v1 `results.json` 读取固定截止、成员及输入；原时间曲线为历史回算。直接重复执行它不会得到新执行日评估，也不会产生真实每日运行历史。首次接入需提供参数化的清单/截止/模式/输出入口及快照账本，保持旧运行目录和原始输入不变。研究目录可能未提交；干净克隆中缺失时依据本 skill 与公式参考实现必要模块，明确原报表不在当前 checkout，不能声称已经复用或验证它。

## 一次刷新

1. 固定本次 `evaluation_cutoff`、`observation_mode`、股票池、模型版本和输出目标。读取一个已发布的 data manifest，校验引用哈希和时间范围。渲染过程不直接调用行情/新闻接口；缺数据按契约生成补齐请求。整体任务包含补齐时可串行调用数据 skill，预算结束后保留缺失状态。
2. 逐标签检查依赖与有效覆盖。行情不足、过期、零方差或精确时刻未知分别处理；地图 G/V 不足时保留无坐标证券及可查看详情，不能填零或删去。各市场使用独立完整行情截止，沿用数据/业务结论显示原截至时间。
3. 按模型版本计算 G/V/M/J/S 的原始值、单位、类别倾向与不确定性。当前 G/V/M/J 是价格统计，S 是日级属性变化分数；即使刷新稀疏，S 仍由内部逐交易日四属性计算，不能用“最近 20 次执行”替代。算法参数改变另升版本，不混入同一可比较曲线。
4. 每日检查新闻增量、已有事件状态、时间衰减和财务/业务证据有效期。价格变化可触发估值更新，沿用最新已披露财务；同一未变财报不用每日重读。复用业务证据按发行人去重，不合并证券价格。新证据导致重评时保存依据与旧新评级关联。
5. 新增新闻/估值标签须有独立且版本化的公式、所需数据、衰减/事件生命周期、缺失和验证规则。现有五标签并没有这些能力；未实现时显示未接入，不制造综合分数。业务 A+/A 与研究初评分别展示，沿用核查评级时保留有效期。若调用质量核查流程，使用实际存在的 ai-stock-rating skill。
6. 保存不可覆盖的评估快照及尝试账本，再由已保存结果渲染页面。相同幂等键重跑不制造新点；真实运行与历史补算分别标识。新闻随时间衰减时即使没有新文章，新的评估截止仍需计算；历史修订重算受影响区间，保留原快照。
7. 验证数据/页面后原子发布新的 current 指针与页面。计算成功而渲染失败时保留已完成快照并可重新渲染；无有效新结果时保留上次可用页面，标记最近尝试、原数据截止和失败原因，不能更新标题为最新成功。

## 既有地图与时间谱契约

- 地图是入口：横轴波动 V、纵轴方向 G，M/J/S 是辅助标记；筛选不改坐标。点击证券打开右侧可关闭浮层，重叠证券可选择；未知仍可查看。
- 侧栏一张时间图：横轴真实日期，五个维度各一条线；只在保存的有效计算结果处画点。未知记录断线，周末/假日保持日历间隔。长时间未计算的连线仅连接端点，不暗示中间已计算，悬浮信息显示两个点的间隔。
- 14/30/60 指最近日历天展示范围，包含评估截止日；它们不是三条窗口线，也不改变 120/60/20 的计算窗口。评估截止为横轴日期依据，详情同时显示真实计算时间与各源数据截至时间。
- 五标签量纲不同。沿用固定显示映射并保留原始值和单位，不能按本次股票/范围自动缩放成无法跨时点比较的分数。显示值与分类倾向、业务评级、综合分数分别说明。
- 数据每天补不等于标签每天已有点；页面首次补算历史须标明历史回算。市场未开盘时旧价格不能伪造为新行情；周末新闻评估可以有新快照，但须显示原价格截止。

## 概率与费用边界

保留现有模型的概率含义。五标签 bootstrap 类别频率、v1 的 Pugh 条件象限倾向与未来上涨概率不同；权重加总或 0–100 显示值不能直接叫概率，不能把各标签边缘概率相乘为已验证联合象限概率。若任务要求刷新原 v1 Pugh 报表，读取其模型/参数单独计算，不能用 v2 的 G/V 地图替换旧模型却沿用名字。

记录计算、重采样、材料核查、渲染和验证耗时，复用/新核查公司数，模型调用及实际 token/费用。每日评估不等于每日全池深读；新证据、到期复评和时间衰减分别触发，缺乏数据渠道不能声称无事件。固定算法的工程验证不代表投资策略或预测概率通过独立验证。

## 接手实现的验收

最少用可控输入验证：新交易日数据使实际窗口推进；截止后数据被排除；缺失标签独立保留；重复执行无重复点；修订产生新版本且旧快照不变；纯渲染不增加标签点；稀疏执行下 S 仍使用日级序列；14/30/60 仅裁切视图；未接入新闻/估值保留未知。

在真实范围上给出至少一次执行证据与可复算快照。已有 `verify.py` 或视图检查可复用，但需核对适用版本。检查地图 → 点证券 → 单图时间轴 → 日期详情/图例 → 关闭浮层的实际流程，覆盖窄屏。静态 SVG/fixture 通过与真实浏览器验收分别报告；工具限制时如实保留未验证项。

交付 `report_run_id`、输入 `data_run_id`、截止和模式、已评/未知数量、主要变化、快照及页面路径、耗时/费用和验收证据。此 skill 执行一次，不自行创建调度、发通知、修改自选或交易；用户要求定时运行时再明确时区、数据就绪条件、锁、超时和睡眠后补跑语义。

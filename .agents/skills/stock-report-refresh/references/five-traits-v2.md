# five_traits_v2：价格描述与固定显示映射

本参考用于现有模型不可用时交接公式，也用于核对实现没有静默改变定义。它不是新训练模型，不包含实时新闻、估值、事件归因或策略有效性。已有模型与本参考不一致时先报告差异，不能边刷新边悄悄换算法。

## 输入与覆盖

同一证券的完成交易日日收盘价 `P_t`，单一可追溯复权来源和币种。定义 `r_t = log(P_t / P_(t-1))`。120/60 表示交易日收益区间，需要 121/61 个收盘；S 需要 140 个收益区间、141 个收盘。

按相应市场官方日历检查逐项窗口，不能跨真缺失构造相邻收益。上市前复用代码的旧行情剔除；零方差、分母零和覆盖不足分别输出未知。价格单位缩放不改变这五个描述，但复权版本修订可能改变它们。

## 五标签

| 标签 | 定义 | 类别界限 |
| --- | --- | --- |
| G 长期方向 | 最近 120 个 r 的均值 × 252 | 小于 -0.10 下行；大于 0.10 上行；其余中性 |
| V 波动幅度 | 最近 60 个 r 的样本标准差（ddof=1）× sqrt(252) | 不大于 0.35 较低；其余较高 |
| M 收益组织代理 | 最近 60 个 r，`corr(r[:-1], r[1:])`，59 对相邻收益 | 小于 -0.15 反向；大于 0.15 延续；其余接近零 |
| J 跳变集中代理 | 最近 60 个 r 去均值后的平方能量，最大 6 项之和 / 全部之和 | 不大于 0.60 较分散；其余较集中 |
| S 历史稳定度 | 下述四属性日级变化分数 | 不小于 0.75 较稳定；其余较易变 |

S 在过去 20 个交易日变化（21 个相邻日四属性点）上计算。每个日点先按本表窗口计算四属性，再投影：

```text
F_t = (tanh(G_t/.5), tanh((V_t-.35)/.25), M_t, tanh((J_t-.55)/.20))
D = mean_over_20_changes_and_4_traits(abs(F_t - F_(t-1))) / 2
S = exp(-10 * D)
```

窗口重叠使 F 机械地平滑，S 不是未来稳定概率或持续期预测。G 是历史年化 log 增长，不是未来年收益；M 不证明可交易反转；J 不证明新闻事件。

## 不确定性

当前定义为 256 次、长度 5 的联合移动块重采样，使用最近最多 140 个有效收益；每次按原定义重算五属性。对每项有限重采样值报告 10/90 百分位及类别频率：

```text
p(category c) = (count_c + 0.5) / (valid_replicates + 0.5 * number_of_categories)
```

用于复现的 seed 由 `five_traits_v2|code|asof|256` 的 SHA-256 前 8 个字节按 little-endian 生成整数，使用 numpy default_rng。重采样块的起点在 0 至 n-5（含）间均匀选取，每次取 ceil(n/5) 块并截到 n；有效覆盖按标签独立检查。

类别频率仅表示重采样条件倾向，未经真实类别标签校准。重排块可能改变长周期组织与 S，不能称为未来置信区间。若更换种子规则、重采样次数或依赖包数值行为，保存相应版本/参数并验证可复现性。

## 显示

地图 `x = asinh(V/.20)`，`y = asinh(G/.50)`，刻度仍标实际年化值；M 为颜色、J 为圆/菱形、S 为实/虚环，未知使用独立标记。二维分位范围不是联合置信区域。

单图时间谱采用以下固定 0–100 显示映射；这些显示值不是概率，不可比较“哪个属性更好”：

```text
G_display = 50 * (1 + tanh(G/.5))
V_display = 50 * (1 + tanh((V-.35)/.25))
M_display = 50 * (1 + M)
J_display = 100 * J
S_display = 100 * S
```

日期详情保留原始数值、单位、覆盖、输入截止及计算模式；14/30/60 是日历展示范围。仅有 G/V 可计算才有地图坐标，其他属性独立保留。分红再投资、汇率收益与产品结构条款不由这些公式提供。

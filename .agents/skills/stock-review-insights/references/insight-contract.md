# 洞察分析与交付契约 v1

## 行业环境

先输出覆盖和截止，再形成行业判断。分开三类证据：宽基价格、普通行业 ETF 价格、当前股票池中的公司样本。US/HK、不同币种及不同截止分别比较；同一名称不能掩盖差异。

- 行业 ETF 可参考 [State Street 官方 11 个 Select Sector ETF](https://www.ssga.com/us/en/individual/capabilities/equities/sector-investing/select-sector-etfs)：XLB 材料、XLC 通信服务、XLE 能源、XLF 金融、XLI 工业、XLK 信息技术、XLP 必需消费、XLRE 房地产、XLU 公用事业、XLV 医疗、XLY 可选消费。观察范围为美国 S&P 500；存在于批次才能计算，缺失单列。
- AI 价值链分组可重叠，以输入标签/来源/有效期为准；未知行业不凭价格图猜。广度只能称“当前成员样本广度”。股票与 ETF 分开，ETF 的成分不能当成该批次已有完整成员数据。行业地位/头部证据来自业务材料，不能用市值或涨幅单独替代。
- 杠杆、反向及单股 ETF 作为产品持仓单独审查，不当普通行业基准。[SEC 的产品说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-alerts/sec)指出这类产品常有每日目标，多日表现不能简单按指数累计变化乘倍数；具体产品仍核对最新发行人条款，不能仅从代码猜杠杆。

附带脚本定义：`R_n = C_t / C_(t-n) - 1`，n 为 5/20/60 个官方交易日变化，需 n+1 个完整交易日收盘；有内部缺口、尾部过期、未知日历或短历史则该窗口未知。US 宽基参照优先批次内可评分 SPY，缺失再看 VOO；其他市场不套用 US 宽基。

`相对涨幅 = R_股票 - R_参照`，显示为百分点差，保持同市场、同截止、同 n；它不是资金流。样本广度为完整窗口内 R_n>0 的证券数/可评分证券数，等权均值和中位数另报；分母为 0 时未知。各组有重叠、样本并非独立，公司多类股未去重时称证券样本。价格 QFQ 变化不称完整分红再投资的总回报。

行业判断使用原始量和可比变化，保留短中期冲突，不另发明综合分数/胜率。明确顺风/逆风依据、分化、相对变化与反证；覆盖不足时只描述已覆盖行业。与前次比较要求显式基线和相同算法/窗口；首次或同一评估重算不能冒充新趋势信号。

## 持仓事项与自选机会

| 类别 | 判断需要的证据 | 信息不足时 |
| --- | --- | --- |
| 立即退出预警 | 当前持仓核实；用户既定退出规则已触发，或官方重大事实使持有逻辑实质失效；解释影响，并核对最新价格/交易状态。停牌、闭市或价差异常等可行性分别写出 | 优先核查风险，不给已经能立刻卖出的承诺 |
| 优先核查风险 | 可追溯结构变化、行业逆风或可信重大消息线索；明确待验证项 | 保留风险事项、核查路径和覆盖缺口 |
| 重要新消息 | 发行人匹配的新事实或实质修订；利好/利空/混合/未定，正文、公开时间与取得时间可核对 | 只有标题/传闻时保留未核实状态 |
| 值得考虑买入 | 当前未持仓且在自选；可核对的业务/行业背景、价格结构或新事实支持；当前价格及交易状态、失效条件明确。逆风中的例外需说明理由 | 待核查候选；不因缺少其他候选提升等级 |
| 无新增已核实事项 | 明确已检查的范围、时点、渠道及事件去重 | 未检查/源失败不能归入这一类 |

旧描述指标没有经过操作门槛训练，不能把偏上行>70%、G/V 象限、波动很大或一根下跌 K 线直接视为买卖指令。质量初评是研究优先级，不等于价格合理或购买资格。没有用户成本、股数和持有理由时，不推算账户盈亏、仓位集中度或已违反用户止损；可以分析方向及询问必要持有逻辑，继续处理有证据的事项。

盘中判断保存行情时间、取得时间、市场时段/交易状态及价格参考；依赖当下可成交价格的提醒须核对报价新鲜度与价差。复权历史价格和未复权实时报价不可直接做绝对价比较，跨口径需转换证据。新闻从上次已核查截止重叠回查，首次可先查最近 7 个日历天；按实际发布时间判断新旧，不把现在搜到旧报道写成刚发生。

风险重要性、解释置信度、行动紧迫性独立；不用合成分数掩盖不确定性。当前洞察与冻结回看是不同分析，补取得的新事实归属新的信息截止。

## 结构化输出

`insights.json` 至少包含：

```json
{
  "schema_version": "stock_review_insights_v1",
  "insight_run_id": "insight-<uuid>",
  "base_run_id": "actual published run",
  "base_data_run_id": "actual data run",
  "base_report_run_id": "actual report run",
  "baseline_insight_run_id": null,
  "mode": "current_insights or frozen_review",
  "information_cutoff": "ISO 8601 with timezone",
  "market_cutoffs": {},
  "membership": {"observed_at": null, "source": null, "current_verified": false},
  "coverage": {"holdings": {}, "watch_only": {}, "industries": {}, "news": {}},
  "industry_environment": [],
  "holding_items": [],
  "watchlist_items": [],
  "selection": {"selected_ids": [], "excluded": []},
  "status": "complete or partial or failed"
}
```

每条事项包含稳定 `insight_id`、事件/规则版本、证券/发行人、类别、优先级、紧迫性、证据置信度、事实、解释、行业背景、建议及触发/失效条件、反证、未知、相对基线变化、证据引用。引用包含 URL 或包内路径+哈希、数据范围、`published_at` / `received_at` / `checked_at` 与精度；报价另存时间与价格口径。没有未来标签验证时不给数字化胜率。

事件去重使用发行人、事件类型及官方材料/关键事实的稳定关联；修订新增版本。洞察身份包含稳定事件/规则与证券/事实版本，不只使用生成时间或 run ID。洞察运行不改变双页面 `report_run_id`。所有候选保留选择/排除原因；持仓查询失败时，潜在自选买入类别保留“是否未持仓待确认”。

`message.md` 顺序为行业环境 → 持仓预警与消息 → 未持仓自选机会。每条用“什么变了 → 为什么重要 → 证据与反证 → 现在检查/处理什么 → 详情”表达。附源批次、实际可用的冻结页面/详情链接及已查/未查计数；v2 无代码查询参数时写明页面内搜索方法。紧急退出事项不能被一般机会排序或展示数量截断。

补充事实保存到 insight 运行的 `inputs/`，原 run 和共用数据只引用；`manifest.json` 登记全部引用、源码/规则版本、阶段状态、真实查询预算/耗时及错误，独立分享时物化引用并校验。纯回看不取新数据；缺最新行情/新闻的技能演练只验证流程，不算实际实时预警或效果验证。

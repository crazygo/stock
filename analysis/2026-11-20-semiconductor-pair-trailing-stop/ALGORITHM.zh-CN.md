# SOXL / SOXS 五分钟第三次确认策略 · 算法与云端复现

版本：2026-11-21。参考策略与历史账本对应代码提交 `0fa0e73`。本文约定盘前、常规盘、盘后和夜盘均运行，做多方向买 SOXL，做空方向买 SOXS，两只都是买入 ETF。每个时点只允许一个方向。所有价格和金额单位为美元。

**迁移对象是最后一次比较的固定金额模拟方案**：前两次只在纸面账户买，第三次也在纸面成交且通过涨幅门槛时，另一套模拟资金账户才买 $1,000。费用是每次买入、卖出各 $2.50。下表的 0.8333% 是从 $600 版本保留的入场参数。$1,000 仓位本身的往返手续费率为 0.5%。两者在 11 月选中同样 8 笔，在 10 月选出了不同的交易。

### 二、参数与数据时间

| 项目 | 固定值与含义 |
|---|---|
| 趋势窗口 | 最新 5 根已完成 K 线；评分另用 12 根，窗口必须时间连续 |
| 打分模型 | 七特征标准化逻辑回归。三个阶段分别要求分数 ≥ q50、q75、q90 |
| 三档纸面账户 | 初始 $1,000，各档证券金额依次 $100、$200、$300；每个纸面成交单独收费。同一轮最多三笔 |
| 最终模拟账户 | 初始 $1,400；证券金额固定 $1,000，买入时可用现金至少 $1,002.50；允许分数股，卖出所得立即可用 |
| 第三档额外门槛 | 最新已完成根收盘相对第二档实际纸面买价，涨幅 ≥ 5/600，即 1/120。比较时保留精度 |
| 退出 | 各笔独立 +8% 固定止盈；从各自已走过的最高价回撤 3% 止损 |
| 交易次数 | 每 5 分钟检查，按现金与持仓约束决定；没有每日上限；跨正常场次和交易日可持仓 |
| 历史根内顺序 | 主路径 O→L→H→C（OLHC）。敏感性路径 O→H→L→C（OHLC）。两次从零重跑全部状态 |

**时间索引。** 第 `i` 根的开盘时间记作 `t[i]`。在 `t[i]+1秒` 做决定，此时最新已完成根是 `i-1`；`C[i-1]` 指该根收盘。参考回放在下一根连续的开盘 `O[i+1]` 成交。如 08:25–08:30 的 K 线于 08:30:01 可用，最早模拟成交是 08:35:00。08:30–08:35 的高低收不参与 08:30:01 的判断。处理挂单和跳空可以使用当前开盘成交事件；仅收到完整 K 线的云端输入，应在收根后按历史事件时间回放这些步骤。

**数据契约。** 每只 ETF 每根需要 `symbol, start_at, end_at, available_at, open, high, low, close, volume, price_basis`。用带时区的时间戳对齐两只 ETF，内部用 UTC，交易日与展示时间用 `America/New_York`。参考数据为未复权 `NONE`，价格有效且为正、成交量为正、根长 5 分钟，历史可用时刻设为 `end_at+1秒`。夜盘 20:00–04:00，盘前 04:00–09:30，常规盘 09:30–16:00，盘后 16:00–20:00；交易日从前一自然日 20:00 ET 开始，周日夜盘归周一。14 日验收使用交易所日历的完整交易日，每个交易日 288 根，每只共 4,032 根。

休市断点让特征重新暖机，基础趋势至少需要 5 根、评分需要 12 根。只预约相隔恰好 5 分钟的下一根开盘；休市期间已有仓位带到下一可用开盘并检查跳空。参考数据读取器拒绝缺根、零成交量或跨除息等公司行动的样本，分块研究另外限定完整常规交易日。云端扩展到半日市、公司行动日或缺失的持仓路径时，须先补上相应日历、调整或真实成交记录。未知退出留待补齐，避免用填充价格结算。

### 三、第一层：基础五根趋势与选方向

对本标的任意一个连续窗口，按时间从旧到新计算下式。每一根先把该根最高价纳入峰值，再用该根最低价检查；这是入场筛选的固定计算顺序，两种根内路径都使用它。

```text
peak = 0
drawdown = 0
blocked = false
对窗口的每根 (O,H,L,C)：
    peak = max(peak, H)
    drawdown = max(drawdown, 1 - L / peak)
    如果 L <= 0.97 * peak + 1e-10，blocked = true
gain = 最后一根收盘 / 第一根开盘 - 1
passed = 最后一根收盘 > 第一根开盘 且 blocked 为 false
```

上涨按窗口首开与末收计算，中间允许下跌。对 SOXL 和 SOXS 各算最近 5 根。基础策略空仓且有合格标的时，选择 `gain` 最大者；涨幅完全相同则按代码升序，SOXL 在先。预约下一开盘建立一笔基础虚拟持仓，沿用 +8% / 3% 退出，持仓期间忽略新基础买点。即使下一层分数太低，基础持仓仍照常成交、占位、退出；该时点不会改选另一只。这样得到的基础买点和方向是下一层首档候选。基础回放以单位本金、买卖各 0.10% 做账，这只影响它的收益标签和账面金额，后两层均按 $2.50 固定成交费。

### 四、七特征评分

以下 `W5`、`W12` 均截止在 `i-1`。所有涨跌幅输入使用小数（1% 写为 0.01）。对正在评估的 ETF 计算前六项；第七项取另一只 ETF 的同步行情。

| 顺序 | 冻结字段 | 定义 |
|---:|---|---|
| 1 | return5 | 本标的 W5 的 gain |
| 2 | return12 | 本标的 W12 的 gain |
| 3 | drawdown5 | 本标的 W5 按第三节递推的最大回撤 |
| 4 | drawdown12 | 本标的 W12 按同式求最大回撤 |
| 5 | close_efficiency12 | W12 末收与首收差的绝对值，除以 11 个相邻收盘变化绝对值之和；分母为零取 0 |
| 6 | close_location12 | (末收 − 窗口最低 L) / (窗口最高 H − 窗口最低 L)；分母为零取 0.5 |
| 7 | inverse_return5 | 配对 ETF 的 W5 末收 / W5 首开 − 1 |

按上表顺序组成 `x`。逐元素标准化 `z=(x−mean)/scale`，取 `score=1/(1+exp(−(intercept+dot(z,weights))))`。入场与加仓均比较原始双精度分数。q50、q75、q90 是校准样本分数的分位数；其数值代表历史门槛，不能解读为 50%、75%、90% 的交易胜率。

```json
{
  "mean": [0.019022821372074714, 0.013765026521156905, 0.016743070383677974, 0.03139001989178687, 0.34875049792236523, 0.8142262575884199, -0.018806029844609575],
  "scale": [0.012033790653352904, 0.025951345120973184, 0.007003323320394936, 0.02041320709960977, 0.2103821986818273, 0.18574594508836859, 0.012341986080727613],
  "weights": [0.052780217859599465, -0.019030693892349862, -0.002906409540096203, -0.22822017272007514, -0.08317849319819563, -0.1768961497886482, -0.41749963778653243],
  "intercept": -0.7210864738816449,
  "q50": 0.2937563838851365,
  "q75": 0.3457443924756659,
  "q90": 0.37297994736375345
}
```

模型于 2026-07-27 至 08-14 从 133 个已平仓样本拟合，08-17 至 08-28 用 48 个可评分买点校准。训练目标是基础策略按其历史费用标签是否净盈利；$1,000 最终账户单独结算。模型输入、系数、阈值的原件为 `entry_filters/shadow_freeze.json`，SHA-256 为 `ed4c7604202031a66a5c969b5e004467f9d11c100ef2784ded806441ff9abe34`。复现这个版本可直接加载该文件。

### 五、第二层：三档纸面账户

纸面现金、持仓、待成交单独立于基础层。仅在纸面空仓、当时有基础买点、同一标的分数 ≥ q50 时，预约纸面首档 $100。对同一轮，将首次**决策**索引记 `first`，最近一次已成交档的**决策**索引记 `last`，其实际成交索引记 `fill`。每档有自己的止盈、峰值与移动止损。

已成交档的数量决定下一档。第二档 $200 要求当前分数 ≥ q75；第三档 $300 要求当前分数 ≥ q90。每一档预约时须同时满足以下条件。

1. 首档还持有，方向沿用首档；当前 `i − fill >= 1`。预约后在 `i+1` 开盘成交，因此两次成交最短间隔为 10 分钟。
2. 本标的最新 W5 通过第三节测试，且 `C[i-1] > C[last-1]`。
3. 从 `first-5` 至 `i-1`（两端含在内）的整段行情连续，且整段也通过第三节测试。判断起点固定在**首档信号的前五根起点**。
4. 有下一连续开盘。到该开盘先处理已有仓位的跳空退出，再检查首档是否还在；首档已平就取消这次加仓。纸面现金足以支付本档证券金额加 $2.50 才成交。

任一时刻只维护一轮。只要还有一档持仓，同一轮就占着方向。首档退出后即停止新增档，剩余档继续各自退出；所有档平仓后重新等待基础买点。档数累计按本轮已经成交的档计算：例如第二档先退出、第一档仍持有，下一档仍是第三档。未成交的预约不占档数。

### 六、第三层：$1,000 模拟买入与退出

在第三档**决策时**记录 `signal_close=C[i-1]` 以及同轮第二档实际纸面成交价 `p2`。用 `(signal_close-p2)*600 >= 5*p2 - 1e-9` 判定额外门槛。这里的 600 固定保留自原策略，实际买入额为 $1,000。该门槛只控制最终账户，纸面第三档照常运行。当第三档随后在预约开盘实际纸面成交，门槛已通过、最终账户空仓且现金 ≥ $1,002.50 时，最终账户在该开盘同价买一次。回测假定两边同步成交、没有额外路由延迟。每轮最多这一次机会，即使最终账户跳过，也继续维护纸面账户原有状态。

```text
入场价 P，数量 Q = 1000 / P
买入后现金减少 1000 + 2.50
初始 peak = P，固定 target = 1.08 * P
对入场后按顺序到达的价格 x：
    stop = 0.97 * peak
    若 x <= stop + 1e-10：按 stop 退出；若是新根开盘跳过 stop，按该开盘价退出
    否则若 x >= target - 1e-10：按 target 退出；若是新根开盘跳过 target，按该开盘价退出
    否则 peak = max(peak, x)
卖出后现金增加 Q * 卖出价 − 2.50
已平净盈亏 = Q * (卖出价 − P) − 5.00
```

止盈与止损互斥，一边成交即结束本笔。触发移动止损也可能净盈利。计算保留全精度，展示才取美分。样本末若仍持仓，以最后一根收盘盯市，费用只扣已经发生的买入费，单列未平。收益率分母为最终账户初始资金 $1,400。

**每根处理顺序。** 在 `t[i]` 的开盘，先让各层处理已有仓位的开盘退出，并按各层规则执行上一根预约的订单。基础与纸面分别推进；当根若有纸面第三次成交，再向最终账户传递该成交及之前算好的门槛。在 `t[i]+1秒` 只用截止 `i-1` 的输入形成下一次预约。最后再按所选根内路径处理第 `i` 根开盘后的高、低、收及持仓退出。如果首档在这一步才平仓，下一开盘会取消已预约的加仓。参考代码可先完整计算基础层和纸面层再驱动最终层；云端逐事件实现时，向下游传递该时刻已发生的信号或成交即可。

### 七、迁移验收与运行边界

| 主路径实例（美东 2026-11-03） | 纸面操作与最终账户结果 |
|---|---|
| 跳过的 SOXL | 04:10 第一档成交 $71.42，04:20 第二档 $71.77。04:25:01 第三档打分 0.613675，已知收盘 $71.60。04:30 第三档按 $71.56 纸面成交，最终账户因额外门槛跳过。 |
| 买入后亏损的 SOXL | 07:30 第一档成交 $73.865，07:40 第二档 $73.9546。08:30:01 第三档打分 0.411070，已知收盘 $76.10。08:35 最终账户按 $76.36 买入 $1,000，移动止损以 $74.142435 退出，净亏 $34.04。 |

**接到云端行情时需要保存的状态。** 至少保留模型版本、最后处理的 UTC 根、两只 ETF 的同步窗口、基础层持仓及预约、纸面现金/本轮各档/首档锚定窗口、最终账户现金/持仓，以及每笔买价、数量、最高价、止盈价。还要保存上一档决策收盘价、第二档成交价、已经确定的第三档门槛结果和待执行时刻。重启可从相同历史起点重放，或从完整检查点续跑。只取最新 12 根可以恢复评分，但无法恢复长窗口回撤、跨日持仓或两个账户的历史现金。对同一版本、账户、标的、档位、决策 UTC 与成交事件去重，防止重复推送或服务重启导致重复入账。

**运行范围。** 随包程序为一次性历史模拟与验收。若云端只有收完的 5 分钟 K 线，根内高低先后及实际成交不可观察；两种路径是模拟假设。实时更新追踪止损需要有先后顺序的行情或券商原生支持，并以真实回报处理成交、撤余单及可用资金；不同场次的订单能力、分数股、点差、滑点和真实结算需以所接通道为准。云端实时订阅、常驻任务、存储和真实订单接口属于后续接入工程。

**效果边界。** 主路径的 $119.13 属于已查看的 14 个交易日。相同买入金额与门槛在较早的 10 月检查期 7 买净亏 $49.22，另一次用年初拟合模型的 91 日历史迁移检验 22 买净亏 $154.68。这套配置用于复现与模拟观察，尚未通过研究的跨时段晋级标准。

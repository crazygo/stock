## 数学模型

横轴是风险幅度，纵轴是价格路径不连续与阶段变化。8 维指标分别是年化波动、收盘回撤、尾部亏损、日振幅、大波动集中度、隔夜能量占比、漂移变化、方向碎片化。上涨/下跌方向独立显示。

每维采用连续 Pugh：`z_j=tanh((m_j-d_j)/s_j)`；两组各自加权得到 `X,Y`。基准是固定绝对边界，增加一只自选不会移动其他证券的位置。

联合日序列做 512 次移动时间块重采样，另对两组权重取 Dirichlet 先验。四项概率是 `p_k=(N_k+0.5)/(512+2)`，全部归属质量和为 1。坐标表示原始测量；10–90% 坐标范围表示重采样的不确定性。权重、基准和块长尚未通过人工类型标签校准，完整数值与假设见协议。

60 日画像按周计算，保留近 16 个观察时点；描述性平滑为 `p_t=0.65q_t+0.35p_(t-1)`，大幅状态变化或缺失立即重置。20/120 日窗口单独评分。窗口、平滑概率、原始概率与敏感性版本全部保留；不把重叠观察当独立证据。

## 从画像到策略

可以把每种策略对四类的适配矩阵记为 `S[a,k]`，再计算 `Fit(a,i,t)=sum_k p[i,t,k] S[a,k]`。这是策略适配度，只有后续在未参与定规则的数据上检验收益、回撤、成本与供给，才可谈是否优于基准。当前尚未拟合 `S` 或验证策略效果。持有候选还需要同时检查业务质量、估值、上行方向和基金产品结构。

| 类型倾向 | 后续应检验的策略假设 | 需另外验证 |
|---|---|---|
| 平稳累积 | 低频持有、再平衡 | 估值、质量变化、回撤承受度 |
| 波动上行 | 风险仓位、核心仓与波段 | 波段规则是否胜过持有，交易成本 |
| 事件台阶 | 持有明确的事件假设 | 实际事件日历、预期差、跳空风险 |
| 高波动反转 | 状态切换复核、缩小风险预算 | 反转识别是否及时，误判成本 |

杠杆产品另加结构约束，不能直接继承其基础指数的持有策略。例如 TQQQ 的发行人目标为 Nasdaq-100 **每日** 3 倍，跨日收益可能明显偏离累计指数收益的 3 倍。[ProShares 官方说明](https://www.proshares.com/our-etfs/leveraged-and-inverse/tqqq)。它用于解释产品结构，本次不在实际自选中，未添加到地图。

## 查看与复算

直接打开 `index.html`，或通过现有 8768 静态服务进入 `/analysis/ai_trend_quadrant_v1/`。页面完全自包含；日期、观察窗口、范围与证券选择均在本地改变显示，不修改模型。证券名称可能重叠时仅减少标签，所有已评分点都保留，可从下拉框定位。

保留当前成员/行情的复算：

```sh
python3 analysis/ai_trend_quadrant_v1/build.py --as-of 2026-10-06
python3 analysis/ai_trend_quadrant_v1/audit.py
python3 analysis/ai_trend_quadrant_v1/render.py
```

刷新成员和行情时，先选择各市场均已完成的日线日期，再串行执行：

```sh
python3 analysis/ai_trend_quadrant_v1/capture.py
python3 analysis/ai_trend_quadrant_v1/acquire.py --as-of 2026-10-06 --budget 360
python3 analysis/ai_trend_quadrant_v1/build.py --as-of 2026-10-06
python3 analysis/ai_trend_quadrant_v1/audit.py
python3 analysis/ai_trend_quadrant_v1/render.py
```

这些日期是本次示例，未来刷新应显式换为已完成日期。采集只读行情与自选分组，不查询账户、不执行交易。原始 Parquet 位于被 Git 忽略的 `market_data/trend_quadrant_v1/daily/`；按 Local→R2→OpenD 获取，不自动上传 R2。需要本仓库本地行情、日历、现有质量评级文件与 OpenD 权限，脚本不宣称云端能直接访问本机 OpenD。

当前采用整段单来源前复权行情；日级覆盖按美股 Nasdaq、港股 2026 官方休市日核验，不混拼不同调整口径。所有历史画像均使用当前成员与本次取得的复权价格，属于历史描述回看；不是历史 PIT 成员回测。

# 五指标三周期叠加视图

视图版本：five_traits_overlay_v1，2026-10-07。

根据用户要求，把原来按周期分栏的15张图改为按指标排列的5张图。每张图包含最近14、30、60个日历天的三条历史曲线，使用同一纵轴、不同线型和图例复选框。当前证券、原模型、指标值、归属概率、成员及数据截止保持原快照；只重新渲染，不重新获取行情或拟合模型。

两个横轴选项：

- **周期进度（默认）**：每个周期的起点映射到0%，行情截止映射到100%。x=(date−period_start)/(as_of−period_start)。用来比较不同回看长度的走势形状；同一x不代表同一实际日期，也不代表同一每天变化速度。缺失断线，周末和假日的真实日历间隔保留。
- **实际时间／距截止日**：所有曲线共同使用60天日历范围，x=(date−start_60)/(as_of−start_60)。14/30/60是嵌套区间，重合日期的值相同。以不同线宽、明度和线型保留各周期，不人为偏移价格或指标。

包含截止日的14/30/60天，对应从13/29/59天前开始。两个选项均保留真实每日值；三条线截止于同一个指标当前值，不制造不同的算法窗口或概率。当前值和10–90%重采样范围仍在详情表中。

纵轴始终根据该证券最近60天全部已知指标点设定，隐藏任意周期不会自动拉伸纵轴。所有周期隐藏时显示选择提示；行情不足时保留五张空图和具体缺失状态，不补零。原三栏页面及交付记录保存在当前run_id的views/three_columns目录。

工程验证检查每指标三条真实来源曲线、日历起止、共用纵轴、两种横轴映射、图例操作、缺失状态、键盘关闭、地图筛选坐标以及桌面／手机和深色模式。修订后的交付清单以view_revision和文件SHA区分视图；数据计算run_id保持不变。

# 自选五属性分布地图与浮动时间谱

打开 [index.html](index.html)，点击地图点，或用证券选择框打开右侧浮层。地图重叠的证券会列出选择按钮；关闭按钮和 Escape 可返回地图。侧栏现在只有一张时间谱：横轴为实际日期，五个标签G/V/M/J/S分别是一条线，每个有效计算结果都有标记。图例复选框可显示或隐藏标签，点击图上的点或选择计算日期能查看该日各标签的原始值与单位。

**14 / 30 / 60 是最近的日历天，包含行情截止日。** 三个按钮只选择回看范围，不改变标签算法，不生成三条周期线，也不把横轴转换成进度。截止2026-10-06时，三个起点分别为9月23日、9月7日、8月8日。未计算／未知不补点，未知记录断线；周末和假日保留真实日历间隔。

五标签量纲不同，叠加图采用统一0–100的固定显示映射：G=50×(1+tanh(G/.5))，V=50×(1+tanh((V−.35)/.25))，M=50×(1+M)，J=100×J，S=100×S。这个尺度不随股票、回看范围或显隐改变；不是概率或综合评级，各标签高低不能直接比较好坏。日期详情保留原始量纲，截止日的重采样范围与模型归属频率仍在独立详情中。本次点由当时可知行情的历史回算生成，不代表那些日期曾实时运行。当前修订见 [VIEW_NOTES.md](VIEW_NOTES.md)；PROTOCOL.md保留模型计算时的冻结登记，旧排版不再是当前界面。

## 地图上的五个标签

| 标签 | 展示通道 | 本版计算 |
| --- | --- | --- |
| G 长期方向 | 纵轴 | 120交易日收盘log收益均值×252 |
| V 波动幅度 | 横轴 | 60交易日收盘log收益样本标准差×√252 |
| M 收益组织 | 颜色 | 60交易日相邻收益相关；负、近零、正 |
| J 跳变集中 | 圆或菱形 | 最大10%去均值收益平方的能量占比 |
| S 历史稳定 | 实、虚或点环 | 过去20交易日四个属性的归一变化分数 |

两条地图轴使用非线性 asinh 压缩，刻度显示指标的实际年化百分比；不改变排序与分类阈值。筛选证券不会移动坐标。选中浅框表示G/V各自的10–90%重采样范围，不能解读成联合置信区域。

这是可复算的描述性探索。G不是未来收益预测；M没有证明可交易的均值回归；J没有做事件归因；S受重叠窗口影响，不是未来状态稳定的概率。当前归属频率由256次5日联合移动块重采样得到，未经人工属性标签校准。业务质量沿用独立快照，质量A+/A筛选不套用于ETF。完整公式、窗口和缺失规则见 [PROTOCOL.md](PROTOCOL.md)。

## 重建与验证

从仓库根目录执行：

```bash
python3 analysis/ai_trend_quadrant_v2/build.py
python3 analysis/ai_trend_quadrant_v2/verify.py
python3 analysis/ai_trend_quadrant_v2/render.py
```

重建需v1的results.json与其登记的本地Parquet输入。本版不下载、不拼接来源、不上传R2，不接券商交易。index.html已嵌入本次指标，可单独打开；原始OHLC没有嵌入或复制到Git。

`verify.py`检查窗口边界、独立公式、价格缩放不变性、截止后数据隔离、交易日缺失、重采样复现性及全部输入哈希；本次独立复算649个日期点，核对163份行情文件。证据在 [model_verification.json](model_verification.json)。

当前视图的离线验证命令为`node analysis/ai_trend_quadrant_v2/verify_timeline.cjs`。它检查实际日期映射、每个有效结果的标记、稀疏计算记录、缺失断线、原始值保留、固定尺度、回看裁切、几何边界及嵌入脚本语法，报告在 [timeline_verification.json](timeline_verification.json)。另保存与页面使用同一个SVG生成器的桌面／窄屏静态预览；这不等同于真实浏览器CSS与交互验收。

内置浏览器安全策略阻止自动访问本地file://页面；当前修订未重新做实时浏览器验收，须手动刷新现有标签。此前三周期叠加版的浏览器验证报告与脚本留在run_id的views/five_traits_overlay_v1目录，不能作为当前版的通过证据。当前browser_verification.json只记录此限制。工程检查不能提升为预测或策略效果验证。

本次数据与页面哈希见delivery_manifest.json；run_id目录保留该次计算快照。

1. 突发催化日（Catalyst Day）打破“早盘陷阱” 在常规震荡日，早盘 10:30 入场往往胜率垫底；但在单边大阳线突破日（如 9月2日全天 50.1%、9月18日全天 47.1%），早盘 10:30 与 11:30 的达成率会同步飙升至 50%~60%+。单日矩阵让我们清晰分辨出哪些交易日是“早盘即可猛烈追击的系统性起爆日”。
2. 震荡阴跌日“尾盘 16:00 永远是最后防线” 在盘中冲高回落的冲天炮行情中（如 9月8日、9月14日），早盘 10:30 买入的 3 日达成率甚至砸到 15%~18%，而尾盘 16:00 入场依然能保住 30% 以上的防守胜率。未确认单日大单流入前，收盘前买入安全边际永远更高。
3. 最新日期未决窗口实时追踪（In-Flight 状态） 9月21日至9月23日/24日的买点由于尚未走满 3 个交易日（21 小时），表格中展示的是“已提前达成 5% 的样本比例”（带黄色角标）。随着后续交易小时推进，已达成的确定性利润会沉淀为闭环结果。
4. 重大实证：首小时（10:30）锚定效应与日内动态均值 若某天 10:30 达成率低（<30%），后续时段胜率极低（均值仅 25.3%）；若 10:30 高（≥50%），后续高位维持（均值达 57.5%），相关系数 r=0.788，分化极差达 +32.2%！开盘到当时的累计均值对下午及尾盘预测力更是高达 r=0.886 ~ 0.941。

聚类方法 2 的量化结论与风控实操规则 (Actionable Rules)

  • 横轴定义：显示当前选定月份的所有交易日（列数 = 当月交易日天数）；最右侧为该选定月份内该时段的整体达成率。
  • 格子定义：每一格显示当前选定分组股票在该交易日、该小时的总入场样本数 N 与达标数 T（达成率 = T / N）。
  • 黄色角标说明：对于最新几天（如 9月21日~9月24日），由于距今尚不足 3 个交易日，角标标注其为进行中（In-Flight），显示的为“截至当前已提前触碰 5% 的强势股胜率”。
  • 规则 1（起爆日双击买入）：当某一日各小时达成率普遍高于 45%（如 9/2 与 9/18），代表市场进入宽幅放量多头态，次日开盘 10:30~11:30 可积极顺势开仓。
  • 规则 2（弱市日只看 16:00）：在单日达成率低于 25% 的弱势日（如 9/8），绝不可早盘低吸抄底，只能在 16:00 收盘确认缩量抗跌后试仓。
  • 规则 3（首小时闸门过滤 · Opening Bell Gate）：全量 118 个闭环交易日实证显示，10:30 首时段达成率与后续时段均值相关系数高达 r=0.788（T2组 r=0.704）。当 10:30 达成率 < 30% 时，后续时段胜率期望跌至 25.3%（一票否决/观望）；当 10:30 达成率 ≥ 50% 时，后续时段胜率高达 57.5%，胜率分化极差达 +32.2%！可将 10:30 设立为当日入场总闸门。
  • 规则 4（日内累积置信度乘数 · Cumulative Momentum Factor）：开盘至时点 t 的平均达成率对后续时段预测力极高：11:30 累计均值预测下午盘（12:30~16:00）胜率 r=0.886；13:30 累计均值预测尾盘（14:30~16:00）胜率高达 r=0.941！可直接作为盘中任意时段买入信号的环境置信度乘数。

# 数据源口径核查 · 2026-10-05

当前默认为v3.1：完整同源Futu NONE日线与动作审计已终止，日线截至10月2日，当前可评分3,663/5,261。下述Massive缺日/混合批次问题属于保留的v1/v2；不再是当前v3的行情截止。v3不与这些旧源拼接。

本次核查保留 v1 / v2 已运行的全部价格模型与失败记录，不改变原始数字。模型数值校准、概率期限一致和工程测试均不能消除下列数据限制。

1. 本地 `market_data/us/<date>/grouped.json.gz` 的原生响应是 Massive grouped daily，`adjusted=true`。它代表拆股调整，**不代表股息调整**，也不是 Futu QFQ。归档各日来自不同抓取批次，拆股因子尚未统一核对。
2. Massive 的 grouped daily 文档只定义交易日的 OHLC，并未承诺仅限 09:30–16:00 ET。官方 extended-hours 文档说明聚合端点没有 session 参数，盘外成交按成交条件决定是否更新 OHLC。因而目前的日 High 触及只能称 **提供商日聚合触及探索标签**；原协议希望检验的常规盘标签尚未由真实分钟 / 交易数据验证。不能用名称、旧 AGENTS 注释或单只股票价格相符替代该核验。
3. 本地最新完整广池日归档是 2026-09-29。2026-09-30、10-01、10-02 缺失。10-02 的 OpenD 快照已覆盖 5,261 个候选，但不能填补中间日线，也不能把 09-29 的模型估计改名为 10-02 / 当下概率。
4. 快照 `last_price` 是未复权报价；历史高峰是混合批次拆股调整价。报告中的最新报价 / 旧高峰比值为待公司行动核对的参考，阶段仍注明历史截止。盘前、盘后和夜盘字段独立保留。
5. Nasdaq 当前证券目录不是历史 PIT 目录；名称分类会包含待核验的基金、信托或壳公司。SEC 当前 ticker / SIC 和 OpenD trust 字段是当前身份核验，不能证明历史身份。历史失败不得因此事后删除。
6. SEC XBRL frame 仅用于唯一精确名称的当前 CIK 映射。财务历史输入使用 companyfacts 中 `filed < 决定日` 的记录，并以 accession 追溯；不把 frame 的最新数值回填过去。

来源：[Massive grouped daily](https://massive.com/docs/rest/stocks/aggregates/daily-market-summary)、[Massive extended hours](https://massive.com/knowledge-base/article/market-data-outside-of-normal-hours)、[Massive adjustment FAQ](https://massive.com/knowledge-base/categories/faq)、[Futu market snapshot](https://openapi.futunn.com/futu-api-doc/quote/get-market-snapshot.html)、[SEC API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)。

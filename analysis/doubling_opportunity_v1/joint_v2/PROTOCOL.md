# 首次翻倍时间与公司质量联合模型 v2 · 预登记

2026-10-05。v1 已暴露历史开发结果保留；新版本是开发修订，不称独立验证。目标仍为广池寻找好公司、热点、60 日翻倍概率 >80%，不降低目标。

## 首次触及时间模型

每个股票日标签为三类：0=60 个日历日未触及参考收盘价×1.002×2；1=首次触及在第31–60日；2=首次触及在前30日。标签必须完整成熟、无缺失且公司行动已知质量符合 v1 数据规则。若 y30=1 但 y60=0 是数据错误，拒绝训练。

同一个模型生成 q0,q1,q2，联合 temperature scaling 校准后仍是三类概率分布：P30=q2，P60=q1+q2。因此 0≤P30≤P60≤1 来自事件定义。它修复事件一致性，不保证预测有效。

固定两算法：标准化 multinomial LogisticRegression(C=1,max_iter=500)；HistGradientBoostingClassifier(max_iter=120,max_leaf_nodes=15,min_samples_leaf=100,l2=2)。每个模型使用 FrozenEstimator + CalibratedClassifierCV(method=temperature) 在独立时间块校准。训练、校准和选择均使用60日完整成熟标签，不用随机 CV 打乱时间。

沿用 v1 评价月份、价差成本、183日历日特征、60日股票信号冷却、校准块与评价月时间隔离。训练 / 校准中每个类别至少20例；校准至少200例；选择至少200例。模型只用此前20日选择块的30/60日 Brier 均值择优。两个算法、原始概率、两期限校准概率、月前选择策略全部保存。

先运行仅价格 / 量能的事件模型，作为新目标数学一致性的对照。财务与行业版使用独立数据快照与命名，不能给价格对照改名为好公司联合结果。全池财报获取任务终止并登记完整覆盖 / 缺失清单后，再冻结联合版评价；不以下载先后形成的字母顺序子集宣布联合模型效果。

## 财务字段的可知时点

SEC companyfacts 只用当日之前 filed 的记录（同日 filing conservatively next-calendar-day available）。以报告原始 accession 和具体 start/end 为来源。按标准概念优先级取值；优先使用决定时点可见的最新修订，不能读未来修订。

流量指标必须匹配同一财务期间。只有已披露累计年初至今和上一累计期恰好匹配时，才相减生成真实季度；全年减前三季度可以生成Q4。原始季度优先；跨期不匹配或累计缺失保持未知。TTM 需要4个连续季度，按实际财务起止日期对齐，不将累计半年度直接当季度，也不重复计算直接季度和差分季度。

特征包括最近季度 / TTM 的营收、营收同比 / 环比、毛利、经营利润、净利润、经营现金流、现金、净资产、流动性、财务期间年龄和缺失状态。最近报表期间距决定日超过183日标过期；旧财务只能作为同比对照，不能冒充最近六个月新价值表现。金融机构、外币、IFRS或自定义缺失标签单列，不把缺失视为好或坏公司。

质量层：增长且盈利 / 现金流健康、改善中的转型、未证明经营质量。报告提供指标原值与出处；“好公司”必要条件不是股价涨幅保证。阈值在联合版本训练前登记，不以评价标签事后改资格。

## 热度

保留当时的市场相对强弱与成交量放大，进一步按 SEC SIC 行业横截面量价判断行业热度。当前 SIC 回溯是有偏元数据，不能称历史 PIT；过去公开时间完整的业务公告 / 发行人催化才可形成业务热点证据。业务热点与价格热度分别展示，单有量价不能称业务已核验。

## 证据门禁

80% 门槛及样本 / 日期 / 不确定性要求沿用 v1。非重叠信号 precision、未知、机会供给、同股基准、增量、股票 / 时间相关性区间、可靠性分箱均保留；不把日行数或跨算法重复当独立机会。价格一致性与工程检查不提升为80%有效性。PIT、公司行动、当前时效、联合效果和独立观察缺口继续公开。

来源：[SEC API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)、[sklearn 概率校准](https://scikit-learn.org/stable/modules/calibration.html)。

## 财务必要条件登记（训练前）

“增长且经营健康”需同时：最近财务期间≤183日、TTM 营收≥1000万美元、单季度同比营收>10%、毛利率≥20%、流动比率≥1、净资产>0，且本季度经营利润率>0或TTM经营现金流/营收>0。增长与毛利达到但经营条件不足者标为“增长、经营健康尚未证明”，继续保留在全池；不将其称已通过好公司门禁。单位、期间、TTM或外币缺失均不通过必要条件。

## 联合实验固定方案（财务训练前登记）

版本 `joint_v2_financial_market_heat`。训练 / 校准 / 选择仍使用全部价格可评分股票日，加入上述16项财務特征及缺失状态。LogisticRegression 的中位数插补及缺失指示只在训练块拟合；HGB 原生处理 NaN。金融业、外币与无法映射的公司保留，缺失不冒充健康。

行业为当前 SEC SIC 前两位。每个决定日对价格合格同业取 ret20、相对 SPY 的 rs20、5/20日均量比的中位数，至少5个真实成员；另有成员数与缺失状态。元数据为当前回溯，不能称历史 PIT。

发出信号必须在当日同时通过：概率严格>80%、当时财务“增长且经营健康”、个股 ret20>10%、rs20>5%、量比≥1.1、同业至少5个、同业 rs20>3%、同业量比≥1.05。冷却与期限同价格对照。所有原始预测保留；必要条件仅在当时决定发出资格，不以未来标签删除失败。没有公开催化历史覆盖，不把这个实验称为业务公告联合模型。

两项全注册 SEC 获取任务终止后才冻结覆盖；未映射、下载失败、不支持财务均进入缺失清单。这个实验使用现有 Massive 日聚合探索标签，常规盘 scope 尚未核验；即使数值门禁通过，当前证券目录、公司行动、时段、独立验证缺口仍阻止部署资格。见 [数据源核查](../SOURCE_AUDIT.md)。

唯一名称取得的 CIK 还需 SEC submissions 当前 ticker 确认；未确认时财务与行业输入保持缺失，原股票价格记录仍保留。该身份核验仍是当前映射，不等于过去每个股票日的 PIT 发行人证明。

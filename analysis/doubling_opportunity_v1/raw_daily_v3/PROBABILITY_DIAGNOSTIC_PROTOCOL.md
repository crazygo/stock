# 已冻结概率的事后诊断 · 2026-10-05

登记在实际运行本诊断之前。v3.1 完整训练和六个月评价已经完成，当前全池仅 SDEV 的60日估计超过80%，但其公司经营质量与行业热度没有通过。这不是新增的独立验证，也不改变原实验的有效信号。

只读取 `latest_backtest.json` 指向的不可变预测、模型源、配置和原始标签。对全部价格可评分候选展示已有预测的固定概率区间、成熟与未知数量、股票与日期供给。原来的当时公司质量/行业条件仍是主信号门禁；去掉该门禁的行仅用于解释数值估计，不能当作合格公司、有效信号或部署资格。

高估计诊断严格沿用原来的 `probability > 0.8`、同股60日历日冷却、全部4–9月、月前算法选择。两固定算法与月前选择分别统计，禁止跨算法累加。原配置、阈值、模型、特征、标签和主回测产物均不改。缺失/未成熟保留，报告TP/(TP+FP)、TP/全部、同股基准、股票簇与周簇区间；每日概率行与重叠未来窗口不能视为独立机会。

输出单独放在 `diagnostics/<training_key>/`，原始预测与评价代码的 SHA 留在诊断 lineage。该报告不能将任何历史后验高值股票子集登记为未来合格股票。SDEV等当前估计也不会因此变成当下真实入场概率。

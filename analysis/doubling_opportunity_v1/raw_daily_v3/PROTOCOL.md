# 原始日线与拆股事件实验 v3 · 数据获取前登记

2026-10-05。目标仍是广池寻找好公司、热点、60日翻倍概率>80%，不降低概率或证据要求。v1、v2模型及全部失败/未知保留。v3不得把新版数据获取、工程检查或当前报价当作效果通过。

## 为什么增加数据路线

当前Massive广池日线止于09-29，本机无源凭证，R2没有09-30、10-01、10-02。OpenD的`request_history_kline`试验表明，新股票的近30日日线和60分钟请求均实际占用历史额度，不能依据旧说明全池免费调用。

另一个官方接口`get_cur_kline`在订阅K_DAY后可返回最近最多1000根。MXL/AAT/AKR实际各返回1000根（2022-10-07–2026-10-02），历史额度保持373。这个试验只证明路线可用，尚未证明全池覆盖、时段或概率有效。

## 固定获取范围与保护

固定本轮当前Nasdaq目录的全部5,261普通股/ADR候选，加SPY作为基准，不事后按结果挑成员；保存目录SHA、完整注册表和每个失败。当前目录不是历史PIT，退市缺失仍公开。

Local→R2(`market_data/us_daily_none/`)→OpenD。价格采用`AuType.NONE`，每股最多1000根K_DAY，同时获取原生`get_rehab`事件，独立缓存，绝不拼接旧Massive/QFQ档案。R2不含本协议所需同口径资料时才走OpenD；只读远程，不自动上传。

单连接、串行请求、订阅批次最多100股，调用发出间隔≥0.65秒，不调用历史K线或交易接口。仅取消当前连接创建的K_DAY订阅，至少持有60秒；不取消其他连接订阅。订阅/历史额度分别记录，外部并发使用可能改变全局额度，不能据此臆测本任务消费。

本轮截止固定为抓取开始时已实际收盘的最新官方ET交易日（10-02）；保存未截断原始响应，特征/标签只能使用该截止前的已完成交易日。新上市、缺失、停牌/过期、无权限和不支持代码均保留，不能用最后价格冒充当前。

## 模型前必须核验

先完成全注册获取、完整覆盖/失败清单与原始SHA冻结，再做训练。禁止用下载字母顺序子集宣布全池效果。Local/R2命中必须满足同一来源、NONE口径、截止及可追溯事件要求。

拆股与现金股息分开：保留原价、原量和全部原生事件。价格翻倍不计现金股息；拆股按ex-date处理，不能把合股涨价当上涨。比率特征须证明未来拆股事件不改变当时输入，绝对价格使用当时原价。分拆、配股、发行人变更等未支持公司行动进入未知状态，不以QFQ系数代替拆股系数。

日线时段仍需与真实常规盘分钟路径/提供商定义核验；原生K_DAY本身不证明可成交或RTH分钟触及。新标签另升版本，不修改v1/v2探索标签。财务继续使用决定日前已披露信息、匹配季度/TTM和缺失状态；业务热点与量价热度分开。

候选算法仍为首次触及时间的LogisticRegression与HistGradientBoostingClassifier，P30≤P60。训练、校准、模型选择、信号资格与完整评价期必须另在首次训练前冻结，不能根据新结果挑阈值、删除失败或把日行数当独立机会。当前无获准模型。

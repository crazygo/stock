# v3联合实验 · 首次训练前登记

本方案在全池数据获取仍未完成时登记。尚未读取新版全池标签、调参或拟合；来源探针涉及MXL/AAT/AKR及少量公司行动。旧v1/v2历史结果与MXL案例已暴露，新实验是历史前向开发回测，不能称新独立效果验证。

评价固定2026年4–9月，保留零信号月与未知；183日历日以内的价格/量能和最近财务期间构造每个决定日输入。更早行情仅供训练和因果特征预热。官方日历只支持2023–2026，因此训练参考起点不早于2023-07-03；1000根原始响应更早的部分保留，但不冒充已核验日历覆盖。

使用原生NONE日线和同一获取快照的split_ratio/ex-date。split-only价格与成交量用于比率；绝对价格及美元成交量用当时NONE原值。future split产生的共同缩放必须在每个当时比率中抵消；不把未来调整后的绝对股价作为输入。现金股息不计入价格翻倍；分拆/配股/送股/特殊股息等未支持动作跨特征183日窗口时不发信号，跨未来标签窗口时保留未知。

目标为从已完成日线Close×1.002开始，下一官方交易日起30/60日历日内的**原生提供商日High的拆股经济触及**。拆/合股自身不产生收益；同时保存到期收盘翻倍。成熟时点是窗口内最后一个官方交易日实际收盘，完整未来前缀不能缺失；已有首次触及也不能提前宣告完整成熟。原生日线High的RTH与可成交范围仍待核验，不能升级为RTH效果或实际成交效果。

三类标签、两算法和校准沿用v2，参数不根据新结果改变：multinomial LogisticRegression(C=1,max_iter=500)；HistGradientBoostingClassifier(iter=120,leaves=15,min_leaf=100,L2=2)。中位数插补及缺失指示仅在训练块拟合，联合temperature scaling。每月开始前120–60日为校准/选择块，前40日校准、后20日选择；更早训练标签必须在校准块开始前完整成熟，校准/选择标签必须在评价月前完整成熟。每类训练/校准至少20例，训练≥500，校准和选择各≥200；不足保留无法训练，不能降低门槛。

输入为17项价格/量能特征、v2已登记16项当时可知财务特征、5项SIC同业量价特征；财务与行业的原值、缺失和来源保留。当前SEC ticker确认和SIC不是历史PIT，未确认身份不附财务，当前目录/退市缺失仍阻止完整部署资格。不得用最新财务事后删除失败。

每月只用此前选择块30/60日Brier均值选择算法；两算法及月前选择策略各保留完整预测。信号资格不变：P严格>80%，当时经营必要条件、个股ret20>10%/rs20>5%/量比≥1.1、同行至少5股且中位rs20>3%/量比≥1.05，同时通过。同股60日历日冷却；所有已发失败和未知保留。业务公告催化单列，目前未作为历史NLP输入。

主precision=TP/(TP+FP)，另报TP/全部信号、数量/日期/股票供给、同股同时条件基准、增量及Wilson/股票簇/周簇区间。不把日预测行或跨模型重复当独立机会。历史数值要求至少30个成熟信号、10股、10日期，三种95%区间下界均>80%且超过同股基准；此数值条件仍不消除PIT、标签范围、实际时效与新的独立观察缺口。

当前模型仅在完整cohort终止、来源SHA与配置一致后训练。报告每股峰值/日期、比率/阶段、P30/P60、报价与概率参考价格/截止。概率不随单个新报价自动更新；最新已完成交易日也不等于夜盘报价对应的入场价。范围不足或来源过期必须弃权，当前合格名单默认为空，直到全部门禁获证。

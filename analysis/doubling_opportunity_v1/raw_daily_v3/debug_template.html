公式、时间切分与证据范围

预测及标签

预测截止为该ET交易日已完成日聚合；参考价是该日收盘×1.002（成本假设）。未来窗口从下一交易日开始，到30 / 60日历日到期，检查High是否触及参考价×2。原始日聚合是否仅含常规盘尚未确认，结果只称探索触及标签；入场可成交性尚未验证。

上次确认高峰：183日历天内，前后各5根已观测日线的局部High最大值，且后5根至少回落5%；最近5根尚不能确认高峰。阶段是日线量价描述。

q0=60日未翻倍；q1=首次触及第31–60日；q2=前30日。P30=q2，P60=q1+q2。缺行情、未成熟、非法OHLC和未支持公司行动保持未知。触及与到期收盘仍翻倍分开保存。

同股60日历日冷却。主 precision=TP/(TP+FP)，同时看信号数量、日期、逐股基准、增量、召回和区间。空分母不可评分。

六个月价格特征

retN=Ct/Ct−N−1；vol20为20日收益标准差；downvol20为负收益截断后的标准差；range20为20日最高/最低−1；volume_ratio为5/20日平均成交量；peak/trough/position用183日真实High/Low；ma20/60为收盘/均线；rsN=个股retN−SPYretN。价格≥1美元、20日平均美元成交量≥50万美元，至少60个真实交易日；覆盖率分母是官方交易日，不填缺失OHLC。

最近财务期间≤183日；季度现金流从可知累计期匹配差分，TTM需要4个连续季度。财务按filed后次日可知连接，只有训练块拟合插补。业务公告催化单列，目前没有历史催化输入。

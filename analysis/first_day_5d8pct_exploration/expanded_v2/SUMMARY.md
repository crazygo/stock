# 五日 +8%：条件、群组与时间迁移

本轮检查58个群、51项特征和首日6个观察时点，纳入盘前、前日盘后、过去3日小时走势与最长60日回看。全部条件只使用观察时已经结束的行情；原始目标仍从11:35 ET的价格起算，五日内触及+8%。

**主要发现：存在明显时间迁移。近期窗口内能挑出100%条件，但部分条件在最近30日已经不再触发；这些高比例不能当作未来已验证概率。**

| 统计窗口 | 起始日范围 | 用途 |
|---|---|---|
| 最近30交易日 | 2026-08-06—2026-09-17 | 近期独立探索条件 |
| 最近60交易日 | 2026-06-24—2026-09-17 | 较宽近期窗口独立探索 |
| 此前30交易日 | 2026-06-24—2026-08-05 | 与最近30日比较同一规则 |

日期指完整五日结果已成熟的起始日；未成熟样本不算失败。每个样本是一个证券×起始日，窗口有重叠。

## Top3单项特征如何阅读

每个入选群的三个单项条件、各自命中数/分母，以及与组合条件的区别，均在 [近期详细报告](RECENT_REPORT.md) 中逐组列出。单项概率不能相乘得到组合概率。
例如最近30日的存储父群，在11:30观察：

| 单项特征 | 五日触达+8% |
|---|---:|
| 前20交易日收盘收益≤−3% | 82.4%（42/51） |
| 前10交易日收盘收益≤−2% | 80.0%（40/50） |
| 前60交易日收盘收益≤−17.6% | 81.8%（18/22） |

三个单项按窗口内保守排序分数选择，并非简单按百分比挑最小样本。单项与三项AND组合是分别计算的条件概率。

## 盘前是否有信息

盘前确实搜到候选：最近30日，连接与定制芯片群在11:30观察，盘前总量不超过过去20日盘前量中位数的75%，触达率为71.4%（20/28），同群同日基线48.8%。它只覆盖2只证券，因此暂不能推广为全部芯片股规律。同成员的互连与交换芯片群给出相同结果，不能当两份独立证据。
加入盘前及跨日小时特征后，它们进入部分群的近期候选；提前冻结、后段复核的主Top5没有选入纯盘前规则。这支持继续跟踪盘前条件，尚不足以认定盘前是最稳定的决定因素。

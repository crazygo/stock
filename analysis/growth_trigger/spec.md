# 增长区间提前触发规律研究 — 冻结规格 v1

冻结时间：2026-09-23。本文件在看任何候选规则表现之前写定；之后任何改动记为 v2 并重跑全流程，
不得把改过的规则称为独立验证。

## 1. 研究范围

- 股票池：`analysis/preopen_three_week/pinned_stocks.json`（version 1，21 只）。不扩展。
- 数据来源与用途分离：
  - 日线 `market_data/us`（Massive grouped daily，adjusted，286 个交易日 2025-08-01→2026-09-21）：
    仅用于资格判断与 8% 区间标签。
  - 小时线 `market_data/us_60m`（Futu 60m，qfq，session=ALL，extended_time=true）：
    用于特征与 +8% 触达判定。`time_key` 已验证为**美东时间的 bar 结束时刻**；
    常规时段=标签 10:30–16:00，盘前=05:00–09:30，盘后=17:00–20:00，夜间=21:00–04:00。
  - 财报 `data/ai_sec_annual_facts.json`：只取 `filed <= 信号日期` 的事实（point-in-time）。
- 已知数据缺陷（必须写进结论，不得静默使用）：
  1. SPCX 小时线仅 2026-06-09 起有数据，之前无法判定；
  2. Futu 小时线成交量约为日线档案的 91%，量能特征只能做同一序列内的相对化；
  3. 分红股（MSFT/AAPL/NVDA/QCOM/TSM/AVGO/META/STX/MRVL/MU）的 Futu 前复权价与日线档案
     存在 0.1%–0.5% 系统性差异，因此**价格基准必须单一来源**：特征与触达判定全部用 Futu 小时线，
     日线档案只用于资格与标签。

## 2. 标签（召回率分母）

8% 区间定义，与页面当前设置逐字一致：起点收盘 → 首个 ≥+8% 的收盘；
自然日间隔 3–14（含端点）；≥3 个交易日收盘间隔；无单日收盘涨幅 >12%；
达标后 2 个交易日收盘均 ≥ 起点+4%（目标一半）。区间不重叠，同一涨幅只保留涨幅最大的一段。
起点须通过 point-in-time 资格（当时已披露年报的营收/经营现金流/净利润门槛、股价、20 日成交额、
60 日最小历史）。

- 产出 `labels_8pct_v1.json`：参数、数据版本（manifest sha256）、生成时间、逐股区间。
- 标签只作召回率分母，**不作为特征，不作为买点**。达标后两日的保留条件只能用于标签，
  不得进入提前触发特征。

## 3. 预测点与结果判定（用户口径）

- 预测点：每只股票、每个通过资格的交易日，取标签 05:00–20:00 的每个小时 bar。
- 动作：买入 / 不买入。非买入不计入精准率分母，也不扣分。
- 入场价 = 该 bar 的收盘价（小时粒度，无隔夜滑点，对应用户选择的 C 口径）。
- 达成 = 入场后 **[t+3 自然日, t+14 自然日]** 内，任意小时 bar（含盘前、盘后、夜间）
  的最高价 ≥ 入场价 × 1.08。
- 次要稳健性变体（只作对照，不进门槛）：
  (a) 只用常规时段收盘价序列判定；(b) 要求达标后 2 日保留 ≥4%。
- 无法判定：末端不足 14 自然日、当日无小时线、资格数据缺失 → 记入 `unable` 清单，不进分母。

## 4. 指标

| 指标 | 定义 |
|---|---|
| 精准率 | 达成的买入点数 / 买入点数（逐股 + 合并） |
| 召回率 | 被 ≥1 个买入点命中事件数 / 事件总数；命中 = 买入点时间 ∈ [事件起点−3 自然日, 事件起点] |
| 误报率 | 未达成的买入点数 / 全部合格预测点数，报告每 100 个合格预测点的误报数 |
| 触发频率 | 买入点数 / 合格预测点数 |
| 提前量 | 买入点时间到事件起点的自然日数分布 |

去重口径三套并列：点位级（原始）、股票日级（每日最多 1 次）、事件级（每股每 14 自然日最多 1 次）。
**主口径 = 股票日级**，其余两套仅作对照。按季度、股票、市场状态（QQQ 20 日涨跌幅分档）拆分。

## 5. 分组与防污染

- 训练集 = 日号为**偶数**的交易日；评估集 = 日号为**奇数**的交易日（按美东日期）。
- 事件归属按区间**起点日期**的奇偶。
- 污染剔除：评估事件若与同一股票的训练期区间起点相距 ≤14 个自然日，则整条剔除并记录剔除数
  （训练标签已包含该段行情路径，两组不独立）。
- 只能使用触发时点已公开的数据；不得根据同一段事后表现反复改规则。

## 6. 通过标准（看评估结果前固定）

基准 = 同期全部合格预测点的达成率（等价于"每个合格点位都买入"）。
门槛（须同时满足）：

1. 评估期去重后买入信号 ≥ 15 个；
2. 召回率 ≥ 25%；
3. 精准率 ≥ 1.3 × 基准，且 bootstrap 95% 置信下界 > 基准。

未达标 → 结论写"尚未找到可靠规律"，不得挑好看阈值。

## 7. 本规格不包含

不把区间当买点；不复用上一版 +20%/15 日买入模型作为成功证明；不生成当前买卖建议；
不做成交、成本、滑点、组合层验证（那需要另立项目）。

## 8. 特征集（冻结 v1，全部只用 ≤ 触发时点的数据）

| 特征 | 定义 |
|---|---|
| `f_ret_1d` | 当日（或最近已完成）常规时段收盘 / 前一常规时段收盘 − 1；盘前 bar 为 None |
| `f_ret_5d` | 最近收盘 / 5 个常规时段前收盘 − 1 |
| `f_ret_20d` | 最近收盘 / 20 个常规时段前收盘 − 1 |
| `f_px_vs_hi20` | 最近收盘 / 近 20 常规时段最高价 − 1 |
| `f_px_vs_lo20` | 最近收盘 / 近 20 常规时段最低价 − 1 |
| `f_vol_ratio` | 当日累计常规时段成交量 / 前 20 个已完成常规时段成交量均值 |
| `f_premkt_ret` | 入场价 / 前一常规时段收盘 − 1（仅盘前 bar 有意义） |
| `f_intraday_pos` | (入场价 − 当日最低) / (当日最高 − 当日最低)，仅常规时段 bar |
| `f_rel_20d` | `f_ret_20d` − QQQ 同期 20 日涨幅 |
| `f_qqq_20d` | QQQ 20 日涨幅 |
| `f_breadth_5d` | 21 只置顶股中 5 日涨幅为正的比例（截至最近已完成常规时段） |
| `f_days_since_filing` | 触发日 − 最近年报 filed 日期的自然日数 |
| `f_revenue` / `f_ocf` / `f_ni` | point-in-time 年报三字段 |

"最近收盘"：常规时段与盘后 bar 取当日累计收盘；盘前 bar 取前一交易日收盘。
成交量一律用同一 Futu 小时线序列内的相对值（已知其绝对量比日线档案低约 9%）。

## 9. 候选规则（冻结 v1）

阈值为整数档、来自标签构造逻辑（3–14 自然日 +8% 属短期动量）与常规技术分析习惯，
**不是**在样本上搜索出来的。规则只用上表特征。

| 编号 | 规则 |
|---|---|
| R0 基准 | 每个合格预测点都买入（随机买入基准）；R0b 从不买入 |
| R1 相对强弱+近高点 | `f_rel_20d > 0` 且 `f_px_vs_hi20 ≥ -0.01` 且 `f_vol_ratio ≥ 1.2` |
| R2 放量上涨 | `f_vol_ratio ≥ 2.0` 且 `f_ret_1d > 0` 且 `f_px_vs_hi20 ≥ -0.03` |
| R3 盘前走强 | 时段=盘前 且 `f_premkt_ret ≥ 0.02` 且 `f_rel_20d > 0` 且 `f_ret_20d > 0` |
| R4 中期动量 | `f_ret_20d > 0.10` 且 `f_qqq_20d > 0` 且 `f_rel_20d > 0` |
| R5 近低点放量转强 | `f_px_vs_lo20 ≤ 0.02` 且 `f_ret_1d > 0` 且 `f_vol_ratio ≥ 1.5` |
| R6 合并 | R1 或 R3 |

评估流程：先在训练集（偶数日）上确认规则可运行并记录触发频率，再**一次性**在评估集
（奇数日、2026-02—09）上出结果；阈值不再改动。任何后续修改记为 v2 并重跑全流程。

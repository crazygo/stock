# 实现核对记录

第一次执行在预测明细输出时遇到 `leader` 字段同时用作股票代码与预测值的命名冲突，改为 `leader_symbol`，无统计参数变动。

第一次成功执行的审计显示只测试了 9,602 个配对，98 个选择中 97 个为 lag=0、1 个为 lag=2。原因是 B 的完整特征首次出现于第 21 个交易日，但 A 的 lag=1/2 还需额外 1/2 日预热；“候选在所有训练日期完整”筛选因此错误地排除了多数目标股的额外滞后。少数更晚才有完整历史的 B 不受此问题影响。

修复将所有候选统一预热至第 23 个交易日，在相同日期上比较协议规定的 0/1/2 滞后。协议的标签、时间切分、候选特征、alpha、评价标准均未变更。初次成功结果保存在 `initial_warmup_run/`，只是未完整搜索两个滞后版本的实现记录，不是另一轮调参或额外阳性证据。后段结果已被看到，因此本次修复重跑不能称新一轮完全未见数据的验证。

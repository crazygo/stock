# 先行股能否改善五日最大涨幅预测：首轮协议

冻结时间：2026-09-27；在本实验的选股及验证结果产生前写入。

用户假设：存在先行股 A，其已知特征可以预测目标股 B 的未来行为；进一步假设找到 A 就能预测 B 的五日最大涨幅。这里检验一个有限版本，不以失败否定所有可能的非线性或盘中关系。

## 样本与目标

- 只读本地 `market_data/us_5m/*/2026.parquet`，不获取行情、不写共享数仓，不改变既有模型。
- 当前 QQQ 101 个股快照为 A/B 候选池，基准使用 QQQ 和 B 的行业代理。属于当前池回溯，有幸存者偏差；元数据并非历史时点成分表。
- 官方 Nasdaq session 日历，按日要求完整常规盘五分钟柱、唯一且精确对齐、价格有效。缺失不补值。
- 决策时点为 t 日收盘后 1 分钟，仅使用当时已结束且 available_at 不晚于决策时间的数据。available_at 为历史重建的 end+1s，并非实盘接收证据。
- 目标 Y：从下一交易日 09:30 Open 起，随后包含该日的 5 个完整常规交易日的最高价涨幅，单位为百分比。不是第五日收盘收益，也不是可执行收益或成交保证。未成熟标签保持缺失。
- 使用 NONE 原价；拆股以生效日比例转换成一致份额单位，历史特征只用已生效因素。现金分红不加回，故是价格涨幅。复杂分拆日及其后 20 日特征不参与，跨分拆标签无效，报告排除情况。

## 冻结实验

- 训练：2026-01-01 至 2026-05-15 的决策日，必须有足够历史且五日标签在选择期前已成熟。
- 选择：2026-05-26 至 2026-06-30。对每个 B，搜索不同 A 及额外滞后 0/1/2 交易日，选择平均绝对误差 MAE 最低的配对。A 永不等于 B；同公司 GOOG/GOOGL 互配也排除。
- 固定后用截至 06-30 决策、标签在 07-13 前已成熟的训练与选择样本重拟合；验证：07-13 至 09-16；标签最迟 09-23 成熟。
- 验证分为 07-13—08-14 与 08-17—09-16 两段，禁止按验证结果改配对、特征或正则系数。
- 不同 A 的比较使用每个 B 的同一训练/选择日期。A 历史特征必须在全部训练/选择日期可用；不因 A 验证期缺失删除 B 的困难日期，缺失时回退基准。
- 同股基线：B 的 1/3/5/20 日收益、5/20 日波动、当日幅度、成交量相对过去 20 日均值。
- 市场基线：同股基线 + QQQ 的 1/5 日收益与 5 日波动 + 行业代理相同 3 项（代理为 QQQ 时不重复）。
- 新增 A：A 的 1/3/5 日收益、5 日波动、当日幅度、相对成交量，整体额外滞后 0/1/2 日。
- 所有回归使用训练集标准化及固定 ridge alpha=20，不调参；预测下限为 0。不声称这是最优模型。选择损失为 MAE，主检验为新增 A 相对市场基线的 MAE 改善。
- 对照：同股基线、市场基线、市场基线+所选 A、A+市场（移除 B）、按代码顺序预先指定的非同公司 A（滞后0）。随机/固定 A 对照不是零假设的完整置换检验。
- 每个 B 至少 50 个训练日、20 个选择日、30 个验证日。即使选择期新增 A 无改善，也保留最优强制配对并披露，直接测试“只要找到 A”这一路线。

## 不确定性与结论

- 同日股票一起抽样，按验证日期 10 日循环时间块 bootstrap 5000 次；另报 5 日块敏感性。重叠五日目标和股票共同环境不视为独立样本。
- 配对改善正值表示新增 A 更好；报告 MAE、相对改善、逐股和逐时段表现、95% 区间。逐股检验采用居中 bootstrap 单边近似 p 值，再做 Holm 校正。
- 不经验证结果挑选子组，不把最优个例等同整个方法有效。只有整体正改善区间排除 0 且两时期同向才称首轮支持；个股独立声明还需 Holm 通过且两时期正改善。
- 验证时间不足三个月、整个 2026 数据已被其他研究看过，故这里只是本实验冻结后的时间后段检验，不是全项目未接触过的最终独立样本，更不是证明因果性。
- 研究阳性也只支持新增信息，不支持固定一对一、必然上涨、精确最高价或可实现收益。阴性只否定本次表示/范围的效果，不否定所有 A→B 关系。

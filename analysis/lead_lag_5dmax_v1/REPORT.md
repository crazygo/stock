# A 的特征能否预测 B 的五日最大涨幅？

本次结果：**没有支持“为每只 B 找一个 A，就能普遍改善五日最大涨幅预测”的路线；没有证否一切先行关系。** 在冻结的日级简单模型里，加入选出的 A，后段平均绝对误差反而增加 6.37%。存在个别可复验线索，但没有稳健到足以确认的配对。

## 问题要分成三层

1. **先行关系是否可能存在？** 有历史研究依据。Hou 发现大、小公司之间的领先滞后主要发生在行业内，其研究中的效应主要由负面信息反应缓慢驱动，不能据此直接推导出“先涨的 A 预告 B 五日最大涨幅”。[Hou, 2007](https://academic.oup.com/rfs/article-abstract/20/4/1113/1615954)
2. **A 是否包含 B 自身与市场之外的预测信息？** 必须用新增 A 前后的后段预测误差回答。同涨同跌、共同市场驱动、事后挑赢家，都不足以回答。客户—供应商的研究提供了跨公司预测的历史证据，但不等于本股票池、这一时期或五日最大涨幅目标已经有效。[Cohen & Frazzini, 2008](https://pages.stern.nyu.edu/~afrazzin/pdf/Economic%20Links%20and%20Predictable%20Returns%20-%20Cohen%20and%20Frazzini.pdf)
3. **找到 A 就足够了吗？** 即使 A 有增量价值，B 自身波动、此前涨幅、市场状态仍可能决定最终幅度；固定一对一关系不是本研究可以预设的事实。日内先行关系的研究也需要控制大规模配对搜索造成的多重比较。[Curme et al., 2014](https://arxiv.org/abs/1401.0462)

## 冻结的首轮实验

- 原始候选池为当前 QQQ 快照的 101 个股；98 个 B 有足够有效样本。HONA、SPCX 历史不足；HON 因分拆窗口处理后选择样本不足。
- 数据：本地 NONE 未复权五分钟行情，官方交易日历，完整常规盘聚合。未混用 QFQ。
- 决策在 t 日收盘后一分钟，只使用截至当时的数据；目标为下一交易日开盘价至其后共 5 个完整常规盘的最高价格涨幅。拆股转换份额，复杂分拆跨越窗口排除；现金分红不加回。
- 训练截至 2026-05-15；选择期 05-26—06-30。对每个 B 搜索不同 A 与额外 0/1/2 日滞后，合计 28,416 个候选配对。所有 A 特征都早于 B 的目标窗口。
- 选择后重拟合截至 06-30 的样本，其五日标签全部在验证期前成熟。验证决策日为 **2026-07-13—2026-09-16**，目标最迟 2026-09-23 成熟。
- 验证共 **47 个日期、98 只股票、4,606 个股票日**。4606 个股票日不等于 4606 个独立样本。
- 模型为固定 alpha=20 的标准化 ridge 回归。用 B 的收益、波动、当日幅度、相对量为自身基线；加入 QQQ/行业代理为市场基线，再加入 A 的价量特征。不是穷尽所有模型。
- 入选 lag=0/1/2 分别 33/36/29 对。lag=2 表示使用截至 t−2 的 A 特征，不意味着已证明 A 恰好领先 B 两天。
- 所有模型在同一 B 的相同验证日比较。A 缺失的 28 行回退基线，没有删掉 B 的困难日期。

## 验证结果

指标为预测五日最大涨幅的 **MAE，单位为百分点，越低越好**。例如真实最大涨幅 8%、预测 5%，该次误差为 3 个百分点。各日期等权，每个日期内股票等权。

| 输入 | 后段 MAE（百分点） |
|---|---:|
| B 自身价量 | 3.7845 |
| B 自身 + 市场/行业 | 3.7885 |
| B 自身 + 市场/行业 + 选出的 A | 4.0298 |
| A + 市场/行业，移除 B | 3.9078 |
| B 自身 + 市场/行业 + 预先固定的 A | 3.9205 |

新增选出的 A 后：

- MAE 从 3.7885 增到 4.0298，增加 0.2413 个百分点，即误差变差 6.37%。
- “改善=基线误差−新增 A 误差”的 10 日时间块 bootstrap 95% 区间为 **[-0.388, -0.125] 个百分点**；5 日块为 [-0.363, -0.139]，都在 0 以下。
- 前、后两个验证区间分别变差 0.314、0.158 个百分点。
- 选择期 98/98 都能找出“比基线更好”的 A；后段只剩 **36/98** 改善，且只有 **21/98** 在两个区间都改善。这正是不能凭前段最佳配对就认定有效的原因。
- 移除 B 自身、只保留 A+市场，整体也没有超过 B+市场基线。预先按代码顺序固定 A 的对照也没有改善；它仅是附加参照，不是完整随机置换检验。

bootstrap 只有 47 个日期、窗口重叠且5000次抽样，尤其不应将临界 p 值当作精确证实。配对及所有超参数在本次后段评估前确定，但 2026 数据此前已被其他研究使用过。

## 证据边界与下一步命题

本次覆盖日级价量摘要、固定单 A、线性增量模型。它没有检验分钟级反应、非线性条件触发、多个 A 共同作用、滚动更换 A 或新闻传播；也未证明“完全无法预测”。而且当前池回溯带有幸存者偏差，行业代理只是粗分类，ETF 含目标股的机械重叠仍存在；未做结构因果识别。

available_at 是历史重建的 end+1 秒，不是历史实盘接收记录。次日 Open 和未来 High 是标签参考价，不是成交保证。五日最高涨幅不等于第五日收益，也不等于可实现收益。

下一步应冻结的更窄命题是：**在 B 自身走势与市场状态之外，某个 A 的已知特征，是否能在另一段未参与开发的数据上继续降低 B 五日最大涨幅的预测误差？** 可以把 WDAY→ADBE 原样留下待新数据复验，不能在本段持续换 A/阈值直到通过。预测方向、预测最大涨幅分布、和证明 A 导致 B，需要分别验证。

# 股票操作节奏概率模型 v1

入口：[index.html](index.html)。它回答“同一股票现在更像反复波动、持续上涨，还是证据不足”，独立于原 ai_trend_quadrant_v2，不覆盖旧结果。

实时查询特别关注55个证券：38只美国公司股票、17只ETF。37只公司股票达到模型历史要求；CBRS不足141个连续收盘，不补概率。日线目标截至2026-10-07 ET，53个证券取得该日有效日线；HK.03006 / HK.07747的新全序列出现非法OHLC，保留旧有效输入与获取失败记录。52只美国证券取得ALL时段60m展示数据，不套ETF公司模型。基本面沿用2026-10-07缓存，8只有正式质量等级；SNPS的EDA头部自述经官网核对，其余头部证据缺失不补值。没有独立份额核验，评级不直接当头部。

## 独立提出的设计

1. **行情机会层**：保留G/V/M/J/S，补20日净收益、20/60日方向效率、5%已确认往返、波动比、收盘回撤、流动性及12月涨幅/集中度。
2. **未来概率层**：五份L2 LogisticRegression（C=.3），独立时间块Platt校准（C=.1）。预测往返20日、短线先赢10日、波段上涨20日、持有上涨60日、下行压力20日；事件重叠，不相加。未来标签以次日常规盘Open起算，一次往返成本假设.20%，只按收盘判断，不伪称盘中委托成交。
3. **公司资格层**：当下财务、头部证据、估值与产品结构审核；缺PIT财报/估值/份额时不放入历史拟合。完整模型数学形式为 P(Y_h|X_t,F_t,L_t,V_t)，F/L/V必须是t之前披露且可用的财务、行业地位、估值。
4. **操作决策层**：将概率与风险/成本/公司资格映射到2–10、10–20、20–60日审查，或底仓+波段/观察。60日只是约三个月，“养肥”到多年还需长历史和跨周期目标。这里没有经过盈利策略验证或获准买卖动作。

“只头部有机会”和“小公司一年只有几次机会”保留为可检验假设，不作为先验事实。高波动不等于短线可获利；公开价格不能推出内幕交易。12月集中度用于检查机会是否依赖少数日期，不能代替新闻归因。

完整标签、阈值、时间隔离与成本登记见[PROTOCOL.md](PROTOCOL.md)。模型系数、填补/标准化与校准器保存为可读取的[models.json](models.json)，不依赖pickle。新行情来自Local→R2→OpenD，另存ZSTD level7 Parquet，旧数据未改，不上传R2；数据请求有可终止的预算。

## 本轮实证

训练决定2025-05-01–10-31（128个日期）；校准2026-02-02–03-02（20个日期）；评价从2026-06-01到截止，标签只在完整成熟后评分。最大60日训练标签在2026-01-29成熟，校准标签在2026-05-27成熟；分块无未来标签泄露。当前成员不是历史PIT，数据已可能暴露，属于历史前向开发回测。

| 事件 | 成熟股票日 / 决定日期 | 模型Brier | 同股基准 | 全池基准 | 对同股改善 |
|---|---:|---:|---:|---:|---:|
| 往返20日 | 2590 / 70 | .17218 | .23329 | .22678 | 26.20% |
| 短线先赢10日 | 2960 / 80 | .25078 | .25984 | .24981 | 3.49% |
| 波段20日 | 2590 / 70 | .10369 | .10980 | .10599 | 5.57% |
| 持有60日 | 1110 / 30 | .05884 | .10957 | .07143 | 46.30% |
| 下行20日 | 2590 / 70 | .25354 | .27045 | .26441 | 6.26% |

往返环境有开发期增量；短线先赢不优于全池基准且概率集中约50%，不能确认盈利优势。60日数字改善很大，但只有30个决定日期，未达到两个60日日期块，未给有效区间，更不能称已验证长期持有。下行概率的可靠性还明显偏乐观。五类目标、两类基准、全部待成熟结果、逐股结果均保留，不能选择其中一个数字宣称整个模型通过。当前没有股票通过登记的高置信度节奏分支。

MXL例：往返概率98.6%，短线先赢49.3%，持有2.5%。这是“反复波动”和“可盈利进出”必须分开估计的实际例子，非买卖建议。

## 页面审查

- 表格筛选、搜索、概率排序；股票详情包含概率范围、基本面日期与缺口、过去12月涨幅和正收益集中度。
- 默认全天60m真实路径，常规盘日线可切换；起止日期、30/60/90/180日历天、固定两年真实日OHLC mini、键盘导航与明确平移。K线最小间距≥5px，全部选定行情可平移；滚轮不改变图范围。
- 失败与成功均可点击，查看整个预测常规盘窗口阴影、评价Open、目标价、未来结果与当时特征。未成熟保留未知；60m不能替代1分钟成交证据。
- **时刻重要核验**：本次供应方time_key是完成时刻。三股09:31的1m Open与日Open一致，10:30的60m Open同样对应开盘。09:30结束的bar属于盘前，16:00结束的bar属于常规盘，20:00结束的bar属于盘后。所有52股逐日核对10:30 Open和日Open；时段投影另存，不影响日线模型。详见[time_contract_probe.json](time_contract_probe.json)。
- 参数调整只改变审查偏好，明确为探索，不改变冻结模型、概率、标签或验证状态。

## 重建与验证

从仓库根目录：

```bash
python3 analysis/operation_cadence_v1/build.py
python3 analysis/operation_cadence_v1/verify.py
python3 analysis/operation_cadence_v1/render.py
node analysis/operation_cadence_v1/verify_browser.cjs
```

浏览器验证器使用本机捆绑Playwright路径，其他环境需调整该require路径；通过既有127.0.0.1:8768静态服务访问，不启动第二个服务。index.html为离线自包含文件，不需要服务或依赖来查看。重建则需要acquisition引用的本地Parquet与原五属性模块，不能声称干净克隆已经包含行情。

`verify.py`独立核对未来标签、G/V/M/J/S、因果截止、内部行情缺口、两基准Brier、时间隔离、全部概率移植、原v2输入哈希、60m/日线Open与时段合同、Parquet忽略规则。真实浏览器验证桌面1440px和手机390px，覆盖搜索/筛选/选择、失败路径/特征、平移、滚轮、日线切换、mini键盘、可靠性图及探索隔离。证据分别为[model_verification.json](model_verification.json)、[browser_verification.json](browser_verification.json)。工程验证不等于模型/策略独立有效。

获取适配器`prepare.py`和`prepare_intraday.py`均写本实验清单与新capture，不更新其他研究current指针。第一次实际成员查询已保存membership.json；静态重建不自动重新查询，不安装自动任务，不交易。获取日志中供应方实际费用未知，未推断为0。

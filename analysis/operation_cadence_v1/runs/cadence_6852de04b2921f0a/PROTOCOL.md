# 股票操作节奏概率模型 v1 · 事前设计登记

登记日期：2026-10-08。独立目录；不覆盖 ai_trend_quadrant_v2。当前特别关注成员以 membership.json 的实时 OpenD 查询为准，不冒充历史 PIT 成员。

## 要回答的问题

一只股票可以同时有持有价值和短线波动。输出五个可验证事件的条件概率，而不是把五个历史分数简单变成百分数；操作节奏是这些概率与投资者约束的决策结果，不能等同交易胜率。长期在本次数据能力下指 60 个交易日，不扩称多年投资。

## 输入与算法

保留 G/V/M/J/S 的原公式（120/60/60/60/140 收益窗口）；新增 20 日收益、20/60 日方向效率（净 log 位移 / 总绝对 log 位移）、20 日 5% 方向变化确认次数、20/60 日波动比、60 日收盘最大回撤、20 日收盘×成交量中位数的 log10、12 月收益与跳涨能量集中度。12 月字段不足时为缺失并附缺失标志，不补成零。只接受连续真实交易日序列，需至少141个收盘。

主算法：每个目标一份 L2 LogisticRegression（C=0.3），训练期中位数填补 + 缺失标志 + 标准化；同日股票权重合计相同。使用独立时间块对原始 logit 作 Platt 校准（C=0.1），该块不足10个正例或负例时仅输出校准块 Jeffreys 基准概率并标记模型不足。无模型/历史不足/非本训练域条目不给数字概率。

## 五个未来事件

日线时点 t 的特征仅用当日及以前完成行情。评价起点为下一交易日常规盘 Open；一买一卖成本假设合计0.20%，不等于实际成交成本。收益/风险事件不使用当日收盘价充当可成交价。

1. **往返波动 / 20日**：从次日 Open 起，后续20日收盘路径发生至少4条已确认、方向交替的5%变化（两轮往返）。方向变化须从运行极值回退/回升5%才确认；未确认末端不计入。它是振荡环境概率，不是可赚取各段极值的概率。
2. **短线先赢 / 10日**：从次日 Open 出发，未来10日第一次收盘净收益达到+5%先于净收益达到−5%。超时及先下跌计0。仅按收盘观察，未模拟止盈委托或盘中可成交性。
3. **波段上行 / 20日**：第20日收盘净收益≥+5%，期间收盘最大回撤≤10%。
4. **持有上行 / 60日**：第60日收盘净收益≥+10%，期间收盘最大回撤≤15%。目标是上涨幅度和可承受路径同时满足；缓慢但涨幅很小的股票不自动成为高分。
5. **下行压力 / 20日**：任一收盘相对评价起点的净收益≤−10%。

五事件可重叠，因此五个概率不合计100%。实际退出、税务、仓位与事件交易没有纳入盈利验证。

## 基本面、头部与操作节奏

今天的 SEC 财务缓存与业务核查仅用于当下持有资格审查。没有逐历史时点可用财报快照，禁止将今天评级放进历史训练。本版概率只验证行情层；完整模型应加入 PIT 营收增长、现金流利润率、杠杆/稀释、估值与经核验的细分市场份额/竞争地位，并做增量消融。

“头部”需要细分行业、竞品集合、份额/排名来源与日期。moat、AI关联、A评级、股价涨幅或市值均不直接等同头部。缺失为待核验；官方自述与独立份额证据分别标记。小公司低频机会/头部长期更优仅是待检验假设；公开行情不能推出内幕交易。

审查页的节奏为**探索性条件分支**：持有概率≥60%、下行压力≤30% → 20–60交易日审查；短线先赢≥60%、往返概率≥40%、下行压力≤30% → 2–10交易日；两者同时满足 → 底仓+波段；波段上行≥60%、压力≤30% → 10–20交易日；否则观察/低置信度。基本面/头部缺口会标记长期资格待确认，不把缺口变成0概率。固定门槛不是本次效果验收结果，不是获准交易动作。

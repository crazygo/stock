4. 对每只股票列出逐个缺失交易日、价格事件、财务解析缺失与经营门槛失败；不足不能按失败或差公司解释。全池3,033只至少一项基础财务字段未解析，不能据此排除所有优秀公司。全池报价缺失不冒充当下，页面可切换日线基准与候选快照。
5. 独立复算确认全池规则选出集合与682张图的数据成员完全相符（681候选+MXL），证明限定池、限定数据版本和规则下没有跳过行。无法证明全市场无遗漏，也不能证明统一门槛覆盖所有优秀业务。

## 生成与验证

```bash
python3 analysis/potential_recovery_v1/build.py
python3 analysis/potential_recovery_v1/verify.py
```

`source_registration.json`锁定来源路径；构建不读取漂移的latest报告。复现需要本地已登记价格面板、原始公司事实及本次报价缓存，路径/哈希见`SOURCE_EVIDENCE.json`；缺失应明确失败，不伪造行情。行情补齐遵循Local→R2→OpenD，不自动上传R2。该研究直接只读复用已核查缓存。

如明确要创建另一份当前快照，独立的`acquire_quotes.py`继承30秒预算、子进程可终止、原子完整文件保留规则。重新报价须另记录快照与重新生成结果；旧业务笔记中的边界数值也须同步核查，不能标旧数据为当下。

当前数值核查：77,391根真实日K逐值对照价格面板；2,744条年度财务事实对照SEC原始载荷；全部5,614条观察证券去向保留。来源SHA核查通过，详见`DATA_VERIFICATION.json`。这些是数据/工程正确性证据，不是预测能力或未来收益验证。

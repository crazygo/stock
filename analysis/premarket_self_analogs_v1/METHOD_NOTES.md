# 持仓历史对照：方法与数据说明

公式、口径与实际覆盖

输入与相似度

主图右侧为历史真实后续3个交易日：盘前截止的当天计第1日，画到第3日盘后结束。黑色本次曲线只到本批次09:00截止。彩色历史延伸沿用输入起点价格归一化；后续数据不参与相似度和聚类。未成熟或缺行情处断线，半日市保留真实收盘时刻，周末闭市不填价格。

曲线点 yₖ=100×ln(Pₖ/P₀)，P₀为上一交易日04:00开始的第一根盘前K线Open，后续点为各小时柱Close。原v1使用整体 Pearson(y当前,y历史)≥N，同时历史曲线极差/当前极差∈[0.5,2]。探索v2增加末半段相关r≥同一N、末半段拟合斜率同向且非平坦；展示的分段系数为min(整体r,末半段r)。末半段按交易小时x≥29/2划分，实际使用x=15至29的15个点，不插值。相关系数取值−1至1，不能解释成百分比相似度。整体相关会受前段共同大幅波动影响，末半段反向可以仍有较高整体r。v2是在已暴露的历史个案审查后修订的探索口径，没有独立验证。全部整体候选保留在图中，未通过v2者不进入v2后续统计；可切换原v1对照。只在完全相同的时段槽位、全部所需价格完整时评分。缺失不插值，零量柱单列。

窗口为上一交易日04:00→本日09:00，共29个交易时段小时、31个价格点。周一窗口保留上一交易日盘后和周日晚真实夜盘，闭市时间不填点；实际日历跨度单列。半日市作为前一交易日时，不与本次完整前日模板匹配。

结果、价格与基准

之后24小时：从历史09:00之后开始，止于次日日历09:00；当天完整常规盘：09:30至交易所收盘。全部收益相对历史09:00价格，同时单列常规盘Close/Open。遇到周末或假日，24小时终值取区间内最后一个实际交易时段收盘；另提供完整延伸至次日盘前的子集。

高低价中位：先分别求每个后续窗口的 High最大值/P参考−1 与 Low最小值/P参考−1，再取跨历史窗口的中位数。展示的美元价=本次09:00价格×(1+该中位收益)，是相似案例的比例映射，不是预期必到的价位。全序列QFQ避免拆股导致伪跳变，不能用于历史成交价模拟。

基准为该股相同小时、相同数据覆盖下的全部可比较日期；没有用未来结果筛选相似案例。未知标签单列。没有进行独立预测验证、概率校准或实盘交易验证。

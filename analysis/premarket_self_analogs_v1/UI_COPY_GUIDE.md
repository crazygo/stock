# 持仓历史对照：页面文案约定

适用范围：本报告的可见界面，包括按钮、标签、状态、表头、图例、图内标注和空结果。

## 页面语言

- 只呈现用户操作、数据、结果、状态和单位；日期以 ET 标注。
- 左栏集中呈现算法版本、阈值和筛选条件；右侧集中呈现曲线、历史日期和结果。
- 用“已匹配”“未匹配”“尾段反向”“后续未完成”“暂无结果”等短状态。
- 参数、版本、数据时点和缺失保留为紧凑标签；研究属性使用“研究版”。
- 相关系数保留小数值，收益率使用百分号，不混用为相似百分比。
- 每个历史日期保留图例、输入区间、后续区间和实际涨跌。

## 文档语言

公式、计算过程、权重、门禁理由、思想、研究边界、验证过程、开发实现、
数据获取路线和方法来源写入 METHOD_NOTES.md、README.txt 或版本协议，
不放在页面结果区，不在图例、状态或空结果中反复解释。

# v2.1 按月更新与波动尺度校准：评分前登记

用户明确主目标为当天触及+3%。固定年度模型的开发期外层已查看：三路线58%—59%，不能再称该段独立验证。此补充只有三条原机制各一个按月更新配置，不搜索新阈值、树参数、持有期或目标；保留固定年度负结果。

目的：分开股票自然触及能力、市场状态迁移和当日盘前信息。新增 `h_base3` 为此前60个完整交易日的真实+3%触及率，至少40个且已全部成熟；按当天20日历史日内振幅尺度归一化盘前振幅、末段动量、夜盘涨跌。`h_base3` 是历史基准，不能说成当天实际胜率。H-only同样增加历史基准，不因新特征容易排序股票就宣称盘前增量。

外层每个2026月初重新拟合：最近252个已有交易日作为窗口，最后64日用于校准，前32日拟合sigmoid、后32日只做阈值可靠性检查及名单登记，其前的历史训练树。只用label_end<月初的成熟数据，同日全股同侧。最低训练500行、校准100行；不足月份不制造预测。阈值固定0.70，校准检查失败仍展示研究预测并明确失败，不因外层结果降低阈值。

树参数、三分位回归、日期块CI/Holm和主通过门槛沿用v2：precision>=70%、至少300信号和60信号日、同股匹配提升CI下界>0、对H的Brier改善CI下界>0、三机制Holm通过。特别关注个股须在此前校准选择块登记（>=10信号、>=70%、较同股基准>=3pp），且外层至少30信号、4个月、>=70%、提升>=3pp。每行携带当月模型、训练结束、校准结束和事前登记状态，所有月份含失败均保留。

静态当前股票池、已有曝光、历史end+1秒假设及缺失仍限制证据，仅为修正模型更新方法的历史开发回测。新数据补齐时用同一冻结代码复算，不改参数；预先把扩大的源清单和覆盖写入新的审计。

# 按可用容量缩量 · 登记于执行任何容量回放之前

新问题：前版使用最多权益 20% 计算整笔股数，然后成交量不足就禁入。20% 是资金上限，较小的盘前仓位也可能可买。检验这个执行假设，而不是用外层结果修饰原模型。

- 原三条基模型、两时段 Platt 校准器、输入特征、月前时间切分全部不变，不重新拟合。
- 决定时 planned_qty = min(floor(min(已结算现金, 权益×20%)/(完成 Close×1.001)), floor(上一根5m成交量×1%))。planned_qty≥1 且当时预计金额≥$1000 才进入合格池。无合格股不操作。
- 入场仍是下一根 5m Open×1.001，因未来价格变化只能缩量保证资金上限；不根据未来成交量或结果筛选信号。历史报价 / 实际撮合仍未知，不能称成交证据。
- 原同股每日一次、最多一笔持仓、常规盘剩余 +3%、无止损日终退出、T+1 交易日结算、成本保持。两个月连续账户共同回放，不把盘前与盘中独立账户相加。
- 在原月前最后20日分别回放每阶段七门槛 0.60–0.90，以原 8次/6日期/70%/基准增量3pp/平均净收益>0/未知0 选择门槛；排序 Wilson 下界、次数。
- 外层仅 2026年8月、9月，再检查原12次/10日期/70%/增量/正净收益。不能用10月标签。五只特别关注、每股n≥12且70%+的目标另报，不能用整体门禁冒充逐股达标。
- 独立容量模型 artifact `capacity_<route>_<month>.pkl`；run ID `v5capacity:<route>:<period>`；结果 `capacity_results.json`。不覆盖原共享 / 分时结果，不自动把试验切到统一入口。
- 这是已暴露历史上的新增开发期试验，选择空间增加，独立性不能恢复。

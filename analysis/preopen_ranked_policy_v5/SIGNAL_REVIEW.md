# 有效信号口径更正与结果 · 2026-10-04

用户要评估有足够置信度、当时发出的预测信号。此前把实际模拟买入作为主分母，并用账户净收益参与门槛选择，不符合这次澄清。本版新增独立的 signal_v1；旧 16/26=61.54% 等账户回放保留为另一种指标，不能改名为本版信号准确率。

主指标 = 成熟有效信号中达成 +3% 的数量 / 全部成熟有效信号。低置信度弃权、未发出的候选和账户不操作不进入分母；当时有效但后来失败必须进入 FP。标签待成熟 / 缺失永久保留，并报告 TP/全部已发有效信号的保守下界。有效性不受现金、持仓、是否成交和盈亏影响。

门槛沿用原七个有限候选，按每月开始前的原 20 日选择块、信号 precision≥70%、8 个信号、6 个日期、基准增量3pp 选定。没有前置通过门槛则弃权；不在八、九月根据结果重新挑阈值。模型、特征和概率校准器完全沿用已有冻结 artifact。

八月有效恢复信号盘中门槛为0.60；九月盘前 / 盘中均0.60。门槛选择评价的是当时排名和去重规则下的条件达成率，不将 score=0.60 本身叫作70%的个人获胜概率。八月相关股盘前门槛0.65、其余月份该路线弃权。基础风险九月前置块曾通过0.80/0.90门槛，但九月没有达到该分数的已发信号，不能用前置83.33%充当外层准确率。

十月恢复模型的前置信号筛选中，两时段均没有通过门槛，因此仍弃权。新的信号配置与模型SHA单独冻结，原模拟账户部署配置不改。新观察从10月5日开始，十月1、2日已经暴露；新统计只在目标窗口成熟后更新标签，不重新确定有效性。

数据覆盖、当前成员非PIT和原始价格 / OHLC代理限制与原报告一致。旧零盘前买入不能说成本版零盘前信号；本版有盘前有效信号，但不能推断真实成交或收益。

数据库 signal_events 记录当时有效性与完整特征；signal_labels 保存未来标签；signal_ticks 保存弃权与排名审计。页面可逐笔检查成功和失败的真实分钟路径，并导出仅有效信号的 CSV。其他低置信度概率可保存用于校准审计，明确不计主达成率。

核验：28项因果 / 账户 / 信号契约检查，54个有效信号的原始价格、完整因果特征、冻结概率及独立第一名复算通过；四入口桌面 / 手机交互、成功与失败检查、有效信号 CSV 导出通过。实时有效信号另记实际 issued_at，超过预定评价价格时点的计算弃权。新数据尚未发生，这些是实现核验与历史回测证据。

# horizon_v1 复盘 · 2026-10-04

三路线保持原特征与算法：基础风险 / LogisticRegression、相关股分钟量价 / LightGBM、回撤恢复 / ExtraTrees；两个目标独立训练/校准/选门槛。五月至九月30个历史模型，加六个十月只读报告模型，均完成。五月实际181训练日，其他折200日；校准/选择各20日，区块之间统一隔离10个官方交易日。所有训练、校准和选择标签分别在下一块开始前成熟。

## 结果如何解释

- 六组整体达成率均不足70%，完整3262个有效信号保留，其中86个未知。精确周表、逐股、同股基准和两周块区间见 REPORT.md；模型输出概率不能直接当作已验证准确率。
- 5日+5%中相关股 / LightGBM 的历史信号达成率69.56%，相对同股同时点前置历史基准57.10%高12.45个百分点；这比只看触及率更有研究价值，但仍未达到目标，区间宽、概率Brier也没有胜过简单基准。
- 10日+10%中恢复 / ExtraTrees 的66.67%只比自身基准65.41%高1.26个百分点，尚不足证明恢复量价特征有稳定增量。基础风险 / LogisticRegression 为55.12%，低于基准59.96%，且全部有效信号平均预测90.31%，明显过度自信。
- 三算法两个目标的全部可评分预测均值比实际触及率高约4个百分点；六组股票日等权Brier均不优于同股/同分钟基准。概率分箱保留于每月元数据。这说明本轮经过Platt校准后在后续月份仍有偏差；市场状态和第一名筛选改变评分群体是下一轮需要验证的解释。校准数据与训练数据隔离的方法依据见 [scikit-learn 概率校准文档](https://scikit-learn.org/stable/modules/calibration.html)。
- 旧当天+3%信号的长窗口后续达成率更高，但样本/筛选不同，旧概率没有为新标签校准。不能断言旧算法更好，也不能把83%–88%的事后达成率写成其原预测概率。
- 5日相关股模型中五只特别关注股票ALAB/AMD/MRVL/TER/TXG，在已暴露评价期各自满足n≥12、70%和3pp增量。它们是评价后发现的子集，未来若限定这五只，必须重新登记固定成员并使用新数据验证；不能据此提高模型的整体通过状态。

## 下一轮可以验证的假设（本轮没有调参追结果）

1. **单独校准第一名信号。** 用时间隔离的前置数据先生成第一名候选，再检查这一筛选群体的概率分箱。与当前全候选校准比较，验证90%概率的过度自信是否降低，同时保留非零机会供给。
2. **把触及机会与短时入场信号分开。** 用成熟日线信息估计5/10日目标的基础机会，再用三路线的分钟信息择时。需要同标签、同成员、同时间切分的对照，避免直接将旧+3%概率乘上历史跨日达成率。
3. **固定算法/特征做消融。** 当前路线同时改变特征与算法，不能归因。下一轮可固定LightGBM比较基础、相关股、恢复特征，再固定输入比较三算法；先登记再运行，并保留全部失败组合。

## 工程证据与边界

verification.json独立复算3262个原始标签与冻结概率、86940个第一名决策点，核对去重、周计数、SQLite和时间purge。native_verification.json对每个十月模型验证20092行，含盘前与盘中，最大概率误差低于1e-10。四个页面的两个目标、成功/失败/未知路径、CSV、平移/禁缩放和390px手机检查通过。

原始OHLCV审计发现HONA上市首日75根零价占位；它在36个模型中均未注册，且新严格OHLCV标签门禁与既有标签数值完全一致。原始文件及特征hash写入交付清单，Parquet/pickle/SQLite不进Git，不上传R2。公司行动仅使用已有归档，未确认公告完整性；跨窗未知的处理是保守覆盖限制。

训练过程中一个元数据记录了带只读云端补充行的协议SHA。两个实际协议快照都保存于protocol_snapshots/，质量检查确认唯一差异是只读云端范围登记；所有回测目标、输入、算法、切分和门槛条款一致。保留原SHA，没有事后改写模型元数据。

这仍是已暴露历史的开发期前向回测。十月新目标六个分时门槛全为空，命令输出研究参考排序；原+3%自动观察配置、模型和准入不变。

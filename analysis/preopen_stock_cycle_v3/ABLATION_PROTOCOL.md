# 信息量审计（在 v3 首次模型结果前冻结）

这不是新的赢家筛选，也不修改主实验通过门禁。对主策略在周期前选中的所有股票周期，用完全相同训练 / 校准日期和模型结构重新拟合四个对照：历史环境 H-only、去成交量信息、去分钟滑窗、去相关股输入。各对照保持该周期原先冻结阈值；比较逐日 Brier 和阈值信号 precision / 供给，避免只在成功股票上消融。置信区间按 30 天周期 block bootstrap，固定 seed 1004、2000 次。

主模型训练日期、成员、环境匹配过滤与协议一致；概率校准仍仅用前置 25 日。过去标签可作为先验，未来标签不可进输入。去量同时去成交量本身、相对量、活跃比例、成交集中、signed-volume、bar-VWAP、量价相关、burst 与历史量；去分钟同时去 w10—w180、slide 与基准/相关股对应分钟输入。H-only 仅历史日特征与 stock_id。所有对照的负结果照样写入报告，不以对照好坏改变胜出组合。

# v3.1 紧凑量价与历史相似日：第二轮方案

首轮预先冻结的 608 个股票周期 / 六模型没有主策略合格组合；324 个已发信号 193 次命中，59.57%，不能称达到任务目标。原始 results_initial.json / predictions_initial.parquet 保留。首轮只有 40 个前置入选股票周期；+3% 常被基础振幅决定，325 维在单股小样本上的信息量和校准不足。

本轮不修改首轮 12 信号 / 70% / 增量 3pp / 正成本代理的通过门禁，也不修改标签、训练日期、周期、阈值候选或校准划分。新增有限候选：单股紧凑 LightGBM 120/240 日、相关股紧凑 LightGBM 120/240 日、单股紧凑 Logistic C=.1 / C=1 120 日、相关股紧凑 Logistic C=.1 240 日、单股相似日 k=15/30 240 日、相关股相似日 k=60 240 日。仍由周期之前的选择期决定模型，保留所有失败。

紧凑特征预先固定：历史 3/20/30 日振幅和基础触及率、30 日收益/波动、前日振幅、盘前相对量与成交年龄、盘前振幅/历史振幅、盘前 gap/历史振幅、夜盘收益、近 30/60/120m 收益/效率/成交相对量/有向量、30m 滑窗最大最小、QQQ 历史收益/波动与盘前 gap、相关股前 30 日收益和当时 breadth/gap。去掉其余弱窗口、重复尺度。单股模式去相关股特征。

Logistic 和 KNN 只在训练集拟合缺失中位数、缺失指示、RobustScaler；距离加权 KNN 的概率再用前置校准期 sigmoid 校准。LGBM 容量保持原协议。新增模型名单和固定参数写入后才运行。

这仍是在已暴露历史上的开发迭代；增加候选导致多重尝试，不能作为独立验证或未来收益保证。即使达到五个历史合格组合，也要分别报告全部股票周期的策略结果和失败范围。

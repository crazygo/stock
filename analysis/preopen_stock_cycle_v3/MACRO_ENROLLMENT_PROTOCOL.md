# v3.2 市场环境与逐模型登记

v3.1 的周期前单一择模策略：570 信号 / 329 命中（57.72%），仅 COHR 一个主策略组合通过。所有周期前通过校准的候选中有 6 个组合满足原 12 次 / 70% / +3pp / 正成本代理门禁，覆盖 AAOI、AXTI、COHR；多个模型共享股票周期，不能当作独立机会或五只股票。该结果写入 results_compact.json 保留。

为回答用户“哪个模型在哪个股票周期有效”，本轮同时登记全部前置合格模型，和原唯一择模策略并列展示。全部候选的阈值仍只从过去选择期确定；通过组合是历史结果筛选，不是可提前知道的周期，也不能据此替代唯一策略整体结果。独立股票数与组合数分开报告，原五股门禁保留。模型不同而股票日期重复时明确相关性，不把重复信号相加为独立机会。

新增固定五个候选：macro_solo_short / long、macro_related_long（紧凑 LightGBM 120/240/240 日）、macro_logistic_solo（120 日 C=.1, liblinear max_iter=1000）、macro_analog_solo（240 日 k=15）。旧模型不加入新宏观列；旧 Logistic 未收敛的拟合不登记为合格候选，不通过压制警告掩盖失败。

新增仅用前一官方交易日可知 Cboe VIX / VVIX / VIX9D 日收盘：VIX 水平、3/10/30 日变化、60 日百分位、VVIX 水平和 VIX9D/VIX 比值。当前日或未来日的值不进输入；不把下载时间误当历史可用时间，假设前日结束后数据已公布。原始 CSV 与 SHA256 归档，Cboe 来源链接记录。旧两年行情、标签、门禁、阈值、周期、训练和校准拆分保持协议一致。

新增宏观候选写入本文件之后才运行；失败周期与所有已登记模型都保留。多次在已暴露历史迭代产生选择偏差，结果仍仅是历史开发回测。

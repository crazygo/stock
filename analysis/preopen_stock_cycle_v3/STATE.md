# 当前问题、方案矩阵与待办

v2 的全股混合模型与全年门禁不匹配用户所需的小范围股票 / 30 天周期；特征以整段小时汇总为主，缺分钟滑窗的量价变化；夜盘低活跃删样造成覆盖不足。图只标点、周末留白、蜡烛挤成亚像素，不能解释失败。

| 思路 | 样本范围 | 验证问题 | 失败条件 |
|---|---|---|---|
| 单股短窗 | 单股过去 120 日 | 个股独有盘前量价结构是否有增量 | 前置校准 / 周期 precision / 增量 / 样本不通过 |
| 单股长窗与非线性 | 单股 240 日或 ExtraTrees | 稳定尺度与非线性是否改善供给 | 同上，并与基础波动对照 |
| 相关股 | 固定产业关联组 | 同行业盘前状态是否帮助个股 | 同上，横截面不可依赖未来标签完整性 |
| 环境匹配 | 相关组历史相近市场环境 | 高波动 / 低波动周期是否需要不同映射 | 历史日期不足、同上 |

待办：冻结协议 → 审核 / 补齐行情 → 提取分钟量价特征 → 每周期前置训练选择 → 全周期账本 → 至少 5 个合格组合 → 失败区间 UI → 重放、因果和浏览器验证。全部失败组合保留，不把后验赢家称可提前知道的周期。

交付状态：四轮开发记录（原六模型、紧凑特征、免费宏观、固定边界敏感性）均保留；14 个历史合格组合覆盖 AAOI / AXTI / COHR / IONQ / LIFE。门禁未调低。原周期唯一择模策略为 350/601=58.24%，不能混同已找到整体可交易 70% 策略。396 个前置登记模型重放、1410 个来源与 3 个宏观来源、8 个因果 / 缺失测试已通过。20 个独立 wireframe 的浏览器验收结果以 ui_verification.json 为准。

# 历史价格形态描述 v1

本版只回答“这段已经发生的价格路径如何描述”。不定义未来X日目标，不输出操作频率，不评估收益策略。人工语义审查完成前，不宣称数学模型符合用户心中的股票性格。

## 输入与边界

复用2026-10-08实际查询的特别关注成员快照55个证券（38公司股票、17ETF），以及 operation_cadence_v1 中已经取得的单次QFQ日线、ALL时段60m及时间戳实证。旧results.json仅抽取证券元数据、来源与基础资料；其未来字段不进入新页面，未来标签、拟合系数、预测概率或操作分支均不参与新计算。前版目录保留完整。

日线请求2024-10-08至2026-10-07；日线实际覆盖逐证券展示。HK.03006、HK.07747保留有效旧输入至10-06，原新捕获OHLC失败不修造成真实行情。小时请求2026-06-01至10-07，52个美国证券；港股不补小时。日历来自已核对的NYSE/Nasdaq官方日历；HKEX仅核验2026年，未知年份不生成连续路径统计。新描述中ETF与较短历史公司仍可描述实际区间；不强制141个收盘才能描述净涨跌。

默认历史描述范围为60日历天，2026-08-09至10-07，包含终点；实际首日为08-10。改变日期时，所有描述仅用新的区间，窗口与极值从本区间内部开始。公司资料缓存与成员查询是当下快照，不冒充历史PIT。

## 原始、连续的描述变量

- 净收益 R = C末/C初−1。
- 日log变化 r_t = log(C_t/C_{t−1})。
- 有符号方向效率 E = Σr_t / Σ|r_t|，范围[-1,1]；平价路径设0。
- 波动 σ = sample_std(r_t)，不年化。
- 最大收盘回撤 D = max(1−C_t/max(C_0…C_t))，保存峰谷日期。
- 大涨集中度：最大的3个正log收益之和 / 全部正log收益之和。没有上涨日时未知；不足3个时按实际数量。不是净涨幅贡献或催化归因。

日线内部有缺失时，不跨缺口计算全段效率、波动、回撤和极值；完整历史子窗口仍可逐个计算。不同前后交易日不能仅按“相邻数组行”假定连续。

## 方向变化法与节奏

默认 q=5%。首先维护运行中的最高/最低收盘；当自最低收盘上涨至少q或自最高收盘下跌至少q，确认第一段方向。其后仅在出现相反方向、幅度达到q时，新增一段。每段保存极值日期/价格、确认日期/价格及间隔。

同向连续涨跌不能拆成多次折返。区间末端未达到幅度的变化不计。初始段是方向确认，不等同于一次折返；至少3段才构成“反复折返”描述。两段交替只是一对方向变化，不保证价格回到原位置。

相邻确认日间隔的中位数为历史变动节奏；极值识别依赖之后已经发生的反向变化，确认有滞后，不是可执行进出点，更不是建议持仓周期。日收盘方向变化与小时盘中振幅分开。

## 历史窗口占比的数学意义

默认 w=20次交易日变化，须21个连续交易日收盘。每天滑动一次，只计完全落在所选区间内的窗口。

- 偏上行：R>0且E≥0.20。
- 较平顺上行：偏上行且σ≤2%。不将“平顺”解释为涨幅慢；快慢看实际幅度。
- 反复折返：至少3段交替方向确认，每段达到q。

p̂(A)=符合描述A的完整已发生窗口数/全部完整已发生窗口数。这是从本段历史窗口均匀抽样的经验符合概率，页面称“历史窗口占比”。不是未来事件概率、模型置信度或买卖胜率。描述重叠、不相加；重叠窗口不是独立样本，不用虚假独立样本置信区间。原始变量始终同时展示，不能只看0/1子窗口条件。

E阈值0.20、σ阈值2%、q=5%、w=20是待人工语义核对的提议定义，没有用预测结果选模。页面允许探索q=3/5/8/10%、w=10/20/40并标记探索，不沿用任何通过状态。人工审查导出包含版本、证券、日期、规则、描述、意见及数据SHA。

## 长期背景与原参数

截至所选终点回看12日历个月，报告实际覆盖净收益、最大回撤、最强历史20日及最大3个上涨日正log贡献。不足12月明确不足；最强窗口属于已知历史的事后描述，不代表可提前选中。

原G/V/M/J/S保持原公式，仅使用当前所选区间内的连续收益：G需120次，V/M/J需60次，S需140次，不足留空。其0/1分类及重采样概率不参与新描述。

基本面、头部资料只显示原始事实、披露与核对日期和缺口。公司研究初评等级不当作行业头部，ETF不套用公司财务。没有头部/估值的概率合成；这是另一条资料核查路线。

## 本轮验收分层

1. 计算正确：独立复算净收益、方向效率、波动、回撤、窗口占比、方向变化及五参数。
2. 证据对应：真实OHLC、区间切片、极值与确认日、缺失及时间戳可定位，浏览器交互核对。
3. 语义符合：用户逐段“符合/部分符合/不符合/证据不足”审查，目前未完成。
4. 预测有效：不在本版范围，没有未来标签或预测效果验收。

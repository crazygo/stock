数学定义、与原 G/V/M/J/S 的关系及数据证据

路线名：历史路径描述；算法：有符号路径效率、方向变化法（Directional Change）、经验窗口频率。没有训练分类器；本轮验证是计算与价格证据核对，语义正确性等待人工审查。

净涨跌R = C末 / C初 − 1，只比较选定区间的首末真实收盘。
有符号方向效率E = Σ log(Ct/Ct−1) / Σ |log(Ct/Ct−1)|，范围 −1…1。+1表示一路上行，−1表示一路下行，接近0表示位移被来回变化抵消；平价路径设0。

收盘最大回撤max(1 − Ct / max(C0…Ct))。点击定位峰值到谷值；未把盘中低点混为收盘回撤。
折返节奏相邻确认日的交易日间隔中位数；从极值到确认有滞后，也依赖阈值。这不是建议持仓天数。

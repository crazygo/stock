## 一、策略背景与交易痛点

交易员在美股盘中开盘后，经常面临三个核心决策痛点：
1. **盘中信息过载，抓不住主线**：自选股很多，但在美股开盘前 1~2 小时内，哪些股票真正放量走强？哪些只是虚假脉冲？
2. **缺乏近期动量兑现的量化参照**：某只股票今天看着强势，它在过去 3 个交易日（今天-3、今天-2、今天-1）中买入的“3日涨 5% 达成率”到底有多高？是屡创新高的真牛股，还是冲高即套人的假突破？
3. **首小时锚定效应的实时落地**：
   - 我们在聚类方法 2 中实证发现：**美股开盘首小时（10:30）的达成率与全天后续胜率具有高达 $r = 0.788$ 的强相关性，上午盘结束（11:30 累计均值）对下午盘预测力高达 $r = 0.886$**。
   - 因此，**开盘到现在的 -1 小时总数据（10:30 与 11:30 两个小时）**，是决定当天该股能否买入、是否应该加仓的最强微观依据。

## 二、横轴列定义与计算口径

| 字段类别 | 列名 | 数据口径与计算方式 |
| :--- | :--- | :--- |
| **基础信息** | **标的代码 / 名称** | 美股 Ticker 与富途官方中文名称，置顶冻结首列 |
| **分组类别** | **类别** | 自动标识：`0086持仓+特注`、`0086现金持仓`、`特别关注`、`亏损特别关注` |
| **实时行情** | **最新价 / 今日涨跌幅** | 盘中毫秒级快照现价与当日涨跌幅 % |
| **日内波动** | **日内振幅** | `(今日最高价 - 今日最低价) / 昨收价 * 100%` |
| **开盘-1h总数据** | **成交量 (10:30+11:30)** | 开盘至 11:30 两个已完成小时的累计成交量，附带占全天当前总量的百分比 |
| **首小时异动** | **首小时 (10:30) 冲幅** | 10:30 收盘价入场后，截至目前的最高冲幅 %；附 10:30 收盘价与成交量 |
| **次小时异动** | **次小时 (11:30) 冲幅** | 11:30 收盘价入场后，截至目前的最高冲幅 %；附 11:30 收盘价与成交量 |
| **【新增核心基准】** | **近5日 (D-5~D-1) 综合达成率** | **最近 5 个完整交易日（09-17 至 09-23，不含今天）共 35 个交易小时的综合达成率（$T/35$）**。多日平滑消除单日偶然性，是衡量该股持续做多动能的最强基准！ |
| **单日追踪 1** | **今天-3 (09-21) 达成率** | 周一 7 个小时后续在窗口期内触达目标的比率（$T/7$），附该日入场至今最大冲幅 |
| **单日追踪 2** | **今天-2 (09-22) 达成率** | 周二 7 个小时在途跟踪窗口（⏳），已达标提前计入，附最大冲幅 |
| **单日追踪 3** | **今天-1 (09-23) 达成率** | 周三 7 个小时在途跟踪窗口（⏳），已达标提前计入，附最大冲幅 |
| **单日追踪 4** | **今天 (09-24) 达成率** | 今天已完成的 2 个时段（10:30、11:30），分子为截至目前已触达目标的时段数 |
| **0086 账户持仓** | **持仓盈亏详情** | 针对真实持仓标的，显示持仓股数、成本价、盈亏率 % 与浮动盈亏额 $ |

## 三、动态参数交互设计 (Interactive Sliders)

页面顶部新增双滑块与快速预设模式，**所有计算在前端以毫秒级响应，拖动即刻全表重算**：
1. **参数 1：目标涨幅阈值 ($T\%$)**
   * **可调范围**：**$5.0\% \sim 10.0\%$**（步长 0.5%）
   * **实操意义**：测试个股仅是微弱脉冲（5%），还是具备爆发出 7%~10% 大波段的能力。
2. **参数 2：持仓考察窗口 ($W$ 天)**
   * **可调范围**：**$1 \sim 5$ 天**（相当于 7 ~ 35 个常规交易小时）
   * **实操意义**：测试 1 天超短线隔夜胜率，对比 3 天与 5 天完整周期的波段兑现率。
3. **5 大快捷模式**：
   * `标准模式 (3天 5%)`：默认基准
   * `长波段 (5天 5%)`：宽限持仓周期
   * `强弹性 (3天 7%)`：筛选高爆发强势股
   * `翻倍主升 (5天 10%)`：捕捉超级龙头
   * `超短隔夜 (1天 5%)`：测试次日即达成 5% 的极速个股

## 五、盘中实操研判指引 (Actionable Playbook)

1. **“开门红 + 过去 3 天持续达标”的进攻标的**：
   - 观察 `今天-3`、`今天-2` 达成率均在 50%~100%（且标注绿底），同时今日开盘 10:30 与 11:30 冲幅为正、且成交量显著放大的标的（例如 ALAB、ARM、CRDO）；
   - 这类标的属于处于主升浪中的强动量龙，日内任何 1-2% 级别的回调都是顺势买点。
2. **“早盘砸盘 + 过去 3 天持续 0%”的避坑标的**：
   - 若 `今天-3`、`今天-2` 达成率全为 0%，且今天 10:30 入场后处于负收益或成交量萎靡；
   - 坚决不抄底，哪怕日内有脉冲反抽也视作诱多。
3. **盘中定时刷新**：
   - 在美东时间 12:30、13:30、14:30、15:30、16:00 各执行一次刷新脚本，页面会自动累加最新已完成小时的达成率与最大浮盈，动态监控持仓与自选股的强弱轮动。

# 连续上涨区间：路径形态分解与条件转移概率研究（范围界定 v0）

> 文件夹名 `uptrend_path_research` 是占位名，随时可改。
> 本文只做**任务理解与范围界定**，不含任何实现与结论。

## 1. 任务拆解

```
父任务：基于已观测序列，预测"未来出现连续上涨区间"的概率
   └── 子任务 A（本文件夹当前重点）：找到"最大连续上涨区间" —— 即把路径切成段，
       给出每一段的类型标签，作为父任务的因变量
   └── 子任务 B：在前序状态已知的条件下，估计进入各类上涨区间的条件概率 / hazard / lift
```

子任务 A 是**标注问题**（回顾性，允许用未来信息定标签）；
子任务 B 是**预测问题**（特征必须因果，触发时点之后的信息一律不得进入）。

这两件事必须分开做、分开验。混淆它们就是材料里说的那种"看起来很准、其实有泄漏"。

## 2. 子任务 A：什么算"连续上涨区间"

**三个参数分工严格分离（2026-09-24 修订，原 `θ=max(δ,A)·ATR` 已废弃）：**

| 参数 | 角色 | 移动支点？ |
|---|---|---|
| `delta` | 唯一结构参数。θ=δ·ATR，回撤超过 θ 才算这一段结束 | 是 |
| `min_amp` | 纯资格标记。段结束后才看够不够大 | 否 |
| `min_bars` | 纯资格标记。时长不足只打标 | 否 |

目标涨幅（8%）**不是分段参数**，只属于预测标签。

已明确：连续上涨**不是**每小时都涨。我理解为：**一段总体向上、期间允许有回撤、但回撤不超过某个容忍度的价格路径**。

因此需要一个可计算、可复算、可审计的定义。我建议用**支点（pivot）交替分段**：

```
log price y(t) = log P(t)
一个上涨区间 = [谷 t0, 峰 t1]，满足：
  (1) y(t1) - y(t0) >= A      （最小振幅，用 ATR 或 σ 归一化，不用绝对百分比）
  (2) 区间内任意时刻的 running max 回撤不超过 δ·ATR（或 δ·σ）
  (3) t1 - t0 >= T_min        （最小时长，按时间尺度声明）
  (4) t0、t1 都是"不可延伸"的：往前/往后延一段就破坏 (1)(2)(3)
```

(4) 就是"最大"的含义——**极大区间（maximal），不是"涨幅最大的那一段"**。
这里有个必须先定的歧义：你说的"最大"是指
(a) 数学意义上的极大（不能再往外扩），还是
(b) 涨幅最大的区间，还是
(c) 持续时间最长的区间？三者会给出不同答案，我默认按 (a) 实现，同时输出 (b)(c) 的排序表。

支点交替分段的好处：每个小时点**有且仅有一个**状态（上涨段内 / 下跌段内 / 盘整），
天然形成材料里那张状态图，也天然避免同一段行情被反复计数。

**这个定义本身用了未来信息**（要知道回撤有没有超过 δ、峰在哪里）。
这是允许的，因为它只用于生成标签。但必须写清楚：标签允许后视，特征不允许。

## 3. 子任务 B：父任务其实是两个不同的预测问题

材料里区分得对，我照抄并确认：

| | 问题 | 形式 |
|---|---|---|
| B1 启动 | 现在还没涨，未来会不会进入上涨区间？ | P(进入上涨 \| X_t) |
| B2 延续 | 已经涨了一段，还会继续 / 加速吗？ | P(继续 \| 已观测 prefix, X_t) |

B1 才是 survival / hazard 框架（"在尚未上涨的条件下，接下来 h 小时进入上涨的瞬时概率"）。
B2 是 prefix-conditioned forecasting，和抄底完全不是一回事。
**两者不能混在一个准确率数字里**，否则一半信号来自"已经在涨了所以接着涨"。

同时，因变量不该是二值。按材料的建议，预测一个**未来轨迹分布**：
快速上涨 / 慢速上涨 / 回踩后再涨 / 横盘 / 下跌。这才对得上"每一种上涨都建模"。

## 4. 形态参数化：先连续、后聚类

不要人工发明分类表。先把每段上涨归一化成连续特征：

```
R          总涨幅（log 收益）
T          持续时间
v̄          平均速度 = R / T
v1,v2,v3   时间归一化到 τ∈[0,1] 后前/中/后三段斜率
Δv         (v3 - v1)          → Δv<0 先快后慢，Δv>0 先慢后快
Curvature  二阶特征
Efficiency 路径效率 = |R| / 路径总变差
MDD        段内最大回撤
Vol        段内已实现波动
```

然后用 clustering 看市场里自然存在几种稳定形态，再给名字。
材料里"先快后慢 = v>0, a<0"和"先慢后快 = v>0, a>0"就是 Δv 的特例，我按 Δv 连续量实现，
分桶只用于展示，不用于建模。

## 5. 我会额外加重的三条（材料里提到但值得更强调）

1. **同一事件的重复计数**：小时级预测点在同一个区间内高度相关。之前那份 8% 研究里，
   R3 规则在"点位级"看精准率 50.9%、"事件级"去重后掉到 43.5%、lift 从 ×1.21 变 ×1.04，
   边缘基本是重复计数造出来的。所以本项目**主口径必须是事件级去重**，CI 要用分块 bootstrap
   （按区间聚块），不能把 5 万个点当成 5 万个独立观测。
2. **右端删失**：最后一段上涨还没走完，不能当标签，也不能当负样本，要单独记录。
3. **波动率归一化是定义的一部分**：δ 和 A 用 ATR/σ 表达，否则模型学到的是"高波动股票"而不是形态。

## 6. 明确不做的事

- 不用 P(前序 | 上涨) 冒充 P(上涨 | 前序)；必须有全机会集分母和 Lift。
- 不用未来信息定义"当时可知"的特征（如"此处是底，因为之后 5 天没破"）。
- 不追求一套脱离时间尺度的通用分类；每个结论必须声明时间尺度。
- 不把所有股票无归一化地混在一起。

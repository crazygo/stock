`causal_quality_training_v5` 的工程须再读 [19 · 拟合前质量股票池登记](docs/19_quality_training_v5_registration.md)及 [20 · 真实训练与评价证据](docs/20_quality_training_v5_evidence.md)。v5 仅使用每行决策前已成熟/可用的过去 63 个官方交易 session，至少 40 个完整六时点股票日且日等权历史触及率严格 >60% 才属主质量组；历史高率不能当作当前实际胜率。两折真实训练均未通过预登记概率或行动证据门槛，保持研究状态和零正式行动。2026 外层已暴露；不能按外层漂亮候选改写冻结选择。新训练/校准策略须另升版本并使用新目录，不覆盖 v5 证据。

## 不可破坏的约束

1. 目标是 **开盘后、从延迟后入场价格起算、1170 个正常交易分钟内触及 +5%**。不是从昨收、今日开盘、谷底算涨幅；不是当天热度分数。
2. 主采样仅 11:30、12:30、13:30、14:30 ET。所有合格股票、日期、时点均保留，包括负例；不能按未来成功筛选样本。09:30 不采样，10:30/15:30 只能开独立协议版本。
3. 一切输入满足 `event/bar_end <= feature_cutoff` 且 `available_at <= decision_at`。标签窗口、最终上涨段、当天最终达成率不得进入输入。
4. 正负样本统一等完整窗口成熟。未成熟、缺失、停牌和无成交分别记录；禁止填 0，禁止只收提前成功者。
5. 股票池必须带当时可知的成员历史；只有今天名单时只能做明确标记的当前池回溯。基准 ETF 不自动成为候选股。
6. 同日全部股票、小时同侧切分；只能前向训练。按真实标签结束和可用时间 purge。标准化、填补、特征选择、校准与阈值不得偷看外层评估。
7. 固定数据、配置和模型后，追加未来数据不能改写历史特征、概率和信号。模型重训必须另存版本。
8. 不接自动下单，不调用交易写接口，不把分数伪装成校准概率，不把触及概率说成盈利概率。
9. 60m 不能制造 5m 成交价、精确触及时间或真实 VWAP。数据不足时输出无法计算及原因。
10. 不覆盖旧研究，不改动无关 WIP；只在明确文件范围内提交。不要创建虚假的已训练模型或通过报告。
11. 本轮遵守 [行情双路线方案](docs/07_model_training_plan.md)：H=历史背景、A=延长时段、B=开盘后路径；HAB 为主方案，LightGBM 与小型多尺度 TCN 同时进入首轮研究。B0/B1 保留，逻辑回归不是前置门槛。
12. 本轮预测输入仅为行情及构造它所需的元数据；事件/文本、成熟 cohort 达成率和 Base Heat 输出不进入主实验。盘前可能反映事件是待检验假设，不得人工指定更高权重。
13. 两路线使用同范围观察和相同时间折；执行 H/HA/HB/HAB × 两模型对照。输入、超参、提前停止、校准和阈值只在内层选择，保留失败 trial；按样本外概率质量、稳定性与成本选型。

## 改动与交付

- 开工摘要写出本次里程碑、契约版本、所用数据和验收方法；这是工作记录，不是额外审批流程。
- 先填写 `templates/experiment.md` 再运行真实实验；登记失败和负结果。目标、采样、期限、标签、特征族或选择规则的语义修改必须升版本，不能按测试结果偷偷改 v1。
- `market_dual_track_v2` 是新增模型方案；目标/入场/标签仍引用 v1。新增特征另建 v2 schema 与训练配置，不把现有 `configs/v1.json` 或 synthetic smoke 宣称为双路线训练器。
- 新数据获取先读仓库 `.agents/skills/r2-market-data/SKILL.md`，沿用本地 → R2 → OpenD，禁止训练过程中隐式联网或自动上传。
- 本目录新增特征必须登记可用时间、缺失处理，并补“追加未来/迟到数据不污染过去”回放检查。
- 合并前运行 README 测试和 smoke；真实模型另需对应里程碑证据。汇报应区分代码检查、合成验证、历史样本外、前向纸面验证。
- 已查看、选择、调过参的时间段必须登记为 exposed，不能再命名 untouched holdout。
- 不要为了本工程重启现有 Web 服务或 OpenD。PID、包版本和行情覆盖只以当次读取为准。

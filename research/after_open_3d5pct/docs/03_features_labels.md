# 03 · 样本、标签和特征

## 样本与入场

先根据当时股票池生成全部合格 `symbol × session_date × cutoff`，再计算特征和标签。新 IPO、缺足够历史、停牌、缺价、迟到数据都保留拒绝原因及分母计数。不能只保留模型感兴趣或未来有行情的样本。

11:30 为主时点；12:30/13:30/14:30 为更新。正常时段以外及半日市收盘后不产生样本。保留所有合法小时，同一股票重复预测可观察概率变化；评估按日期/时间块处理相关性，交易模拟才按单独仓位状态机约束执行。

默认时间线：

```text
09:30 ── 已完成的前两小时 ── 11:30:00 cutoff
                                11:30:30 decision（出结果）
                                11:32:30 最早人工下单（+120秒）
                                11:35:00 entry（首个5m Open代理）
                                         └─累计1170正常交易分钟→ horizon
```

不能跨缺失的预期 entry bar 偷偷选更晚的有利价格；默认同一交易时段，不滚到下一日开盘。`entry_max_wait_minutes=5` 限制最早可下单时间之后的额外等待。

5m Open 只是假设成交代理，不保证可成交。人工延迟以独立配置做 1/2/5/10 分钟敏感性；成本、点差和滑点用单独执行价格场景，不修改主标签后又把不同口径合并。11:30–11:35 VWAP 不能用作 11:32:30 之后才可能成交的默认价，因为其中包含行动前交易。

小时数据若做先行探索，必须建新契约 `hourly_proxy`，如明确下一根小时 Open 的实际开始时间和延迟局限；不得用小时线伪造本工程的 11:35 成交。

## 标签定义

以延迟后的 `P_entry` 为锚：

- `hit = 1[max(high in full horizon) >= P_entry × 1.05]`。
- `MFE = max(0, max(high)/P_entry − 1)`。
- `MAE = min(0, min(low)/P_entry − 1)`，因此 MAE 为非正数。
- `time_to_hit` 保存首次达到目标的 bar 区间上下界，单位是入场后累计正常交易分钟；5m high 无法给出精确秒级时间。
- 同时保存 `label_end_at`、`label_available_at`，后者不早于窗口结束和全部所需行情可用时间。

连续三个正常交易日、无半日和节假日时：周四 11:35 入场，1170 分钟后为下周二 11:35。半日市实际分钟不足，终点自然后移；不简单计算“入场日算第一天”或“第 3 天收盘”。

| status | target / MFE / MAE | 训练处理 |
|---|---|---|
| mature | 完整且已可用，hit=0 或 1 | 可以进入监督训练，但仍需通过 split purge |
| pending | null，即使已提前触及 +5% | 只保留进度，等完整窗口；避免只提前纳入正例 |
| insufficient_data | null | 保留原因和覆盖统计，不当作失败或删除后隐瞒 |

未命中的 time-to-hit 是窗口末端右删失，不能填 0，也不能只在命中者中报告“平均耗时”而不说条件。现阶段主任务不用止损；跌后再涨仍可 hit=1，MAE 会保留途中风险。将来若建止盈止损策略，同一 bar 同时触及两侧必须用更细数据或保守/不明处理，不能假设有利顺序。

## 特征登记（完整训练管线在 M2；当前只实现前四项）

| 特征族 | 定义/来源 | 可用时间及防泄漏要求 | 当前状态 |
|---|---|---|---|
| `return_since_open` | 截至 cutoff 的 close / 正常开盘 Open −1 | 只用当天完成并可用的 bar | 已实现 |
| `range_since_open` | (截至当前 high−low)/Open | 不可用全天 high/low | 已实现 |
| `distance_from_high` | 当前 close / 截至当前 high −1 | 当日运行最高点，不是收盘后极值 | 已实现 |
| `volume_since_open` | 开盘至 cutoff 累计 volume | 检查逐条覆盖，不把缺条当 0 | 已实现 |
| Gap / continuation | 正常 Open/前一完整日 Close−1；首1h/第2h收益、回撤和幅度/滞后ATR | 明确隔夜与盘中贡献；ATR只用此前完成日 | 待实现 |
| VWAP | 当前 close / 当前真实累计 VWAP−1 | 仅同尺度真实 turnover/volume，缺失保留 mask | 待数据审计 |
| RVOL / participation | 当前累计量 / 前20个完整交易日同 elapsed-minute 累计量中位数；群体 RVOL>1 比例 | 分母不含今天或未来，半日按相同已过分钟对齐 | 待实现 |
| Breadth | PIT池内上涨比例、站上VWAP比例、收益中位数、离散度 | numerator/available_denominator/eligible_denominator一起存；当前存量股票不回填历史 | 待实现 |
| Relative strength | 股票开盘至当前收益−QQQ同段收益；行业代理超额 | 相同区间、时间和复权基准；行业映射也要PIT | 待实现 |
| 近期状态 | 已完成的1/3/5/10/20日收益、波动、量变化 | 截至上一完整交易日；盘中特征另列，不拼入今日最终日线 | 待实现 |
| Cohort progress | 之前两个session的固定11:30池内模拟入场 cohort；当前收益中位数、已触及1/2/3%比例、MFE_so_far、underwater、age | 成员与entry当时冻结；只观察到cutoff；正负/未完成全保留 | 待实现 |
| 成熟历史环境 | 截至decision真正成熟的历史 cohort 达成率 | 不能包含昨日/前日未到期结果；窗口分母固定并报告 | 待实现 |
| 事件 | 已公开业绩日期距离、已发布信息 | 发布/可用/修订时间全具备才启用；非必需首版依赖 | 后置 |

盘中还需保留前两小时固定路径特征和“截至当前”动态特征，区分开盘跳高后耗尽与盘中持续启动。不要预设 Gap 大就是坏、强就是好；由消融和样本外效果检验。

cohort 初版采用全部合格股票在前两日 11:30 的固定模拟入场，不按模型命中阈值选择，避免随模型版本循环变化。每个 cohort 的 +1/+2/+3% 是 **到目前为止的进度**，不是 3 日最终标签；同时保留 age、覆盖率、缺失数。缺数据不能把剩余可见强者的比率当整组健康度。

如果进一步训练 Base Heat 模型，再把其输出作为主模型特征，训练行的 Heat 必须来自时间前向 OOF 预测，线上只能用当时已训练版本；不能把同一批样本拟合出的热度回灌自身。

所有特征必须登记：公式、所需原始字段、截止时间、最晚可用时间、lookback、单位、缺失原因、数据版本。主模型不使用“可靠度”人工分数替代校准概率；缺失/陈旧时允许输出 unavailable。

# C 有群 R1：优化收敛诊断（拟合前登记）

- 数据、标签、5m/60m/日级输入、六个有类型的群槽位、purge 和 train/inner/outer 切分完全沿用冻结 v6.1 数据与配置。全部 2026 日期已暴露。
- R0 只训练 5 epochs，主目标内层 Brier 从 0.181644 连续降至 0.157525；训练 loss 从 0.577425 降至 0.480054，最后一轮仍明显改善。这个数值支持“训练尚未收敛”，不能据 14,793 参数判断容量不足。
- **唯一主要改变**：同一模型、AdamW/学习率/批量与九任务等权损失，最多 40 epochs、patience 6，以内层主目标 Brier 选择 checkpoint；固定 seed 3566。R0 是既有短训练的必要对照，不再加实验。
- 保存每 epoch 的 train loss、train 与 inner 主目标 Brier、原始和单调投影概率；若出现先改善后反弹，则据内层选停止点。不得查看 R1 外层结果来决定 R2。
- 当前 patch attention 带位置编码，理论上同端点不同路径可区分，但未验证是否能有效利用；R1 不加入数学函数或未来形态标签。R2 的形态实验由 R1 内层证据决定。

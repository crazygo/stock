# R3 内层分析（外层统一揭盲前）

加入六类群本周相对既往有效周的显式差分后，seed 3566 的内层主目标 Brier 为 0.154499（最佳 epoch 11，参数 16,593），seed 81173 为 0.155487（最佳 epoch 12）；二者均弱于 R2 的 0.151063。两个种子的内层预测均值分别 0.2524、0.2241，实际率同为 0.2281，说明初始化会影响整体概率水平。训练 Brier 分别 0.168829 和 0.167820，均低于 R2 的 0.170989；训练进步没有迁移到内层，新增群变化可能提供了过拟合入口。这个负结果只属于已经暴露的开发样本；不据此删除 R3 制品。

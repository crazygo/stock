# R1 拟合前登记：相对价格坐标

- 固定冻结数据、九目标、purge 和 11:30/11:35 定义；不读取 `xday`，不从其他输入重建日线。仍保留原有五群和 QQQ。
- 唯一主要改变：对 5m/60m 两个输入分支，将 OHLC 的 log(Open) 改为相对于该分支首个有效 Open 的 log 价格并乘 10；通道 0–3 的 log 回报乘 50。由此把绝对价格水平对卷积的支配转为相对路径坐标，且保持原始成交量、时间、mask、群输入不变。无效位置归零。首 Open 之前的跳空未知，不制造窗口外价格。
- 固定 seed 3566、AdamW 0.001、weight decay .01、batch 128、九目标等权 BCE、最多40 epochs、patience6；按内层主目标投影后 Brier 选择 checkpoint。R0 是必要对照；本轮无第二候选。
- 每 epoch 记录训练 loss、训练与内层主目标 Brier/AUC、预测分位数及九目标内层结果。若排序未恢复，R2 优先考察路径形态是否可被 patch 读出；若排序恢复，R2 分析群或多任务剩余瓶颈。外层在 R3 完成前不评分。

## R1 必要诊断对照（R2/R3 已登记后、评分外层前补记）

R1 同时比 R0 增加了训练上限和耐心，因此不能把恢复排序全归于输入表示。固定 seed3566、原始未归一化 C 无日级结构与输入，使用和 R1 一样的 40 epochs/patience6，其他优化与数据不变；只比较训练/内层曲线和概率，不用外层选择。此为 R1 的唯一诊断对照。相对价格通道与回报放大本身也属于一组表示改变，不能从这项对照拆开各自因果贡献。

## 内层结果（完成后记录）

R1 seed3566 训练28.25秒、12,537参数、最佳epoch14；内层3日+5%实际率0.22814、预测均值0.25739、Brier 0.148922、logloss 0.46316、AUC 0.7643。训练九任务 loss 由epoch1的0.58886下降至epoch14的0.45346；主目标训练Brier 0.20375→0.17338，内层0.17847→0.14892。epoch20训练Brier进一步降至0.16974，内层Brier则为0.15076，符合停止后的轻微泛化回落。

原输入同预算对照最佳epoch6，训练14.70秒，内层Brier 0.156990、AUC 0.7311。相对R0短预算的内层Brier改善0.02048，5日期块探索区间[−0.03111,−0.00552]；R1进一步相对对照改善0.00807，区间[−0.01558,+0.00229]跨零。故已确认短训练预算是R0重大瓶颈；相对价格+回报尺度为有利点估计，但不能据16个日期断言稳定，也不能分别归因两项尺度子变换。

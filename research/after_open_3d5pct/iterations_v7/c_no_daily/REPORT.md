# C 无日级路线：v7 三轮真实拟合与已暴露外层评分

本路线保留原有五个策略群与 QQQ，包括可使用126日因果统计的趋势群；逐股模型只读取原有 5m（七个完整日+当前前缀）和 60m（30个完整日+当前前缀）序列，从不读取 `xday`、拼造日K或补充更长价格史。冻结清单 SHA256 为 `56b3d04def58b72e388f98e41c0d72df1b996aef3ecf7c8ee6325349082a143b`。共9,222个样本；训练/内层/外层5,606/1,521/1,140行、58/16/12个ET日；相同11:30信息、11:35代理入场、九个1/3/5日×+3/+5/+8%触及目标与最长标签可用时间purge。所有2026日期已暴露，此为历史开发评分，不是独立验证或交易概率发布。

### R1 同预算诊断对照

R0 只有最多5轮、patience2，epoch1最佳且只训练到epoch3。为拆分训练预算与输入表示，R1唯一必要对照沿用**原始未归一化输入**和相同seed3566，但给40轮/patience6；仅查看内层，最佳epoch6，Brier .156990、AUC .7311。该对照前3轮训练loss/内层Brier与R0相差不超过数值舍入（epoch1内层.177473642），证明训练协议对齐。相对R0内层Brier差−.020484，5日期块区间[−.031105,−.005519]；R1相对此对照差−.008068，区间[−.015579,+.002291]。因此短预算可解释R0逆序的大部分，R1的坐标/收益放大组合还有正向点估计，但区间跨零；不能把恢复排序全部归于归一化，也不能把“去绝对价格”与“放大回报”两项单独归因。

## 曲线表达与未解决瓶颈

输入通道0为log(Close/Open)、3为log(Open/前Close)、12为log(Open)/5；完整Close必须用`5*channel12+channel0`还原。R1把每个分支首个有效Open设为原点、缩放相对价格和OHLC回报；仍保留5m/60m时序与mask。R2只用已观察bar重建连续Close路径，分三段收益、最大回撤、路径效率和早晚波动；跨有效bar的缺口由相邻Close差纳入，首根没有虚构窗外跳空，无效尾部不贡献。构造测试证实同端点不同路径会得到不同摘要，但真实内层九目标Brier全部变差。数学函数能表达历史路径，并不证明其预测未来触及的能力。

R1训练主目标Brier从epoch1的.20375降至最佳epoch14的.17338，内层从.17847降至.14892；R2最佳epoch训练Brier进一步降至.16924，内层却升至.15433，提示附加摘要更易拟合训练期。R3两个种子内层都略低于R1，未支持当前主目标加权。余下瓶颈为日期数少、目标率时期变化、九任务长短期差异、概率可靠性局部偏差、历史成员/周群回填和真实接收时刻缺失；不能从本轮判断无日级路线在真正前向环境是否优于有日级或B树模型。训练期完整126日逐股日线覆盖23.47%，内层/外层约97.9%；本路线不读取它，但时期变化仍可能影响群统计与标签率。

## 制品、重放与复现

- 五次本轮拟合（含R1同预算对照）合计约112.0秒，远低于15分钟；每次≤40 epochs、patience6、单线程，未做网格。R1/R2/R3参数量12,537/12,921/12,537。每个`runs/v7_c_no_daily_r*`有模型、训练/内层逐epoch曲线、内层九目标逐行原始与投影概率、拟合时源码/数据/配置 SHA256。R0 checkpoint保留在旧冻结目录。
- `runs/v7_c_no_daily_final_20260927/`在全部训练后一次性写出R0–R3外层及内层逐行 `sample_id`、九目标`y/raw/p`；重放内层与原拟合保存概率最大绝对差为0。`results.json`还保存所有目标的Brier/logloss/AUC、十桶、ECE、拟合参数/耗时/哈希及5日期块配对区间。R1同预算对照未评分外层。
- 四个边界测试通过：首有效Open原点、收益与缺口语义、同端点不同路径、无效尾部不改变形态。没有新增行情获取、R2上传、自动交易或服务变更。

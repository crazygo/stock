# C 无群 R3 拟合前登记

R2 加入三尺度因果路径描述后，内层主目标 Brier 由 R1 的 0.150788 升至 0.154024；内层 AUC 0.750→0.739。形态在 5日+3% 与 5日+5% 的 Brier 分别改善 0.004856/0.002179，主目标和部分稀有阈值退化；R2 训练第21轮主目标 Brier 0.169173、内层0.154024，后续训练继续改善而内层波动。这个方向支持“九任务竞争或新增描述过拟合”作为待测解释，尚不能证明多任务负迁移。

**唯一主要改动**：保留 R2 的本股三尺度 patch 与形态、参数容量和优化器，将九目标 BCE 中主目标3日+5%权重从1设为3，其余八项仍为1，按总权重归一化。固定 seed3566 与 81173，各最多40 epochs、patience6，按内层主目标投影 Brier 早停；无网格、无其他拟合对照。逐项报告九目标损益，主目标改善若牺牲其他目标须说明。R3 之后一次性打开外层 R0/R1/R2/R3，双种子都保留，不能按外层选择。

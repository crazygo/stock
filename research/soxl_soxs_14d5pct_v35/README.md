## 从行业价格状态扩展到已披露业绩

v34 增加行业同步、参与度和领涨扩散后没有改善预测。本轮检查价格之外的公开财务信息：营收增长是否加速，利润率同比是否改善，以及近期是否有业绩披露。它们可以在当时观察，不需要事后给月份贴“热门”标签。

沿用八只固定参考股 NVDA、AMD、AVGO、MU、AMAT、LRCX、KLAC、INTC。本地已有八份 SEC Company Facts 与八份 submissions，逐份核对原取得账本的 SHA、发行人 CIK 与证券代码。没有下载新原始行情／财务、上传 R2 或券商下单。该池不是历史 PIT 行业成分；Broadcom 公司总营收包含软件，不能把它解释为纯半导体业务需求。

本轮遵循 [stock-news-catalyst 技能](/Users/admin/.codex/skills/stock-news-catalyst/SKILL.md)对来源及时间的区分，实际接入的是财务披露状态与已发生披露的日期信息。未取得历史分析师一致预期、指引完整时间线或全量新闻，所以没有“超预期幅度”、未来财报日程或新闻情绪特征。

## 历史可用日期是明确的假设

[SEC API 文档](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)说明 submissions 提供发行人披露历史，Company Facts 汇集标准分类、公司整体层面的 XBRL 数据；当前下载的聚合数据不是当年接收快照。[SEC 时间说明](https://www.sec.gov/files/about/webmaster-faq.htm)区分报告期、官方 filing date 和 acceptance time，并说明没有文件首次可在网站读取的时间戳。

每条财务事实必须与 submissions 的 accession、表格类型和 filing date 一致。使用假定可用日：

```text
max(官方 filingDate, acceptanceDateTime 字符串的日期部分) + 1 日历天
该日 00:00 ET 起可进入输入
```

这样等待两个日期都过去；UTC 日期比 ET 日期晚时会额外延迟。本轮不把 acceptance 秒数当作首次公开时间，也不把 2026 年 10 月真实缓存取得时间回写成历史接收记录。未知 accession、元数据不一致、币种不符的行保留排除计数，不填零。

已公布的修订仅在它自己的假定可用日以后生效。每次查询只取当时可用且报告期已结束的事实，保留原始标签、数组位置、数值、期间、披露批次和可用日期。对于 SEC 事后更正以及当前聚合接口的历史可得性，本轮仍属于带日期假设的历史重建；没有证明实时延迟或当年全量接收覆盖。

## 财务期间与字段

只用 USD、标准 US-GAAP、10-K／10-Q 及修订。营收沿用四个已登记标准标签的优先级，净利润使用 NetIncomeLoss，缺少同一期间值时允许 ProfitLoss 标签参与归一化。

两种净利润口径并不完全相同：本次 Broadcom 为包含非控股权益的 ProfitLoss，其他七家为归母 NetIncomeLoss。已检查全部可用的 2,875 个公司／日期同比比较，当前期与上年期标签一致；跨公司绝对利润率口径仍有差异。本轮输入使用各公司同比变化，不将其宣称为同口径行业经营利润。

同一精确期间选择当时已知的最新 filing date，标签优先级处理同日重叠；同优先级／同日但数值冲突直接报错。60–120 日的直接季度优先；其余 121–400 日累计数减去同起点、同标签、结尾相隔 60–120 日的前期累计数推导单季，保留两项来源及较晚可用日期，禁止年度直接除以四。累计差值仍依赖会计基础可比的假设。

前一季度须与本季度起点相接（容许 1–7 天）；同比期结束日相隔 350–380 天、期间长度差不超过 10 天。利润和收入须有完全相同的起止日。营收必须为正，最新报告期结束距查询不超过 183 日。

源数据准备时，营业利润方案因 KLA 缺少标准字段而不可用；改用净利润后，Broadcom 的单一 NetIncomeLoss 标签仍不完整。补入旧财务解析器已支持的 ProfitLoss 映射后，仍保留 2024-12-23 至 2025-03-12 的 53 个官方日期缺失，不以其他利润项目或零值替代。这些源数据选择发生在登记和任何新策略结果之前，初始探针日志均保留。

## 八项输入与每日训练

| 输入 | 固定定义 |
| --- | --- |
| 营收增长 | 各股 `log(本季收入/上年同季收入)` 裁剪到 [−2,2] 后取八股均值 |
| 增长广度 | 八股营收增长为正的占比 |
| 增长加速 | 本季营收对数同比减前一季度的对数同比，裁剪到 [−2,2] 后取均值 |
| 加速广度 | 八股增长加速为正的占比 |
| 利润率改善 | 本季净利润／营收减上年同季比率，裁剪到 [−1,1] 后取均值 |
| 改善广度 | 八股利润率同比变化为正的占比 |
| 近期业绩披露 | 最近五个官方交易日内已假定可用的 8-K／8-K/A Item 2.02 发行人占比；周末映射到下一官方交易日 |
| 披露新鲜度 | 各股 `exp(−距所用比较事实最晚可用日期的日历天数/63)` 的均值 |

所有新输入在同日四个查询内不变；原价格量价输入仍随时点更新。每股只出现 6–7 个不同的最新报告期状态，不能把每日重复财务值当成几百份独立业绩证据。

全历史 1,459 个查询中 1,248 个财务输入可用，211 个查询因上述 53 日期缺失而不可用；一至四月 328 个查询全部可用。三组新基础模型使用相同的原输入可用且八家公司财务完整的历史成员。主路线旧 19／31 项价格输入加八项，成为盘前 27／盘中 39 项；状态对照只加前六项（25／37）；匹配基础对照保留旧 19／31 项。另保留原样 v32 对照，区分历史覆盖变化和新增输入的作用。

三组均每天 00:00 ET、按四个时点分别重训。只使用此前完整成熟的双 ETF 日期前缀，遇到未知结果立即停止，不跳过亏损或未成熟日；至少 120 日期。126 日期半衰期权重总和归一到日期数，加权标准化；Ridge α=100 分别学习净对数收益共同项和双边优势幅度，损失加权 LogisticRegression C=0.1 学习方向，恢复两只 ETF 原始收益分数。每个模型及当时发出的原分数保留，不用未来模型重写。

各版本使用自己的历史原分数做 v32 部分共享残差校准：每时点独立截距／斜率，斜率均值及差异惩罚均为 20。整日全部双边结果成熟后进入共同日期前缀，最近 120／至少 60 日期，63 日期半衰期；本开发期实际 96–120 日期。199 次十日期循环分块，每次重算标准化和模型。点估计减共同 90% 向上扰动余量仍为正才买，否则弃权；该余量不是月收益保证。

# v36 · 每日学习校准修正幅度

**预测误差略降，三月亏损没有解决。** 主路线一至四月净资金收益为 **+25.07%、+3.40%、−3.05%、+15.44%**，算术均值 **+10.21%**；24 笔完成交易，17 次止盈、7 次止损。与 v35 基本相同，未通过每月非负要求，没有运行新的五／七／九月回归。

## 检验什么

v35 引入当时假定可用的营收、利润率和披露事件，降低了原始预测误差，但随后校准使误差回升。共同收益 C=(SOXL+SOXS)/2 的误差改善，方向优势 D=(SOXL−SOXS)/2 的整体误差变差。本轮检查能否仅凭过去已经成熟的反馈，减少有害的校准修正。

这不是新发明的混合算法。[v18](../soxl_soxs_14d5pct_v18/README.md)已经试过 C／D 有界混合，后续 v19 离散选择在指定月份失败。本轮迁移同一标量损失到新的财务模型、四个时点和更早成熟的双边反馈；新增两层拟合共同按日期重抽样，并保留原校准风险余量。没有按三月或事后表现较差的时点设例外。

基础算法仍为每日重训的 Ridge 与损失加权 LogisticRegression，四时点部分共享残差校准仍为带惩罚的线性模型；本轮新增的只是有界二次损失修正权重。复用的是历史当时发出的原始和校准分数，逐项核验 v35 交付记录中 1,874 份文件 SHA；这不等于把某个月的模型一直用到九月。基础模型原有训练时间约束不变。

## 每日反馈与预热

每天 00:00 ET，只允许此前各时点、双 ETF 结果均已成熟的完整日期前缀进入。遇到首个未知或尚未成熟日期停止，不跳过去使用后面的结果。其间最近 120 个日期还必须有当时实际发出的完整校准预测，至少 60 日期才能学习修正。

预检查发现源模型最早在 2025-11-05 发出可校准预测，一月前只有 39 日期。此发现发生在新回放之前，因此预先登记：不足 60 个成熟日期时，适配路线保留源模型的点估计、余量及抽样预测，权重为 1；原始输入或源模型不可用仍不操作。实际自适应从 **2026-02-04** 开始，共 60 日期、240 查询；开发期前 88 查询沿用源模型。仅点估计诊断始终移除余量，单独展示。

历史两个专家均使用当时发出的值，不能把今天拟合的模型回填成历史专家预测。训练日期、成员、原始分数、校准分数和每日权重均保存。

## 修正公式与不确定性处理

每个时点分别对 C、D 选择校准权重 a：

```text
delta = 历史校准预测 − 历史原始预测
residual = 历史实际净对数收益 − 历史原始预测
A = Σw delta²；B = Σw delta residual
neff = 1 / Σ(按原日期合并后的归一权重)²
lambda = 2A / neff
a = clip((B + lambda/2) / (A + lambda), 0, 1)
若 A ≤ 1e−16，a = 0.5
当前预测 = 当前原始预测 + a × (当前校准预测 − 当前原始预测)
```

这等价于有界二次损失加 `lambda(a−0.5)²`。沿用 63 日期半衰期，每日权重先均分到真实三个／四个时点；每个头内部归一。跨时点共享对照仍按日期计算有效样本数，不能把四次查询算成四倍独立证据。测试另用 [SciPy 有界最小二乘](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.lsq_linear.html)复核标量解，实际运行使用上述闭式解。

当前残差校准与修正学习的历史起点不同，重抽样先取两组历史日期的有序并集，做 199 次十日期循环分块，种子为 `826+ET日期序号`。同一原日期的重复次数同时作用于两层拟合；各层保留自己的原始时间权重及样本归一，重新估计标准化、校准系数、有效日期数和混合系数。不是把不同日期碰巧相同的行号配对。

恢复双 ETF 收益分数后，计算所有抽样相对点估计的双边最大向上偏离，取非负的较高法 90% 分位作为联合扰动余量。**最终余量取它与原 v35 余量的较大者**，不能通过缩小修正自动放松旧风险门槛。点估计减余量的最大值仍大于零才允许买入，否则弃权。两者相同优先 SOXL。

原始基础模型的参数不在这次重抽样中重训；它量化的是这两层校准的经验扰动，既不是完整预测置信区间，也不是每月不亏损保证。240 个启用查询中，102 个由原余量下限决定，其余由联合扰动余量决定。

## 合约与验收保持

四时点为 09:25:30、10:05:30、10:35:30、13:05:30 ET，覆盖盘前，半日市遵循官方收盘。已完成行情加延迟，随后下一根常规盘五分钟 Open 模拟入场。买 SOXL／SOXS 或不行动，附带 +5% 止盈、固定 6% 保护止损；同根双触及先止损，不利跳空照实成交。最多 14 个包含买入日的日历天，在买入日加 13 天之前最后一个官方收盘退出。

连续资金账本保留费用、滑点、T+1、股息／拆股、跨月市值和未知占用，仓位只取 0／1，单持仓、同日不重复买入。v4 任意时点入口保持未获准状态。

原验收为五／七／九月完整净资金收益算术均值至少 10%，五月至九月全部月份非负。既有开发筛选为一至四月全部非负、月均至少 10%、至少十笔完成交易、完整覆盖。本轮主路线筛选失败，实际 CLI 已确认在创建回归目录前拒绝新指定月份回放。当前开发运行器尚未实现通过后的财务源扩展；若后续方法通过，必须补齐并核验源预测延续，不能把这项未实现功能宣称为已完成。

## 为什么没有解开三月亏损

| 净对数收益估计 | 日期等权 MSE |
| --- | ---: |
| 原始财务模型 | 0.00439015 |
| v35 校准 | 0.00441269 |
| 本轮各时点自适应 | 0.00437650 |
| 跨时点共享自适应 | 0.00436853 |
| 固定半混合，含预热 | 0.00424258 |

326 个成熟查询先按日内平均、再按日期等权，另外两个未知查询保留。固定半混合误差最低，资金收益却很差。这再次说明候选整体 MSE 与实际账户目标不同。

启用期方向 D 的平均校准权重：盘前 96.43%、10:05 为 83.41%、10:35 为 94.65%、13:05 为 91.78%。源校准在当时已有反馈中仍占优势，盘前有 50/60 日期直接采用完整校准；并非程序没有执行学习。

三月四笔实际入场仍为 3 月 4 日止损 −6.14%、13 日止盈 +4.90%、23 日止盈 +4.91%、30 日止损 −6.14%。4 日的方向权重为 1，共同收益权重降到 0.385，扣除更大余量后的优势仍为正 0.000186；30 日 C、D 均为 1，扣除余量后优势 0.002243。不能事后围绕这两个正值设置门槛并当作验证。

下一步应检查**当时排名第一、可能实际出手的子集**能否学到可重复的亏损识别信息，并与整体候选误差分开。v13 曾做过旧模型的第一名校准，不能忽略该失败历史；需在当前财务模型上明确新增信息和对照，不是继续尝试同一混合比例。风险规避仍需牺牲部分机会，也不能凭代码保证市场月收益非负。

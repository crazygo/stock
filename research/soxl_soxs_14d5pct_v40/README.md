## 三个学习器只改变方向关系

令两只 ETF 固定交易规则下的净对数收益为 rL、rS：

```text
C = (rL + rS)/2
D = (rL - rS)/2
M = |D|
q 的标签 = 1(D>0)，训练权重 = 时间权重 × M，再归一到日期数
预测 D = max(0,预测 M) × (2q−1)
预测 SOXL = 预测 C + 预测 D
预测 SOXS = 预测 C − 预测 D
```

C 与 M 继续用相同加权标准化及 Ridge(alpha=100)。q 是方向收益金额占比的估计，不是普通方向次数胜率，也不是盈利概率。两个 ETF 都可能亏损，方向相对正确并不表示适合买入。

| 路线 | 方向算法 | 用途 |
| --- | --- | --- |
| tree | HistGradientBoostingClassifier，深度 2、最多 4 叶 | 主路线，允许两项特征形成条件关系 |
| stump | 同算法，深度 1、最多 2 叶 | 只学习单变量分段关系的对照 |
| linear | LogisticRegression，C=0.1 | 原 v35 完整重训对照 |

提升树固定 80 轮、学习率 0.05、每叶至少 30 行、叶 L2=10、31 个分箱、seed=826；关闭随机留出与提前停止。参数在结果前登记，没有搜索。每个分时模型同日只有一行，但叶子最小行数不是时间权重下的有效样本数。参数含义参见 [scikit-learn 1.8 官方文档](https://scikit-learn.org/1.8/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html)。

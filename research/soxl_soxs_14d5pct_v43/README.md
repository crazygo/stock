**主路线未通过开发筛查，当前不行动。** 一至四月月均 −4.68%，二月 −20.56%；三类交互均未达标，没有新指定月份回归。

## 检验什么

v42 加入八项股票／债券风险输入后，原始第一名收益略改善但仍为负，实际资金结果变差。仅有一个加法系数，可能不能表达“相同风险环境在不同半导体状态下含义不同”。本轮检验这个具体限制，不使用事后热门月份、月份编号或未来行业达成率。

八项风险输入仍是 SPY、IWM−SPY、TLT−SHY、HYG−LQD 的五／二十日总对数回报。三项行业状态全部沿用此前可知定义：

| 状态 | 当时可知的计算 |
| --- | --- |
| 趋势 `sector_5` | SOXX 前五日收益 ÷（前二十日日波动 × √5），沿用原 ±5 截断 |
| 参与度 `breadth_5` | 固定八家公司前五日收益为正的比例 ×2−1 |
| 波动 `log_sector_volatility` | SOXX 前二十日日波动的对数，沿用原波动下限 |

这些状态均基于此前完成的日级历史，不把今日尚未完成的日线用于盘前。原来的盘中量价输入仍按该时点的完整数据计算。固定八家公司不是历史全行业 PIT 成分；宏观数据的历史可用性假设与 [v42 数据说明](../soxl_soxs_14d5pct_v42/README.md) 完全相同。

## 训练时确定交互基准

```text
每天、每时点：只取当时完整成熟的训练日期前缀
z_macro = (macro − 训练加权均值) / 训练加权标准差
z_state = (state − 训练加权均值) / 训练加权标准差
cross = z_macro × z_state
```

初始标准化沿用原 `StandardScaler`，退化常量列按其规则处理。保留全部主效应，追加指定交互列后，再用相同历史拟合最终标准化器及模型。当前查询和未来行都不能参与两次标准化的拟合；查询使用该份模型保存的基准。旧历史预测保持当时版本，后续训练不改写。

| 路线 | 追加交互数 | 盘前／盘中维度 |
| --- | ---: | ---: |
| joint，主路线 | 八项宏观 × 三项状态＝24 | 59／71 |
| trend | 八项宏观 × 趋势＝8 | 43／55 |
| risk | 八项宏观 × 参与度、波动＝16 | 51／63 |
| additive | 无，完整复现 v42 主模型 | 35／47 |

这里只增加指定二阶乘积，不展开全部特征组合，没有搜索交互组、阈值或正则参数。线性模型可通过乘积表达条件斜率；方法背景见 [scikit-learn 官方预处理说明](https://github.com/scikit-learn/scikit-learn/blob/main/doc/modules/preprocessing.rst)。该数学能力不证明股票预测有效。

共同净对数收益 C 与方向幅度 M 仍用 Ridge(alpha=100)，方向 q 仍用金额加权 LogisticRegression(C=0.1)；q 不是普通获利概率。至少 120 个成熟训练日期，126 日期半衰期。各版本使用自己的历史当时预测和残差，沿用四时点部分共享校准：最近 120、至少 60 日期，63 日期半衰期，199 次十日期整块重采样，固定惩罚 20。同日 ETF 和时点共同移动。

## 方向学习与入场校准分开看

326 个成熟双边查询、82 日期，两个未知仍单列。按日期等权的金额加权方向 Brier：无交互 0.26139，全部交互 0.27853，仅趋势 0.27214，仅参与度／波动 0.27067；三种交互都更差。全部交互的原始双边均方误差从 0.004446 升到 0.004647，原始第一名平均净对数收益从 −0.001579 降到 −0.005638。

主路线发出 34 条建议、覆盖 28 日期，平均净对数收益 −0.007580；实际买入 17 笔为 −0.012458；无法入场的 17 条为 −0.001708。相对无交互，实际新增八笔（四止盈、四止损），删除八笔（五止盈、三止损）。交互没有更好地识别亏损机会。

实际买入的主路线原始预测均值 +0.001745，经校准后均值 +0.015734，实际为 −0.012458；平均校准后高估 0.028191，超过平均误差余量 0.011351。无交互实际买入的原始预测 −0.006381、实际 −0.007169，原始均值接近；校准后却被提升到 +0.015761。总体校准均方误差略低，并不说明被选入场的预测可靠。

当前校准器仍只接收原始预测、旧行业状态和时点，没有直接接收新增八项宏观输入。本轮给基础模型增加交互并没有解决这一层的偏差。下一步优先单独检验校准是否需要使用同一组当时可知的宏观条件，采用 v42 简单基础模型与完全匹配的原校准对照，避免继续堆叠已经变差的交互。这个结构解释尚未通过新实验，不能称已找到有效修复。

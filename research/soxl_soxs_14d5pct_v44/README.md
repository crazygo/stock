# v44 · 宏观条件残差校准

本轮未达标。宏观条件校准主路线一至四月完整资金账本月均 **−2.18%**，一／三／四月亏损，16 笔中九次止盈、七次止损。20 项测试、独立方程与九份账本核验通过；没有启动新五至九月回归，没有买入准入。

## 问题与匹配对照

v43 基础交互使方向误差变差，而实际入场的预测经校准后仍显著偏乐观。源码核对同时更正了旧文档：v32–v43 使用的校准器直接输入只有两只 ETF 的原始预测和时点，没有行业状态或宏观字段；基础模型虽然使用这些信息，校准器只能通过原始预测间接接触它们。

本轮恢复简单基础模型，检验将同一组八项宏观输入直接交给残差校准是否有用。四组固定对照隔离两层的作用：

| 路线 | 基础模型直接读取八项宏观 | 校准层直接读取八项宏观 |
| --- | --- | --- |
| macro_context，主路线 | 是 | 是 |
| macro_plain | 是 | 否，精确复现 v42 |
| base_context | 否，原 v35 | 是 |
| base_plain | 否，原 v35 | 否，精确复现 v35 |

基础模型仍是 C／M 的 Ridge(alpha=100) 与金额加权方向 LogisticRegression(C=0.1)，没有 v43 交互项。两种基础输入分别为盘前／盘中 35／47 项和 27／39 项。同一基础模型在两条校准路线复用，重复输出不是独立市场证据。

宏观字段固定为 SPY、IWM−SPY、TLT−SHY、HYG−LQD 的五／二十日总对数回报。只用前一官方交易日及更早的收盘和过去除权记录；未新增数据、资产或时间窗口。价格代理不是真实利率或信用利差。数据、公司行动和历史交付时间假设沿用 [v42](../soxl_soxs_14d5pct_v42/README.md)，固定八家公司也不冒充历史全行业 PIT 名单。

## 只用当时预测和后来已成熟的误差

每日美东零点，从之前双边结果完整成熟的日期前缀中，取最近 120、至少 60 个具备历史原始预测的日期。当天和未来标签不进入；尚未完整成熟的前缀不能跳过。原始预测按历史当时的模型保存，后来的训练不改写旧输出。基础训练仍至少 120 日期、126 日期半衰期。

```text
Y_i = 当时建议对应的已实现双 ETF 净对数收益 − 当时原始预测
X_i = [当时原始 SOXL 预测, 当时原始 SOXS 预测, 八项当时宏观输入]
当前点估计 = 当前原始预测 + 预测残差
```

这里按全部合格历史查询学习，尚未专门对“最终被选为第一名”或“账户能够买入”分布拟合。因此必须另报实际入场偏差，不能用总体均方误差代替入场可靠性。校准数据使用原始历史当时预测的动机可参考 [scikit-learn 对训练与校准分离的说明](https://github.com/scikit-learn/scikit-learn/blob/main/doc/modules/calibration.rst)；本实验是净收益残差回归，没有使用其概率校准器，也不声称历史重叠样本相互独立。

每个时点用校准训练样本的加权均值／标准差归一化 X，小于 1e−12 的标准差置 1；重采样中权重为零的行先删除，不能影响归一化。每个时点有自己的自由截距和斜率，斜率向四时点均值收缩：

```text
目标 = 日期加权残差平方误差
     + 20 × ||四时点平均斜率||²
     + 20 × Σ ||各时点斜率 − 平均斜率||²
```

宏观校准有十个解释变量、每个输出四十个时点斜率及四个截距。原校准只有两个解释变量，继续调用原实现以精确复现。惩罚强度、63 日期半衰期和日期权重总和不变；同日三个或四个时点平分一个日期权重，不能用重复时点增加样本量。199 次十日期循环整块重采样，每次重拟合归一化、截距和斜率，同日两只 ETF 和各时点一起移动。没有参数搜索和日期专用规则。

## 动作、成本与验收

主路线从校准点估计减共同误差余量后的正优势中选择 SOXL 或 SOXS，否则现金。另登记主路线不加余量、仅盘前、冻结 v35、现金和双倍成本对照。误差余量是参数敏感度估计，不是未来每笔或整月收益下界。

四时点仍为 09:25:30／10:05:30／10:35:30／13:05:30 ET，下一可用常规盘五分钟开价加成本入场。+5% 附带止盈、固定 6% 保护止损、最长含入场日 14 个日历天；费用、滑点、跳空、同柱先止损、T+1、股息到账、单持仓、同日不重入、跨月盯市和未知资金占用全部保留。v4 任意时点分析仍不行动，代码不下券商订单。

原目标保持五／七／九月净资金月收益算术均值至少 10%，五月至九月各月非负。一至四月是预登记开发筛查：全部非负、均值至少 10%、至少十笔完成交易和完整覆盖；通过主路线及工程核验后才启动新指定月份回归。对照不能替换失败主路线，现金零收益不能算增长；已暴露历史称开发回归，不增设未来观察期门槛。

## 错误来自哪里

326 个已成熟查询按 82 个日期等权统计，两个未知查询保留。相同基础模型的两条校准路线拥有完全相同的原始预测，便于隔离校准的变化。宏观基础模型加入条件校准后，净对数收益均方误差从 0.00438549 升到 0.00457490；原基础模型对应从 0.00441269 升到 0.00458376。两种情况下都没有降低总体误差。

主路线 48 次建议分布在 27 天，日期等权的建议净对数收益为 +0.001590；真正买到的 16 笔均值却为 −0.005560。持仓占用和同日不重入改变了能执行的机会集合，不能把所有建议的正均值换算成账户收益。相对 v42，主路线新增 40、移除 18 次建议；实际新增十二笔中七止盈五止损，移除十三笔中七止盈六止损。

这支持两个具体诊断方向：校准扩展至每个输出四十个斜率后的复杂度，以及全部查询与可执行机会之间的选择差异。当前结果尚不能把因果责任归给其中一个。诊断在结果后运行，仅解释失败，没有据此过滤交易或调整参数。详见 [diagnostics.json](evidence/diagnostics.json)。

## 为什么双倍成本反而少亏

双倍成本累计 +1.75%，但一／二／三月均亏损，仍未达标。它使用完全相同的冻结建议，增加成本后重新执行完整资金路径，并非从同一批成交简单减去费用。

原始分钟行情复算定位到四月二十四日 SOXL 入场：主路线入场价 125.272605、保护止损价 117.75；双倍成本入场价 125.335210、保护止损价 117.81。四月二十七日 09:50–09:55 ET 的最低价 117.7902 只触发后者。主路线随后遇到四月二十八日开盘 108.75 的向下跳空，净亏 13.32%；压力路线提前退出，净亏 6.29%，结算后还取得次日后续入场机会。

这个已暴露事件说明止损价取整、跳空和资金路径敏感，不能证明更高成本更优，也没有据此改止损。逐根前缀及下一次动作已由 [audit_cost_path.py](audit_cost_path.py) 对原始行情复算，[cost_path_audit.json](evidence/cost_path_audit.json)保存证据。

## 交付核验与下一步

独立审计通过 1,459 个查询、366 个每日拟合、8,964 项基础方程、193,600 项校准方程、48 次锚点检查、13,131 项动作与九份连续账本、153 项统计断言。两种基础模型在四个分支复用，48 次锚点对应 24 个不同基础拟合，不是 48 份独立市场证据。宏观输入沿用独立重建核验；两个原校准分支分别完整复现 v42 与 v35。工程核验不提升收益验收状态。

下一步先做固定结果的校准诊断：按当时训练权重计算有效日期数、平滑矩阵自由度和新查询杠杆值，比较全部查询、发出建议、实际入场三层的误差；同时拆出共享斜率与时点差异的贡献。只检验“条件校准复杂度是否与高估同现”，不从事后好坏交易反推门槛。若证据支持，再另行预登记仅由过去成熟误差决定复杂度的方案；若不支持，放弃这条校准方向。原 v39 已证明仅过滤少量旧建议不足以完成指定月份目标，不能把诊断替代新的基础机会能力。

持续目标仍在进行，原定月份与收益条件不变。详见 [GOAL_PROGRESS.md](GOAL_PROGRESS.md)。

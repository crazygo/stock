# v47 · 期权活跃度与隐含波动的方向信息

**开发筛选失败，完整核验通过。** 两个交易日延迟的主路线，一至四月月均 +2.03%，二月 −3.80%、三月 −10.37%。本版没有获得新的指定月份回归资格。

v46 的指定月份回归表明，主要预测误差在 SOXL／SOXS 的方向选择；只过滤旧建议无法达到目标。本版将已经存在的历史期权输入用于方向模型，检查市场对半导体的参与程度与波动预期能否提供增量。旧失败结果保留，没有给月份事后贴“热门”标签。

## 数据和时间边界

使用 [R06](../../analysis/preopen_5d5pct_v6/R06/README.md) 已于十月五日取得的本地历史。固定八只参考股 NVDA、AMD、AVGO、MU、AMAT、LRCX、KLAC、INTC，另用 SOXX 和 QQQ 作行业／市场比较。十个标的的期权统计与波动率各 498 行，共二十份原始文件、9,960 行，日期为 2024-10-04 至 2026-09-30，与官方交易日日历一致。

逐份核对原获取元数据的 SHA、代码、行数和采集错误。原历史覆盖完整，所以按 `r2-market-data` 的 Local → R2 → OpenD 顺序停在本地命中；本轮没有 R2／OpenD 请求、下载、上传或账户访问。原始 JSON／Parquet 保留于忽略缓存，不入 Git。

[富途历史期权统计说明](https://openapi.futunn.com/futu-api-doc/quote/get-option-underlying-his-statistic.html)把数据定义为按日成交量、持仓量和 Put/Call 统计，持仓量注明 T−1 延迟。调用返回的 `time`／`timestamp` 是统计日期，不能当作当年首次发布时间。原始接收发生在十月五日；没有历史发布及修订版本，不能认证历史 PIT。

主路线假定统计日后第二个官方交易日 00:00 ET 才可知；固定敏感性对照使用第五个交易日。节假日和半日市均以官方交易日序列计算。同一日四个时点用相同的已延迟期权输入，原量价特征仍随时点更新。缺失不向前填、不填零、不减少均值分母。所有原先可训练的 1,228 个查询均有新输入，没有因新字段移除原训练日期。

本次不使用持仓量作为输入：原数据中 KLAC 2026-06-11 的总持仓为零、比率缺失，按未知保留，不能把延迟或缺失的持仓反移到前一天。现有表没有按行权价／到期日的历史曲面、成交发起方向，也没有完整历史新闻／一致预期版本，所以不制造偏斜、净看多流或财报超预期指标。看涨期权成交多也可能涉及卖出、平仓或组合，方向由历史收益学习。

## 八个新增输入

| 输入 | 固定定义 |
| --- | --- |
| 成交结构 | 八股 `(call_volume−put_volume)/(call_volume+put_volume)` 等权均值 |
| 结构变化 | 各股成交结构减五个交易日前，取八股均值 |
| 活跃度 | 各股 `log(当日期权成交量/此前二十交易日均量)` 的均值，分母不含当日 |
| 参与广度 | 八股活跃度大于零的占比，要求八股均完整 |
| 波动预期差 | 八股 `log(IV/HV)` 均值 |
| 预期变化 | 八股 `log(IV/五个交易日前IV)` 均值 |
| 行业／市场成交结构差 | SOXX 成交结构减 QQQ 成交结构 |
| 行业／市场波动差 | SOXX `log(IV/HV)` 减 QQQ 同值 |

输入先按原始统计日期计算，再整体延迟两天或五天，不用查询日以后行情。当前参考池不是历史 PIT 行业成分；IV 是隐含波动指标，HV 是历史波动指标，二者都不是上涨概率。

## 学习和动作

共同净对数收益 `C=(L+S)/2` 与方向幅度 `M=abs((L−S)/2)` 继续使用 v35 的 Ridge α=100，原 27／39 项量价和财务输入、训练成员、权重完全不变。只有方向 LogisticRegression C=0.1 增加八项期权输入，成为盘前 35／盘中 47 项。

每个交易日 00:00 ET 分时点重训，只取此前已完整成熟的双边标签前缀，至少 120 日期；126 日期半衰期。方向标签是 `D>0`，权重为时间权重乘 `abs(D)`，归一到日期数。它学习收益幅度加权方向，不能称为止盈胜率。新方向标准化只用训练成员及同一时间权重。单类和全零幅度回退沿用原规则。

三个版本各自保存当时发出的基础预测，再做原有部分共享误差校准：输入只有两只 ETF 的原分数和时点，不将期权再次放入校准。最近 120／至少 60 个完整成熟日期，63 日期半衰期，199 次十日期循环分块，整日各时点和两只 ETF 一起抽样。点估计减共同 90% 向上扰动余量仍为正才买，否则不行动。

09:25:30、10:05:30、10:35:30、13:05:30 ET 的原执行规则保留；下一可成交常规盘五分钟 Open 加成本入场，+5% 附带止盈、6% 保护止损，最多含入场日十四个日历天。同根双触及先止损，不利跳空、费用、滑点、T+1、股息／拆股、跨月盯市和未知占资均入连续资金账本。一次一个仓位，同日不重复买入。

原目标仍为五月／七月／九月完整净资金月收益算术均值至少 10%，五月至九月每月非负。一至四月开发筛选要求每月非负、均值至少 10%、至少十笔完成交易且覆盖完整；只有本版主路线通过并完成核验才启动新的指定月份回归。对照不能替代失败主路线。已暴露历史属于开发研究，不增加未来观察期门槛。

### 方向信息增量

326 个已成熟查询、82 日期按日内平均再日期等权，另外两个未知查询保留。共同收益原模型保持完全一致，所以原始配对 MSE 的变化都来自方向。

| 模型 | 原始配对 MSE | 原始方向 MSE | 幅度加权方向 Brier | 校准后配对 MSE |
| --- | ---: | ---: | ---: | ---: |
| 两天延迟 | 0.00440721 | 0.00386734 | 0.259549 | 0.00436126 |
| 五天延迟 | 0.00442178 | 0.00388191 | 0.262550 | 0.00435139 |
| 原 v35 输入 | 0.00439015 | 0.00385029 | 0.259070 | 0.00441269 |

两种延迟的原始方向误差均略差于对照，幅度加权 Brier 也都差于相同权重的恒定 0.5（0.25）。校准后 MSE 下降不能替代资金验证：主路线实际入场平均净对数收益为 0.00240，对照为 0.01541；止盈占实际完成交易 60%，低于对照的 70.83%。两天延迟没有建立新的有效方向优势。

这次证据否定的是“固定八项期权状态以线性方向项加入现模型”的本次候选，不能据此断言期权或行业热度永远无用。下一步考虑其条件含义：成交结构可能同时反映追涨、对冲、平仓，固定线性符号未必合适。应另立预登记版本检验期权状态与已知价格趋势的条件关系，保留本版线性与不含期权的对照；不能继续改本轮门槛或挑出好月份。

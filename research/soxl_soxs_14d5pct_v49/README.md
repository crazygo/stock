# v49 · 保留当时预测的方向纠偏

本版沿用每天当时发出的原始方向预测，只从此前完整成熟的预测误差学习修正。固定比较“时点偏差修正”和“加入期权状态的修正”，检查半导体的可观察状态是否提供增量。原始预测、历史修正、所有失败和资金结果分别保留；不以事后热门月份定义特征。

## 冻结设计

原模型将 SOXL／SOXS 的净对数收益分解为共同收益 C、方向幅度 M 和方向估计 q，重组为 `C ± M(2q−1)`。q 是收益幅度加权的相对方向估计，不是十四天止盈概率。C、M、q 均保留原日模型当时发出的值；开发来源为 v35，指定月份扩展来源为 v39 的逐日模型，后续月份不沿用五月静态模型。

新模型固定原 q 的系数为一：

```
q_new = sigmoid(logit(clip(q_source, 1e-6, 1-1e-6))
                + a_clock + standardized_options @ beta)
```

四个分析时点各有偏差项，八项期权斜率在时点间共享。训练目标是 `I(D>0)` 的二元对数损失，按时间权重乘 `abs(D)` 后归一化到日期数量；偏差项 L2 系数一，期权斜率系数十。所有参数均有惩罚，原 q 不重新估计。全零方向幅度时保留原 q；单类样本也有有限解。使用 Newton 加回溯线搜索，超过六十步或不收敛即报错。固定系数偏置的定义参见 [statsmodels GLM 文档](https://www.statsmodels.org/stable/generated/statsmodels.genmod.generalized_linear_model.GLM.html)。

| 方向修正 | 输入 | 角色 |
| --- | --- | --- |
| 固定原 q + 时点偏差 + 期权 | 两交易日延迟的八项指标 | 主路线 |
| 固定原 q + 时点偏差 | 不加期权 | 隔离通用偏差修正 |
| 固定原 q + 时点偏差 + 期权 | 五交易日延迟 | 可得性敏感性检查 |
| 原 q | 原预测和校准不变 | v35 精确对照 |

另保留主路线仅点估计、去掉收益误差校准、仅盘前、现金、双倍成本，共九份完整资金账本。不搜索参数或按已知月份切换主路线。

八项期权指标沿用 [v47 公式](../soxl_soxs_14d5pct_v47/README.md)：固定八只半导体参考股的看涨／看跌成交平衡、五日变化、成交活跃度、活跃股票占比、IV/HV、IV 五日变化，以及 SOXX 相对 QQQ 的成交平衡和 IV/HV。共二十份本地历史文件，每份 498 个官方交易日。缺少买卖发起方向，不能将看涨期权成交量称为净看多资金流；原始发布／修订历史未认证，滞后两天／五天是假设，十月采集记录不冒充历史接收。

## 时间隔离与联合不确定性

每日 00:00 ET 截止，仅用此前完整成熟日期的连续前缀，最近一百二十个、至少六十个日期，六十三日期半衰期。每个日期的权重平分给当日实际三或四个时点，避免多时点偷偷增加独立样本数。未满六十个日期保留原分数，但操作门禁仍不行动；逾期未解的前缀不能跳过。

每次发出的修正分数立即保存。后续收益误差校准使用这些当时分数，不用今天的方向模型回写历史。校准保持原来的部分共享 Ridge α=20，输入仅为双 ETF 分数和时点。

进行 199 次十日期循环分块重抽样。方向纠偏和收益校准使用同一组日期重复次数；每次既重新计算当前修正分数，又用该分数作为当次收益校准的查询输入。历史已发分数在重抽样中保持原样。两个 ETF 的共同向上扰动九十分位数为扣减余量；扣后最大的净分数仍为正才允许买，否则现金。

这部分覆盖方向纠偏和收益校准的不确定性，基础 C／M／q 视为给定，不能称包含所有基础模型估计误差。去掉收益校准的对照仍计算方向纠偏余量。

分析时点为 09:25:30、10:05:30、10:35:30、13:05:30 ET，覆盖盘前。原 v4 任意时点接口保留。由完整行情截止加延迟后下一常规盘五分钟 Open 计入场成本；+5% 附带止盈、固定 6% 保护止损、最多含入场日十四个日历天，最后可交易收盘强制退出。保留同根先止损、不利跳空、费用／滑点、T+1、公司行动、跨月盯市、未知占资、最多一个仓位、同日不重入，不用期末浮亏隐藏负月。

## 纠偏是否真正改善方向

以下覆盖 326 个完整成熟查询、82 日期，先按日内均值再按日期等权；另两个未知查询保留，不提前计成功或失败。

| 模型 | 原始方向 MSE | 幅度加权 Brier | 校准后配对 MSE |
| --- | ---: | ---: | ---: |
| 两天期权纠偏 | 0.00404767 | 0.275248 | 0.00436132 |
| 仅时点偏差 | 0.00394396 | 0.266510 | 0.00443189 |
| 五天期权纠偏 | 0.00402352 | 0.272341 | 0.00436086 |
| 原 v35 | 0.00385029 | 0.259070 | 0.00441269 |

主路线的原始方向 Brier 从 0.25907 恶化至 0.27525，另外两种纠偏也恶化；同权重常数 q=0.5 为 0.25。共同收益 C 和幅度 M 没有变化，这里的原始误差变化来自方向。校准后整体 MSE 稍低，仍不能代替出手收益。

328 个评价查询的主路线平均绝对 q 修正为 0.09223，17.68% 查询改变原始相对方向。修正已经生效，失败并非代码未接入新输入。203 个查询点估计为正，余量后仅 39 个，分布在 25 日期；最终十九次实际买入。十九次出手净对数收益均值 −0.004869，其余二十次建议受资金／持仓／限次约束，没有冒充实际出手或独立交易。

主路线联合余量日期均值 0.014873，旧基础 0.014408，均为净对数收益分数单位。这些余量不是可保证的最大亏损。仅点估计、去掉收益误差校准的两条路线也亏损，现有证据不支持把失败全部归于余量太保守。原始方向拟合恶化和实际出手亏损同时存在。

下一步先核查原 q 的置信度是否应收缩：本版固定原 q 的 log-odds 系数为一，只能增加偏置，不能直接降低旧估计的过度置信。候选机制是用当时已发预测的成熟反馈估计有界斜率，保留固定原 q、常数 q=0.5 和无期权对照，再按相同资金目标验收；先核对与旧 v36 的 C／D 平方损失混合、v28 的局部竞争风险估计有无重复，不继续用调树深或事后月度门槛取巧。本段是下一实验方向，没有改变本次冻结规则，也未宣称其效果。

# v52 · 用可见行业状态调整方向可靠性

v51 的全局有符号系数改善了部分资金路径，但整体方向误差仍高于中性对照。此次检验一个更具体的假设：同一方向分数的可信程度可能随行业状态变化。将用户提出的半导体热度思路转为查询时可计算的指标，再学习它与原方向可靠性的关系。

这并非首次使用行业状态：v22 用状态距离调整训练权重，v29 用在线变点调整历史记忆，v43 在基础模型加入宏观交互，v49／v50 加入期权偏置或全局置信系数。本版只改变已发方向分数的条件校准，不重复这些方法，也不声称已提前识别热门期。

## 当时可见的行业状态

固定指数为：

```
u = [1 + (tanh(relative_5) + breadth_5 + volume_direction_diffusion) / 3] / 2
```

三项各占三分之一，u∈[0,1]，没有拟合权重或热门阈值。

| 分量 | 可复算定义 | 截止 |
| --- | --- | --- |
| 相对强弱 | SOXX 与 QQQ 此前五日收益差，除以 SOXX 此前二十日波动率×√5，再截断至 ±5 并取 tanh | 此前完整常规盘 |
| 上涨广度 | 八只固定代表股此前五日收益为正的比例×2−1 | 此前完整常规盘 |
| 放量方向扩散 | 当前上涨且累计量高于过去二十日同钟点均量的股票占比，减去对应下跌股票占比 | 当日 04:00 至当前已完成分钟截止 |

代表股为 NVDA、AMD、AVGO、MU、AMAT、LRCX、KLAC、INTC；沿用现有登记池，不冒充历史全行业成分。比较的是同钟点完整前缀，盘前不会使用完整盘前或收盘总量。指数每次查询重算，历史已发指数不改写；缺失保持缺失，不能补为中性。

这些字段原本已存在于基础模型输入。本版检验的是它们参与可靠性校准的新作用。u 表示可见相对强弱和参与程度，**不是热门行情概率，也不是未来止盈概率**。

## 模型与对照

基础模型保留当时发出的共同净对数收益 C、方向幅度 M 和幅度加权方向 q。令 x 为截断至 [1e−6,1−1e−6] 的 q 的 log-odds。主路线为：

```
s(u) = (1−u) × s_cold + u × s_hot
q_new = sigmoid(x × s(u))
-1 ≤ s_cold, s_hot ≤ 1
```

只学习两个端点系数；在当前 u 处线性插值。系数可以反转或减弱原方向，不能放大原 log-odds；q=0.5 时仍为 0.5。端点名称仅描述 u 的低高端，不把样本划成事后热门月份。最终原始收益仍为 `C ± M(2q_new−1)`，C、M 均不变。

[概率校准文档](https://scikit-learn.org/stable/modules/calibration.html)说明，应使用基础模型未见过结果时产生的预测记录拟合校准器；Brier 同时反映多种误差来源，降低它不等于证明盈利。本版使用历史当时已发分数及后来成熟的反馈，扩展为自定义状态条件校准；文档不证明该扩展在股票上有效。

| 模型 | 形式 | 检查的问题 |
| --- | --- | --- |
| **状态条件可靠性，主路线** | x×[(1−u)s_cold+u s_hot] | 原方向在不同状态下是否有不同可靠性 |
| 状态偏置对照 | s×x+b×(2u−1)，s、b∈[−1,1] | 状态是否直接提供方向偏置，而非改变原方向可靠性 |
| v51 全局可靠性 | 原冻结标量 s×x | 精确复现上一轮主路线 |
| 固定中性 | q_new=0.5 | 精确复现上一轮中性路线 |
| 原基础 | 保持原 q | 精确复现 v35／v51 基础路线 |

主路线和状态偏置均为两个参数，但函数形式及约束含义不同；对照不代表两者拥有完全等价的函数空间。另有主路线点估计、去掉收益校准、仅盘前、现金和双倍成本，共十份连续资金账本。

## 每日训练与执行边界

每日 00:00 ET 只用此前已完整成熟日期的连续前缀，最近一百二十、至少六十个日期；六十三日期半衰期，日期权重平分给当日三或四个实际钟点。训练目标为 I(D>0) 的二元对数损失，D 为真实双 ETF 净对数收益差的一半，权重再乘 |D| 并归一至日期数。

主路线惩罚为 `0.25×[(s_cold−1)²+(s_hot−1)²]`，等于平均斜率向一、半差向零的两个 0.5 平方惩罚。两个端点相等时，目标退化为 v51 的原标量目标。状态偏置惩罚为 `0.5×(s−1)²+0.5×b²`。正惩罚保证严格凸；两维有边界 Newton 步枚举九个面，回溯最多五十次、最多一百步，最终投影梯度不得超过 `1e−8×日期数`。独立审计重算目标和约束最优性。全局对照直接调用冻结 v51 求解器。

系数在午夜训练，当前指数在查询时计算。零方向幅度保留原 q；学习路线不足六十个成熟日期时保留原分数，买入继续受原准备门禁约束。每条路线保存自己的当时分数，再用原部分共享双 ETF＋钟点 Ridge α=20 校准净收益。199 次十日期循环重抽样在方向层和收益层使用同一日期重复次数，同时改变当前方向和校准输入。基础 C／M／q 与状态指标视为给定，不声称包含全部估计误差。

决定时点仍为 09:25:30、10:05:30、10:35:30、13:05:30 ET，含盘前；v4 任意时点接口保留。扣除共同九十分位向上扰动余量后，最高净收益估计仍为正才买其中一只，否则不行动。下一常规盘五分钟 Open 加成本入场，最多等六分钟；挂 +5% 止盈、固定 6% 保护止损，最多含买入日十四个日历天。不利跳空、同根先止损、T+1、股息／拆股、跨月盯市、未知占资、一次一个仓位和同日不重入均保持。

原验收不变：**五月、七月、九月完整净资金月收益算术均值至少 10%，五月至九月每月非负。** 开发筛选为一至四月各月非负、均值至少 10%、至少十笔完成交易及完整覆盖；只有主路线通过并完成独立核验才进入新指定月份回归。历史已暴露，不能称独立市场验证；没有新增未来观察期门槛。

## 预检与冻结

23 项测试首次通过，覆盖另一优化器的最优解、两维受限 Newton 步、常数状态退化关系、相反状态学习、单类／端点／零幅度、单位不变性、偏置对照、篡改拒绝、不可放大约束、冻结全局对照、状态公式及未来输入免疫、联合日期重抽样、成熟前缀、缺失弃权、C／M 保持及回归门禁。

真实输入预检重建 1,439 个状态行和 4,317 项分量方程，四份同钟点累计量文件 SHA 与旧审计一致，没有删去原合格行。三个真实日期再通过 1,800 份最优性证书和 6,000 项收益校准方程，三组 v51 对照精确复现。新路线预检收益历史明确使用基础历史占位，仅核对方程；完整回放会生成自身当时分数历史。新资金结果出现前冻结 186 份源文件与依赖，见[登记](evidence/preregistration.json)。

沿用二十份本地期权历史及原始审计以匹配旧输入和准备条件，本版拟合不使用期权列；原历史发布时间与修订局限保留。本轮没有新下载、R2 上传或券商操作。

## 方向误差与状态关系

82 个开发日期，平均低端系数 −0.03734、高端系数 −0.72170，后者十天达到 −1 下界；实际查询处平均系数 −0.44499。原相对方向在 92.68% 查询中反转。这个结果描述此前反馈拟合出的系数，不表示行业指数高时就应机械反向买入。

下一步优先核对一个具有明确表达差异的假设：单条线性状态斜率能否充分描述这种关系，还是需要允许中间状态与两个端点不同。继续使用此前成熟反馈、固定状态定义及相同资金规则，另行登记非单调方法和旧主路线对照；不得通过扩大系数界限或依照这张事后表设置交易例外。另已核对旧代码的查询时点：v7／v23 入场候选为四钟点，v10／v11 的十一钟点用于持仓复查，不能冒充已验证的密集入场模型。更密集查询是后续独立方向，本轮没有生成其数据或回报。

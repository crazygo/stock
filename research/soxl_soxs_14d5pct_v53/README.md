# v53 · 允许行业状态与方向可靠性呈弯曲关系

**主路线未达标。** 开发月均 +4.01%，三／四月亏损；新增中点改变分数，但相对旧线性模型没有动作或资金增量，方向 Brier 恶化。24 项测试与完整独立核验通过，未启动新指定月份回归。

v52 的可见行业状态改变了预测，但实际成交与全局对照完全相同。其开发诊断还显示，中间状态与两端的误差关系不同。本版检验一个明确差异：在原两端线性插值中，增加一个固定中点，允许可靠性在中间凸起或凹下。

这是假设来自已暴露历史的开发实验，不是独立发现；不按五月、七月、九月拟合，也不把旧诊断的最佳分组直接设为买入条件。v22 的邻域权重、v29 的变点记忆、v40 的基础树模型、v43 的宏观交互以及 v52 的线性状态可靠性各自保留。

## 查询时可见的行业状态

完全沿用 v52 的固定指数：

```
u = [1 + (tanh(relative_5) + breadth_5 + volume_direction_diffusion) / 3] / 2
```

- `relative_5`：此前五日 SOXX 相对 QQQ 的收益，除以 SOXX 此前二十日波动率×√5，再截断至 ±5。
- `breadth_5`：八只固定代表股此前五日收益为正的比例×2−1。
- `volume_direction_diffusion`：当日 04:00 至当前已完成分钟内，上涨且累计量高于过去二十日同钟点均量的股票占比，减去对应下跌股票占比。

八只代表股为 NVDA、AMD、AVGO、MU、AMAT、LRCX、KLAC、INTC，不冒充历史全行业成分。三项等权、没有热门阈值；盘前只用当前已完成前缀，缺失保留。u∈[0,1] 表示可见强弱与参与程度，不是热门行情或未来止盈概率。

## 一个新增的弯曲参数

基础模型保留当时已发共同净对数收益 C、方向幅度 M 和幅度加权方向 q。设 x 为截断至 [1e−6,1−1e−6] 的 q 的 log-odds；三个可靠性系数在 u=0、0.5、1 处取值，并连续线性插值：

```
z = 2u−1
h(u) = [max(−z,0), 1−|z|, max(z,0)]
s(u) = h(u) · [s0,s1,s2]
q_new = sigmoid(x × s(u))
−1 ≤ s0,s1,s2 ≤ 1
```

插值权重非负且总和为一，因此可反转、减弱原方向，不能放大原 log-odds；q=0.5 保持中性。中点固定为指数区间的中心 0.5，没有按历史收益、分位数或月份寻找拐点。最终原始配对收益仍为 `C ± M(2q_new−1)`。

惩罚也保持与旧模型一致。令 `a=(s0+s2)/2`、`b=(s2−s0)/2`、`c=s1−a`：

```
penalty = 0.5(a−1)² + 0.5b² + 0.5c²
```

当 c=0 时，预测形式和惩罚均精确退回 v52；增加中点不会悄悄减小原方向的惩罚。三个系数等于一为先验。固定基函数后，系数拟合仍为严格凸优化。三维受限 Newton 步枚举二十七个面，独立审计另写分段公式与变换后的惩罚梯度，核对约束最优性。

[固定基函数方法](https://scikit-learn.org/stable/auto_examples/linear_model/plot_polynomial_interpolation.html)说明如何表达输入的非线性关系；本版使用自定义一阶基函数和有边界的加权 Logistic 目标。该文档不证明股票效果。[校准文档](https://scikit-learn.org/stable/modules/calibration.html)也明确，预测误差指标同时受多种因素影响，不能直接证明资金收益。

## 每日训练和原验收

每日 00:00 ET 使用此前完整成熟日期的连续前缀，最近一百二十、至少六十日期；六十三日期半衰期，每日权重平分给当天实际三或四个钟点。方向目标是 I(D>0)，D 为真实双 ETF 净对数收益差的一半；权重乘 |D| 并归一至日期数。零方向幅度保留原 q；不足六十日期保留原分数并继续受准备门禁约束。

五种模型各存自己的当时预测历史，原部分共享双 ETF＋钟点 Ridge α=20 收益校准不变。199 次十日期循环重抽样，在方向层与收益层共用日期重复次数，同时改变当前方向及校准输入。基础模型和固定状态视为给定；此余量不是全部估计误差或未来亏损保证。

决定时点为 09:25:30、10:05:30、10:35:30、13:05:30 ET，含盘前；v4 任意时点接口保留。最高净收益减共同九十分位向上扰动余量后仍为正才买其中一只，否则不行动。下一常规盘五分钟 Open 加成本入场，最多等六分钟；附带 +5% 止盈，固定 6% 保护止损，最多含买入日十四日历天。原 T+1、成本、股息／拆股、跨月盯市、同根先止损、不利跳空、未知占资、一次一个仓位及同日不重入都保持。

原验收为**五月、七月、九月完整净资金月收益算术均值至少 10%，五月至九月每月非负**。开发筛选为一至四月每月非负、均值至少 10%、至少十笔完成交易、完整覆盖。只有独立核验后的主路线通过才进入新的指定月份回归；诊断路线不能替换失败主路线。历史已经暴露，没有新增未来观察期门槛，也不声称独立市场验证。

## 增加弯曲关系没有产生动作增量

328 个开发查询的原 q、校准后配对分数、联合余量都与旧线性模型不同，q 最大差异 0.04685。但相对线性模型，**动作变化为零**；决定、订单、成交、权益四份 CSV 均完全相等，配对日收益差和区间均为零。曲线模型确实参与了计算，但没有改变一次实际操作。

主路线共 34 次非现金建议、24 日期，实际十五次入场（十四次 SOXL、一次 SOXS）；十九次被持仓或同日限制拦截。被拦截建议保留，不能当作新增成交，也不能靠忽略资金约束提高月收益。见[增量审计](evidence/increment_audit.json)，此诊断代码在本版资金结果出现前已经登记。

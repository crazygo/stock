## 相同算法，重新生成新时点预测

输入沿用价格、行业广度、同钟点累计量，以及八家代表公司的公开财务／披露状态。代表股仍为 NVDA、AMD、AVGO、MU、AMAT、LRCX、KLAC、INTC，不冒充历史全行业成分。本版不再拟合 v53 的弯曲可靠性系数，也没有新增期权字段。财务可用日沿用旧协议的延迟假设：取申报日与受理时间字面日期中较晚者的下一日 00:00 ET；不能据此声称重建了历史首次公开或实际接收时间。

每个新增时点每天 00:00 ET 训练一次，只用该时点此前完全成熟配对标签的连续前缀，至少一百二十日期。原四时点在特征、准备条件、标签完全一致后复用已核验的当时模型记录，不重新改写历史分数。三项基础输出为：

```
C = (SOXL 净对数收益 + SOXS 净对数收益) / 2
M = |SOXL 净对数收益 − SOXS 净对数收益| / 2
q = 幅度加权的相对方向分数
预测配对收益 = C_hat ± max(0,M_hat) × (2q_hat−1)
```

算法保持 C／M 的 Ridge α=100，以及 q 的 LogisticRegression C=0.1；标准化只拟合此前训练数据。日期权重为一百二十六日期半衰期，方向权重再乘真实 M 并归一至日期数。q 不是未来止盈概率。缺失和未知保留，不补成零；遇到未成熟日期不能跳过去选后面的已知结果。

[时间序列交叉验证说明](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-of-time-series-data)强调时序依赖和训练／评价的顺序。本版沿用自己的每日成熟前缀与日期分块实现；普通随机拆分无法验证本策略，也没有因新增分钟查询而增加独立市场日期。

## 日期权重与校准惩罚

收益校准仍使用自己的当时原始分数和后来成熟的净收益误差。最近一百二十、至少六十个完整成熟日期，六十三日期半衰期，总权重等于日期数，每日权重分给当日实际五或八个查询。所有同日时点和两个 ETF 在 199 次十日期循环重抽样中一起移动，种子保持 `826＋美东日期序号`。

登记时将部分共享惩罚按相同系数从四时点扩展到八时点：

```
20 × ||时点斜率均值||²
+ 20 × Σ ||各时点斜率 − 均值||²
```

每个时点各有自由截距。若 k 为时点数，对每个原始分数的系数向量，矩阵为 `20(I−J/k)+20J/k²`；两项输入取块矩阵。四时点子实现精确复现旧求解器，八时点另由联合截距的正规方程独立核验。新增查询不增加每日总权重；惩罚系数未改变，但它相对于每个时点样本的强度会随时点数量改变，见文末合成检验。半日市没有晚时点行；重抽样拟合必须保留每个时点的正权重支持，否则拒绝，不补假数据。

主路线继续选净收益点估计减共同九十分位向上扰动余量后最高且大于零的一只 ETF，否则不行动。余量覆盖收益校准的历史敏感性，不含所有基础模型误差，也不是未来无亏损保证。

## 后续假设：时点数量与收缩强度

结果后的只读合成检验发现一个可复证的结构问题：将每个时点完全复制为两个通道、每行权重减半，数据误差项保持不变；当前 `20×Σ时点偏差平方` 惩罚却翻倍，而均值惩罚保持不变。因此，“每日总权重未增加”不足以证明训练强度相同。这是登记公式的性质，完整实现仍与登记一致，不能静默修正旧结果，也不能据此解释全部实际亏损。

[合成检验](audit_clock_replication.py)只读取合成数组，不读行情、不重放资金。独立联合截距求解与本版求解器一致。四通道复制到八／十二通道后，本版预测分别最大变化 0.73186／1.09182（合成单位）。候选公式 `20×均值平方 + (80/k)×时点偏差平方和` 在四通道完全保留旧惩罚，复制检验中预测误差小于 4e−15、完整目标函数不变。[核验结果](evidence/clock_replication_audit.json)只证明复制不变性，不证明投资效果。

下一步可另立版本，预先固定这一按通道数归一的公式，保留本版及旧四时点匹配对照，检验能否分离新增信息和相对收缩改变；不按月份挑参数、不在本版替换主路线。没有新的资金结果或通过状态。

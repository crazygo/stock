# v60 · 按当时行业环境抽取双 ETF 联合价格路径

本版研究“事前行业环境是否能改善原交易合同的预期收益”。每天只扩大到当日零点前已完整可知的历史片段，每个查询时刻再使用当时已知的状态与报价；不把后来确认的热门月份当成特征。原始收益预测由路径估值产生，之后仍以历史当时发出的预测和已经成熟的十四日真实结果逐日校准。

算法为条件核加权的双日经验路径抽样；收益校准为按时点部分共享的 Ridge 残差回归，配合日期块重抽样。

## 方法与边界

1. 从已有真实行情建立 SOXL／SOXS 连续两个官方交易日的联合片段。源日必须拥有完整的 78 根常规盘 5 分钟线、前一交易日收盘及公司行动信息；半日市源片段不参与，不跨缺失日拼接。源历史分红在支付日之后才允许进入样本，属于保守可用时间假设，不证明历史原始消息接收时间。
2. 第一片段按查询时钟的四项状态赋权：行业相对五日强弱、五日上涨广度、行业波动率对数、当时行业价格前缀。后续片段使用前三项。权重为 126 个合格片段起始日半衰期 × 标准化距离的高斯核；带宽固定为正距离的 40% 分位数。至少 120 个真实片段，权重有效样本数至少 20，否则弃权。固定参考公司池不是历史完整半导体成分股池。
3. 每次生成 2,048 条联合路径，两只 ETF 使用完全相同的片段索引；无条件对照共享样本池、随机均匀数与真实校准目标，只去掉状态权重。种子和全部参数固定，不按月份或结果修改。
4. 首日从当前已知原始报价出发，使用源同钟点报价到延迟成交的价格比例；不能使用实际未来入场价启动预测。后续日沿用源相对前收盘的 OHLC、跳空、拆股比与分红比。进入当日不领取当日除息现金；后续持有到除息日才计入。价格经济单位与原始报价最小分变化分别处理。
5. 每条路径按原合同估值：+5% 分币向上取整止盈、固定 6% 止损、同根双触及时止损优先、跳空按更差开盘成交、费用与滑点；入场日加十三个日历日为截止，取其内最后官方收盘。实际账本另按原规则处理 T+1、分红支付现金、单一持仓、当日禁止再入场、跨月盯市及未知资金占用。
6. 原始两只 ETF 输出是净收益对数的路径均值。记路径收益对数为 L、S，则 C=mean((L+S)/2)、D=mean((L−S)/2)、M=mean(abs((L−S)/2))，q 为 abs(D_path) 加权的正方向占比；C±D 是预期对数收益，q 不是止盈胜率。模拟标准误只描述数值积分误差，不能作为真实市场收益置信区间。

两日块内保留真实联合变化，块与块之间独立抽取。后续片段选择始终使用查询当时的行业状态，没有模拟状态随未来价格演变；目标半日市截取完整源日的前半部分。这两项是模型假设，未被真实收益自动证明。样本重叠、固定行业池、历史行情可用时间及公司行动 metadata 的来源限制继续保留。模拟路径不会增加独立真实日期数，也不保证月收益非负。

时间序列块抽样的背景可参照 [Politis 与 Romano 原论文](https://users.ssc.wisc.edu/~bhansen/718/Politis%20Romano.pdf)及[作者的综述](https://mathweb.ucsd.edu/~politis/impactBOOTrev.pdf)。本版是固定两日、条件经验情景模型，不能套用 stationary bootstrap 的平稳性定理作为预测或交易保证。协议原登记的 Purdue 技术报告链接本轮返回 404；上面给出可访问论文，未据此更改模型公式。

## 验收及复跑

主路线固定为 `conditional_band`。`conditional_point`、`unconditional_band`、旧 v56、旧 v55、仅盘前、现金和双成本都是对照。原校准使用最近 120 个成熟完整日期，至少 60 个；199 次日期块重抽样、八时点归一化权重与罚项不变。校准未就绪、未知过期前缀、路径或报价缺失均弃权。校准误差带不是月度亏损上限。

先检查一至四月的主路线开发筛选：每月非负、净月收益算术均值至少 10%、至少十笔完成交易、覆盖完整。主路线经独立核验通过后才允许新五月至九月账本回归；对照不能替代主路线通过。用户最终目标仍是五／七／九月净月收益算术均值至少 10%，五月至九月每月非负；已暴露历史称开发回归，不增加未来观察期验收门槛。

## 独立审计的补充登记

首轮全量审计发现一个浮点边界差异：2025-06-26 13:05:30 ET、条件模型路径索引 626（从零计数）的 SOXL，正确缩放高点恰为 26.33，旧审计器改换乘除顺序后得到 26.329999999999995，漏判止盈。60 位十进制计算及原逐条 `first_exit` 引擎确认止盈。新独立审计器保留生成器的浮点价格构造顺序，仍独立计算全路径的首个事件、费用、分红及到期退出；没有放宽容差或改变模型结果。

原 402 份冻结文件、首轮失败日志和结果都保留。四份补充审计文件及五项测试在新指定月份回放前登记于 [audit_amendment.json](evidence/audit_amendment.json)，可用 [reproduce_boundary.py](reproduce_boundary.py) 重现价格证据。跨阶段比较允许尚未成熟的目标在原开发截止之后成熟，禁止改写已知值、因果输入和历史已发预测；时间戳先对齐原精度后比较数值。这个检查修复不改变收益目标、学习规则或交易动作。


指定月份执行入口为 `run_paths.py --case-after <已验证开发运行> --output <新目录>`，完整审计可使用 `verify_paths_canonical.py`。本次采用等价的 `verify_cases_reuse.py`：先逐字节核对旧训练／校准记录，逐值核对全部旧模型数组，检查因果输入、已知目标、价格库及历史动作前缀，再复用开发审计；新月份的所有计算、后来成熟的标签与八账本仍独立检查。四项前缀测试和审计源码在新指定月份资金结果出现前登记于 [case_audit_registration.json](evidence/case_audit_registration.json)。不满足精确一致便拒绝复用。

## 回归卡点与下一步

指定月份 840 个查询全部具备原始预测和校准，过期未决前缀为零。五月／六月／七月／八月／九月，正点估计查询分别为 110／92／46／12／24，正下界仅为 4／0／3／0／0，共七次建议，实际五次入场。去掉误差带的 66 次入场对照累计 −76.86%，不能靠放宽门槛完成增长目标。方向 Brier 由开发 0.248803 变为指定月份 0.255616，劣于中性 0.25；21 个未知标签继续保留。

另有一项可测量的数值敏感性值得单独试验：固定已经拟合的校准器，原始模拟均值的积分标准误平均为 0.001435 个对数收益单位，经过线性校准后为 0.004719，中位放大 3.23 倍。使用解析 Jacobian 与有限差分核对 3,360 次，再用协方差传播和路径残差变换两种方法核对标准误，结果一致。这只是条件于现有校准器的数值积分误差，不是市场收益不确定性，也不证明减少模拟噪声便能改善资金收益。见[事后数值诊断](evidence/cases/integration_inspection.json)。

下一步先以固定、少量的低差异或分层抽样方案降低积分噪声，保留同一真实历史、价格模型与交易规则作对照，再检验逐日校准是否更稳定。若没有收益增量，继续检查固定行业状态投影的限制；不针对亏损月份改规则。本项新试验尚未实现，目标仍未完成。

诊断对照中有未完成交易，其净收益在 JSON 中为 null、CSV 中为 NaN；初版诊断审计器错误地直接相减。补充版本 `audit_diagnostics_nullable.py` 明确检查两者都未知，保留原数据，全部 80 项诊断检查通过。[登记](evidence/diagnostic_audit_amendment.json)明确为事后只读审计修复，未改变策略、结果和验收。

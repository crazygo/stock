# v67 · 最新已完整行情的条件路径

本轮已完成此前登记的输入时效实验与完整开发核验，主路线未通过。目标仍为五／七／九月净资金月收益算术均值至少 10%，五月至九月每月非负。v66 的失败结果完整保留。

算法仍是六字段条件历史块重采样、精确首段积分、每日联合线性残差校准与正的点估计决策。唯一预测改动是取消未参与生成器的后继状态依赖：最近两日价格片段若已经完整且当时可知，就可以进入主路线样本；真实价格、报价、分红、拆股及可用时点条件全部保留。未知发布时间继续拒绝。

`fresh_point` 是唯一主路线，`conditional_point`／`conditional_band` 保留 v66 原六字段模型，要求预测和账本精确复现。主路线仍按每个美东日零点截断历史，盘前与盘中共八时点预测，每日只用成熟反馈校准。+5% 止盈、6% 保护止损、十四个日历日上限、费用、T+1、同日不再入场和完整资金规则不变。

时效改善不等于收益改善。先通过独立输入与数值预检，再执行完整开发重放；只有正式主路线开发筛选及独立核验通过，才可运行原指定月份。已暴露历史仍是开发回归，没有新增未来观察期门槛，也没有真实下单。

## 数据时效与决策变化

独立输入审计确认，656 个查询中 640 个可加入最近一段已完整且当时已知的两日行情。最新片段平均滞后从 2.96 天降到 1.50 天；新增片段的平均首段抽样权重 0.83%。十三个行情数组逐项复现 v66，没有新采集行情。此审计在资金结果前完成，未读取资金收益。

结果出现后的描述性核查：656 个查询中 161 个改变买入／等待建议，分布在 63 个日期；新旧路线分别 48／46 次实际入场，其中 39 个入场时点及方向相同。小幅更新历史样本也能经每日校准、择边和持仓约束改变资金路径。这些计数说明决策变化，不证明风险改善；同日多查询不是独立交易样本。

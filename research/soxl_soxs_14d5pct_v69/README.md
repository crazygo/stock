# v69 · 随生成价格更新行业状态

检验固定行业状态的替代机制：将当时已知价格历史与模拟价格合并，每两日重算行业强弱、上涨广度和波动，再决定后续历史片段的权重。SOXL／SOXS 使用自身未缩放价格路径。唯一主路线 `dynamic_point`，对照为已核验的 v68 `fresh_point`。

保留盘前及盘中八时点、每日当时已知历史与成熟反馈、+5% 止盈、6% 保护止损、十四个日历日上限和原完整资金规则。目标仍为五／七／九月净月收益算术均值至少 10%，五月至九月每月非负；开发先要求一至四月全部非负、均值至少 10%、至少十笔完成交易。主路线开发失败不得新跑案例。

候选机制已在 v68 资金结果出现前登记；本版是在 v68 失败结果已知后实施，属于已暴露历史上的开发回归。状态一致性不能替代收益验证，本轮结果与核验如下。协议见 [protocol.json](protocol.json)。

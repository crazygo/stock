# v70 · 跨 ETF 配对学习的数据准备

本阶段先核验辅助数据，尚无新策略收益结果。候选来自 [v69 可行性记录](../soxl_soxs_14d5pct_v69/TRANSFER_CANDIDATE.md)，登记时已知 v69 未通过开发筛选，全部旧失败记录保留。

目标是检验其他真实杠杆 ETF 多空配对的历史经验能否改善 SOXL／SOXS 选边；最终动作仍只买 SOXL、SOXS 或弃权。训练只读每日当时已知数据和成熟标签，不能按指定月份拟合。完整资金账本、十四日 +5% 止盈、保护退出、成本和 T+1 规则不变。原目标仍为五／七／九月净收益算术均值至少 10%，五月至九月各月非负。

先补 TQQQ／SQQQ、UPRO／SPXU 与 SPY 参考行情，范围 2024-10-14–2026-04-30。分别保存未复权全时段 5 分钟、公司行动及官方日历，逐根核对覆盖。辅助配对不能替代半导体价格路径，同日多配对不能增加独立日期样本数。

数据获取沿用 Local → R2 → OpenD，不覆盖共享归档，不上传 R2。IBKR 只读公司行动交叉核对会请求两年日线接口，因接口没有截止日参数，返回的行情数组全部丢弃，仅保留首批范围内公司行动及查询身份。当前获取的公司行动不是历史当时收到的快照，标签和训练释放时点须明确处理。

完成数据审计后，才另行冻结模型、精确对照和开发验收方案；当前数据阶段不代表收益目标通过。

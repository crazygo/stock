# v74：原字段与新增二次项分块惩罚

**主方案仍未通过，不能采用。** 2026 年 1–4 月完整净资金月收益算术均值 **−1.37%**，一月 **−6.15%**、三月 **−9.29%**；连续资金 **−6.19%**，日终最大回撤 **−20.27%**。15 笔实际模拟交易全部完成，8 次止盈、7 次保护止损；14 笔 SOXL、1 笔 SOXS，其中 1 笔在盘前决策。

实现、输入、逐日模型及 15 份完整账本已经独立核验。数学正确没有带来合格收益，未新跑指定月份回归，没有买入资格。目标继续进行，旧失败结果保留。

## 为什么分块

v73 把全部 189 字段的惩罚统一放大 10.5 倍，同时收紧了原 18 字段与新增 171 项。v74 在新收益产生前冻结一个不同的假设：保留原 18 字段的共同／偏离惩罚 **100／300**，只把新增 171 项按 **171/18=9.5** 放大为 **950／2850**。没有惩罚搜索、月份过滤或事后更换主方案。

算法为**二次特征＋多输出 Ridge 部分共享，按字段块设置惩罚**。先用对角变换把不同字段惩罚化为标量，再用分块 Cholesky 求解。独立核验直接在原坐标构造完整正规方程；测试还验证去掉新增项退回 v71、全部因子为 1 退回 v72、全部因子为 10.5 退回 v73。

[公式与证明范围](METHOD.md) · [冻结协议](protocol.json) · [收益前代码登记](evidence/preregistration.json) · [真实模型预检](evidence/model_preflight.json)

保留原字段惩罚不意味着保留原系数：两个块仍有相关性，联合拟合会重新分配贡献。原 18 字段本身含三个人工交互，这里的分块是展开构造，不是经济因果分解。新旧总函数尺度也不同，不能称等容量模型。

## 新发现：先证明状态特征的增量

事后只读诊断把两侧误差拆为共同收益 C 与相对方向 D，核对恒等式 `两侧平均平方误差 = C平方误差 + D平方误差`。基准采用**同日已冻结模型中的半导体自身截距**，即相同历史成熟成员、时点和日期权重下的 C/D 均值。它不使用当前查询或未来标签，但本版只作误差对照，尚未作为另一策略回放资金。

| 预测 | C 的 MSE | D 的 MSE |
| --- | ---: | ---: |
| 当时历史均值基准 | 0.00053345 | 0.00382521 |
| v74 基础模型 | 0.00053962 | 0.00414898 |
| v74 校准后 | 0.00054306 | 0.00388626 |

主模型基础方向误差比均值基准高 **8.46%**，校准后仍高 **1.60%**。本次对照的六种模型在该批样本的 C/D 平均误差上均未胜过这个基准。这不能证明所有行情特征无用，也不能推出均值策略会盈利；它说明目前尚缺“状态特征带来可交易增量”的证据。

因此暂不继续按亏损月份尝试惩罚倍数。下一阶段先把因果均值基准做成严格冻结的完整资金对照，与相同校准和相同训练日期的状态模型比较。只有通过真实收益验证才能谈准入。现有 v18／v19／v45 专家组合及 v58 跨时点共享已做过，不能换名当新发现；后续扩展必须解释新增信息或结构，而不是重复旧方案。

# v76：扩充早期市场环境的数据准备

本版为日后比较“更长训练历史是否改善每日决策”准备数据，目标仍未达成。没有训练新模型，没有执行新的五月／七月／九月策略回归，没有新买入资格。

扩展范围固定为 2023-04-03 至 2024-10-11，另取得 2024-10-14 至 10-18 作为重叠核对。九个标的是 SOXL、SOXS、SOXX、QQQ、TQQQ、SQQQ、UPRO、SPXU、SPY。实际决策范围仍只允许 SOXL／SOXS／不行动；辅助 ETF 不能增加独立市场日期样本数。

## 目的和约束

此前模型在不足两年的训练环境上反复改变状态表达，仍未达到资金目标。本版先扩展经历过的市场环境，再另行冻结模型比较。所谓半导体“热门”必须由预测时刻可见的相对强弱、交易活动和价格路径推断，不能把未来涨幅标成当天已知的环境。更长历史也不能直接证明预测能力改善。

原验收保留：2026 年 5／7／9 月完整资金净月收益算术均值至少 10%，且 5–9 月各月非负；跨月持仓、市值、成本、资金结算及所有亏损均保留。买入附 +5% 价格止盈，固定 6% 保护止损，最迟第 14 个含买入日的自然日退出。逐日训练只使用完整成熟的标签；分析允许任意时刻启动，研究覆盖盘前 09:25:30 及七个盘中时点。

## 时间戳更正

v75 小样本报告将 09:30–15:55 的 78 根记录称为常规盘，描述错误。v76 实际请求同一天的 Futu `Session.RTH` 五分钟和日线：返回的常规盘网格为 **09:35–16:00**，五分钟 OHLC 聚合与日线一致。ALL 请求的相同行完全一致；IBKR 日线价格另行支持这一结果。

本批 Futu 五分钟 `time_key` 是**结束时间**。09:30 记录属于上一段盘前，16:00 属于最后一段常规盘；只数 78 根不能区分这两个网格。旧 v2 模型使用结束时间转换，此处无需修改。v75 原始证据及失败结果保留，以本版更正为准，不能将抽样结论推广到所有供应商。

## 来源与质量边界

沿用 [r2-market-data](../../.agents/skills/r2-market-data/SKILL.md) 的 Local → R2 → OpenD 顺序。QQQ 复用本地月分片，并与旧抓取原始页逐值核对；其余标的保留 R2 查询和 OpenD 分页原文哈希。九个公司行动档案均从本地复用，IBKR 五年日线用于交叉核验，保存前剔除 2024-10-18 之后的行情。更晚的拆股元数据仅用于逆转 IBKR 历史价格的当前股数口径，不进入早期特征。

日历使用 [Nasdaq 2023](https://www.nasdaqtrader.com/content/technicalsupport/2023tradingcalendar.pdf)、[2024](https://www.nasdaqtrader.com/content/technicalsupport/2024tradingcalendar.pdf)，并核对 [NYSE 官方假日及半日市表](https://www.nasdaq.com/press-release/nyse-group-announces-2022-2023-and-2024-holiday-and-early-closings-calendar-2021-12)。半日市 13:00 之后不能作常规盘退出或有效预测时点。

分红检查包括 Futu 普通及特别分红字段；QQQ 2023-12-27 属于特别分红。三个五位小数边界案例与 IBKR 相差半个末位单位，因此明确使用十进制绝对误差不超过 0.000005，合同金额仍保留 IBKR 完整精度和支付日期。拆股比例严格倒数核对，未支持的其他非零公司行动仍拒绝。

旧数据初始边界始于 2024-10-14，新抓取多出此前周日晚 47 根。相同时间戳的价格／量额不允许改变；接入只取新增区间到 10-11，10-14 以后继续复用原父版本，包括其原始缺失状态，不用较新的抓取改写旧回测。

缺失分钟不补零、不插值；原始完整性、常规盘覆盖和盘前特征前缀分别报告。一个缺失盘前时点还会影响依赖过去二十个同时点的特征，不能只屏蔽当日后宣称其他日期都就绪。历史 `available_at=end+1s` 是研究假设；当时实际收到时间、历史夜盘可交易性和逐根跨源成交并未因此得到证明。夜盘保留，但当前八时点特征从 04:00 后的完整前缀计算，退出标签使用常规盘。

数据接入通过后，下一版才登记并运行训练。首先比较同一每日模型在原始短历史和扩展历史上的表现，并保留因果均值对照。必须隔离历史长度和“权重归一到样本数”改变的惩罚相对强度，报告有效样本数和固定权重质量的对照，不把正则变弱当成学会了更多环境。模型与校准各自保留当时已发预测，不以五月、七月或九月身份调参。

全部行情、日线和模型缓存不进 Git，无 R2 上传或券商交易。当前历史均为已暴露研究资料，不称独立验证。新增数据不改变旧失败结论，也不改变原目标。

### 必须继续保留的来源差异

14,040 项日级 OHLC 跨源比较中，收盘价全部相差不超过原始价格一美分，开盘和盘中高低价并非完全一致。固定差异案例再请求 Futu 日线，确认主要开盘价差不是本次转换或拆股缩放引入；具体成交集合／筛选口径未得到完整证实。

SPY 在 2023-10-30 的 10:28 一分钟记录及聚合到 10:30 的五分钟记录最低为 **408.91**，但 Futu 日线与 IBKR 日线最低均为 **412.22**。一分钟与五分钟的 OHLC／成交量／成交额聚合一致。保留原值与来源分歧，不能用收盘后才知道的日线最低价倒改盘中特征。这是参考证券，但仍可能影响基于 HLC 估计的交易活动。

已检查直接成交额字段是否适合作为后续替代：全部正成交量记录都有有限正成交额，但 `成交额/成交量` 有不少记录落在所报 OHLC 范围之外，包括需要的 04:05–15:05 时段。因此不能宣称它比原典型价近似可靠，也不直接替换。下版增加价格特征与原量价特征的匹配对照，结合短／长历史比较；直接成交额先保留为待解释的数据问题。价格特征版本仍须保留同样因果时间切分与数据资格，避免靠改变样本筛选制造提升。

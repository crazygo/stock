# v90：可按历史时点读取的公司收入兑现输入

**已完成 v89 的全量数值／日期核验，并实现可复算的历史时点接口。** 122 份季度结果中，107 个有可使用的此前定期季度指引参照；11 个缺少同季度参照，四个业务范围问题保持未知。尚未训练新策略，也没有新的收益改善结论。

这轮继续落实用户关于行业升温的提示：让未来模型观察当时已经披露的公司收入兑现情况，不由后来股票上涨判断当时是否热门。数据含 NVDA、AMD、AVGO、MU、AMAT、LRCX、KLAC、INTC，源自 [v89](../soxl_soxs_14d5pct_v89/README.md) 保存的 128 份官方正文。

## 新完成的核验

- 阅读核对全部 122 份当前季度收入、表头期间、美元单位及收入指引；119 项为季度指引，三项为 Broadcom 年度指引。
- 独立解析原始 HTML 表格单元，与单独登记的 122 个实际收入及指引区间核对；与 v89 的数值一致。Lam 和 KLA 的千美元统一换算为百万美元，KLA 不使用取整的概要收入替代精确财务表。
- 核对 128 项正文公开日期，修复审查辅助程序对 `Sept.` 缩写的识别；原有公告日期没有被修改。六份预告／修订／重申继续单列。
- 对 AMD 三个季度和 Intel 一个季度保留范围疑问，不计算其兑现比值。详情及官方资料见[范围审查](SCOPE_REVIEW.md)。

同一正文的两种解析方式不是独立财务来源。数据只描述公司报告收入与公司定期指引之间的关系，不冒充分析师一致预期、同范围有机增长或纯半导体收入。

## 历史接口

`issuer_state.snapshot(dataset, asof)` 接受带时区的任意时间，登记的查询覆盖为 2023-01-01 至 2026-04-30。每家公司选当时已可用的最新正式结果，寻找更早的同一财务季度定期公告指引，计算 `实际收入 / 指引中点 − 1`。年度指引不能匹配季度结果，最新结果缺失参照或范围不明时保留未知，不能回退旧季度替代。

所有公告统一在公开日期加两个日历日的美东零点起可用。原始取得时间单列；该约定属于历史模拟，不是历史真实接收证据。中途预告、修订与重申保留其可用时点和引用，不把它们写成正式实际收入，也不替换固定的定期公告参照。完整修订史未获认证，因此接口名称与含义不使用“最后指引”或“最新预期差”。

接口输出包括原区间、中点、实际期间与收入、引用的原公告、已知中途事件、最新结果年龄、下一期指引的期间与年度／季度区别，以及缺失原因。它不会输出合格买入；`market_model_qualified=false`。

## 全范围验证

12 项测试通过，覆盖期间和单位、公开边界、时区等价、年度与季度隔离、范围未知不回退、修订不冒充实际结果、未来值修改与删除不改变历史快照、覆盖之外拒绝及无策略资格。

另用按美东日期减两天的独立参考方法，验证既有开发面板的 **6,152 个时点、772 个日期、49,216 个公司状态**，共 492,160 项字段核对。各日八个时点的已披露财务状态相同；行情在盘中仍可变化，财务状态的日内不变不代表预测概率也应不变。

# v91：已公布收入与定期指引状态

本版在 v88 的量价、日程、已完成反应 13 项状态上，加入六项按历史时点读取的财务坐标。算法仍为带原概率偏置项的多项 Logistic 校准；不预设“行业热门就买 SOXL”。本文件与 protocol.json 在新增资金回放前冻结。

输入来自 v90 已核验的 122 份季度正文及六项特别公告标记，固定八家公司。可用时间统一为正文发布日期加两个日历日的美东零点。这是当前存档构造的历史模拟时点，不代表当年的实收时间、最早发布时刻或完整修订历史。特别公告不会替换此前定期指引，不称“超市场预期”。

每一查询时点，各公司只取当时最新的季度结果。其收入只能与更早定期财报中指向同一季度的收入指引比较；年度指引不除四，业务口径未明时不沿用更老的好结果。

| 坐标 | 固定定义 |
| --- | --- |
| 兑现覆盖 N | 最新结果有可比原定期指引的公司数 |
| 兑现对数比 | N 家 log(当季收入 / 原同季指引中值) 的算术均值 |
| 超区间广度 | 2 × N 家中收入严格超过原指引上界的比例 − 1 |
| 前瞻覆盖 K | 最新结果口径已明确且有下一季度指引的公司数 |
| 指引对数增长 | K 家 log(下季指引中值 / 刚公布季度收入) 的均值 |
| 结果年龄 | N 家结果可用日至当前日期的日历日数均值 |

公司层面缺失不计入均值，来源 ID、参照 ID 与未知原因一起保存。仅当 N 或 K 为零时，将相应空均值编码为零，同时保留零覆盖计数。SOXS 翻转兑现、广度、指引增长三项方向符号；两个计数和年龄不翻转。不再增设交互、窗口、公司选择或阈值搜索。

每天第一个查询时点重新训练，只读取此前全日期、全 14 日期限成熟的原已发预测样本；遇到未知前缀停止。最近 120 个共同日期、至少 60 日期且其中至少 30 个有原合格候选的日期、日期半衰期 63、正则 lambda=10，均沿用。日内后续查询复用当天模型。禁止未来重新预测覆盖旧样本。各模型均保留原第一名和原买入资格，只能放行或弃权；不会改买另一只或把原不合格候选升级。

主方案 eligible_fundamental 用全部 19 坐标；匹配对照 eligible_reaction 用原 13 坐标，另保留 9 坐标日程、5 坐标量价及原四条路线。top_fundamental 仅为训练人群诊断。基准概率、盘前单时点、现金、双成本共组成 13 条资金账本。七个旧对照账本必须逐字节一致。所有控制组均不能替换失败主方案。

初始 1 单位资金、单只 ETF、全额或现金、T+1、成本、股息拆股和跨月盯市不变。买入附带 +5% 止盈、既有 6% 防护止损，缺口不以止损价虚构成交，最迟入场第 14 个日历日的可交易收盘退出。主评估保留全部亏损和未知占资。

先独立按发布日期 d−2 重建全部财务字段，检验未来扰动、范围缺失和日期边界；再验证样本、标准化、L-BFGS 与 Newton 数值解；冻结源码后生成所有预测，再回放一至四月。每个开发月非负、均值至少 10%、至少十笔完整交易且覆盖和复算通过，才允许扩展来源及新增五月至九月回归。最终仍是五／七／九月净月收益算术均值至少 10%，五月至九月各月非负。既有数据已暴露，结果不称独立策略验证。

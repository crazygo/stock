# v91：公司收入兑现状态接入每日滚动训练

**本轮主方案失败，未改善收益或风险回避。** 在 v88 的量价、日程和已观察反应上加入已公布收入与公司原定期指引的比较，每天只用此前成熟历史重训。一至四月净月收益算术均值 **−5.34%**，二月 **−3.12%**、三月 **−18.23%**，弱于匹配 v88 的 −2.60%。实现与独立复算通过不代表策略有效。

这轮把用户关于行业升温的提示落实为可检验模型：识别当时已经观察到的经营状态，不用未来上涨给某个月贴“热门”标签，也不预设经营好就一定买 SOXL。算法为带原已发概率偏置项的正则多项 Logistic；六个新坐标、同样的成熟训练前缀、成本和资金合同在结果出现前冻结。详见 [方法](METHOD.md) 与 [协议](protocol.json)。

## 新输入及当时可知的边界

沿用 v90 核对的 122 份定期季度结果与六份特别公告标记，固定 NVDA、AMD、AVGO、MU、AMAT、LRCX、KLAC、INTC。每个查询只读取发布日期加两个日历日后已经可用的最新正式结果，匹配更早定期公告里对同一季度的指引。年度指引不转换为季度，已知业务范围问题保留未知，不回退旧季度代替。

新增坐标为：可比公司数、收入相对原指引中值的平均对数比、超过原区间上界的公司比例、具有季度前瞻指引的公司数、下季指引相对刚公布收入的平均对数增长、结果平均年龄。公司缺失不作为零值参加均值；空集合编码与显式零覆盖计数配套。三个方向坐标对 SOXS 翻转，计数和年龄不翻转。完整表达见方法文件；每行保留结果 ID、参照 ID 与未知原因。

这是公司报告收入的代理量，不是分析师一致预期、完整指引修订史、同范围有机增长或纯半导体需求。已知的四个业务范围问题继续未知，其余公司也不因此取得同范围增长认证。当前取得的历史正文与两日可用假设不证明当年的真实接收时刻或最早发布时间。特别公告没有被当成正式结果，也没有替换原定期参照；模型不声称在正式财报时才首次知道全部差异。

独立参考程序直接用美东查询日期减两天过滤正文日期，重建全部 **6,152 个时点、772 个日期、98,432 项字段核对**。各时点的兑现覆盖为 6–8 家，季度前瞻覆盖为 6–8 家，具体分布见 [财务特征核验](evidence/fundamental_verification.json)。季度事实的重复使用不是新的独立财报样本。

本次结果否定这组固定表达的有效性，不能推论所有经营信息都无用。下一步优先核查有限样本对大幅概率修正的支持度，详见 [后续研究](NEXT_RESEARCH.md)。

## 验证与复跑

23 项测试通过，覆盖历史发布边界、未来扰动不变性、年度／季度隔离、范围未知不回退、数值导数和三套旧模型等价。15 个独立 L-BFGS 拟合锚点与五个历史不足弃权锚点通过；最大系数差约 2.63e−8。随后冻结 161 份源码、协议与输入清单，再生成全部预测并进行资金回放。

全量独立审计检查 772 个日期、1,545 次梯度、816,374 个历史成员引用、79,976 个路线动作、十三份资金账本和 221 项统计。最大梯度约 9.84e−10。四条原来源、量价、日程和反应共七份旧对照账本逐字节一致。诊断另外复算 37,632 项数值、77 个跨路线入场预测引用和十组配对区块区间；重复交易引用不是独立市场证据。

本轮属于已暴露历史上的开发回测，没有独立策略验证或新买入资格。开发门禁实际返回拒绝状态，不新增指定月份回归。最终五／七／九月净月收益算术均值至少 10%、五月至九月各月非负的目标仍未完成，[目标继续](GOAL_PROGRESS.md)。

# v92：限制状态校准的概率外推

**主方案仍未达到收益目标。** 新增零点锚定凸包约束，使模型在缺乏同类成熟样本时不能作无限的校准外推。开发期一至四月月均净收益由 v91 的 **−5.34%** 改善至 **−4.11%**，但二月 **−3.12%**、三月 **−18.23%**；七笔亏损全部保留，改善只来自新增一笔 SOXS 止盈。

算法为正则多项 Logistic 加凸包投影，继续使用当时可知的量价、日程、已观察反应和 v90 财务输入。原每日模型逐日重新训练并精确重现；本轮只限制查询时的校准修正。规则、对照及源码在新资金结果出现前冻结。[方法](METHOD.md) · [协议](protocol.json)

## 支持度检查带来的发现

全历史三个校准器共 **7,380 个已就绪查询**，进行了 73,800 项数值复算。对原合格样本校准器，SOXL 有 580 个合格查询、128 个日期，SOXS 仅四个查询、三个日期。四个 SOXS 查询均没有同一 ETF、同一时点的成熟合格历史；其中两个时点连同方向历史也为零，另外两个各只有一个同方向日期。

开发期 85 个共同候选中，84 个是 SOXL、一个是 SOXS。SOXL 同一时点成熟日期中位数为 14，披露组合中位数为 5.5；全局就绪条件的三十个合格日期不能当成各时点都有三十个独立样本。季度事实被多次引用不增加独立财报信息。具体行与分母见 [支持度审查](evidence/support_audit.json) 和无损压缩的 [全量查询](evidence/support_queries.csv.gz)。

## 冻结的新约束

对每个每日模型，取同一 ETF、同一时点历史训练样本在该模型下的四类校准修正，减去四类均值；加入零修正，构成凸包。当前修正被投影到这个集合中距离最近的点，再作用于原已发概率。空上下文精确返回原概率；原本为零的类别仍为零。

这保证新增修正的向量长度不增大、类别间赔率修正不超出零与历史同类修正的范围，训练点本身保持。它不等于特征处于历史分布内，也不是统计置信区间或收益保证。算法和逐笔最优性证明见方法文件；实现采用 [SciPy ConvexHull 官方接口](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.ConvexHull.html)。

主方案在 2,460 个已就绪查询、309 个日期中改变了 1,797 次修正，395 个查询缺少同类上下文。三个新有界模型的 7,380 次投影均有可行凸组合及最优性证书。原十三条路线保持，新增三条有界路线及主方案自己的盘前、双成本对照，共十八份账本。

## 验证与交付

13 项测试涵盖零样本、零修正、线段／平面／三维投影、所有训练点不变、独立二次规划、尺度与排列不变、退化输入、概率零支持、未来扰动、保存后重建、旧动作精确保留及不提升原弃权资格。实现预检中修复了旧 JSON 日期需要还原为 Timestamp 的读取问题，并增加对应测试；修复发生在资金结果前，原失败日志保留在缓存。

全量预检有 7,380 项投影证书和 **48 个独立 SLSQP 锚点**，最大解差约 4.51e−8。冻结 **176 份源码**后重新训练；772 个每日基础记录与 v91 完全一致，其中 1,545 个已就绪拟合继续由原梯度审计及当前输入／源码哈希支持。

新审计独立重建 **14,832 个上下文集合、7,380 项凸组合及最优性证书、110,736 个动作、十八份资金账本和 306 项统计**。最大投影最优性残差约 5.67e−14，十三份旧账本逐字节一致。诊断另复算 56,448 项数值、117 个跨路线入场预测引用和十四组区块自助区间，重复引用不作为独立市场样本。

开发门禁实际拒绝新增五月至九月回归。最终五／七／九月净资金月收益算术均值至少 10%、五月至九月各月非负的目标仍未完成。[目标继续](GOAL_PROGRESS.md)；下一步审查双侧成熟样本与动作选择，不继续围绕单笔交易调边界。[后续研究](NEXT_RESEARCH.md)
